# 310. 最小高度树

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-height-trees/description/)

### 题意

给定 n 个节点的无向树，可选择任意节点作为根。树高按根到最远叶子的边数计算，返回能使树高最小的所有根节点，顺序不限。

### 样例 1

```text
输入：n = 4, edges = [[1,0],[1,2],[1,3]]
输出：[1]
```

解释：以节点 1 为根时树高为 1，以任意叶子为根时树高为 2。
