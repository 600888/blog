# 2246. 相邻字符不同的最长路径

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-path-with-different-adjacent-characters/description/)

### 题意

parent 描述以节点 0 为根的树，s[i] 是节点 i 的字符。求任意两端点之间、相邻节点字符均不同的最长简单路径，长度按节点数计算。

### 样例 1

```text
输入：parent = [-1,0,0,0], s = "aabc"
输出：3
```

解释：路径 2 → 0 → 3 的字符为 b、a、c，包含三个节点。
