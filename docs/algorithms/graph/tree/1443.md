# 1443. 收集树上所有苹果的最少时间

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-time-to-collect-all-apples-in-a-tree/description/)

### 题意

无向树中 hasApple 标记有苹果的节点，每走一条边花费一秒。从节点 0 出发收集全部苹果并返回节点 0，求最少时间。

### 样例 1

```text
输入：n = 3, edges = [[0,1],[1,2]], hasApple = [false,false,true]
输出：4
```

解释：沿 0 → 1 → 2 收集苹果，再原路返回，共走四条边。
