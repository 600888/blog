# 1519. 子树中标签相同的节点数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-nodes-in-the-sub-tree-with-the-same-label/description/)

### 题意

给定以节点 0 为根的无向树和标签字符串 labels。对每个节点，统计其子树中与它标签相同的节点数，包含节点自身，按节点编号返回数组。

### 样例 1

```text
输入：n = 4, edges = [[0,1],[1,2],[0,3]], labels = "bbbb"
输出：[4,2,1,1]
```

解释：所有标签相同，答案分别等于各节点的子树大小。
