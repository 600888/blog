# 947. 移除最多的同行或同列石头

[力扣原题（完整题面）](https://leetcode.cn/problems/most-stones-removed-with-same-row-or-column/description/)

### 题意

stones 记录平面上的石头坐标，每个位置至多一块石头。若一块石头与另一块尚未移除的石头同行或同列，就可以移除它；求最多能移除多少块。

### 样例 1

```text
输入：stones = [[0,0],[0,1],[1,0]]
输出：2
```

解释：先移除 [0,1]，再移除 [1,0]，留下 [0,0]。
