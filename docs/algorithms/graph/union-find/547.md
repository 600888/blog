# 547. 省份数量

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-provinces/description/)

### 题意

给定城市连接矩阵 `isConnected`，若城市之间直接或间接相连，则属于同一省份。求省份总数。

### 样例 1

```text
输入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
输出：2
```

解释：前两个城市相连，第三个城市单独构成一个省份。
