# 1202. 交换字符串中的元素

[力扣原题（完整题面）](https://leetcode.cn/problems/smallest-string-with-swaps/description/)

### 题意

pairs 中每个数对指定字符串 s 的两个下标，这两个位置的字符可以交换任意多次。返回所有允许交换后能够得到的字典序最小字符串。

### 样例 1

```text
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
```

解释：交换 0、3 得到 bcad，再交换 1、2 得到 bacd。
