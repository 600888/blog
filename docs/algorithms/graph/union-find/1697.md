# 1697. 检查边长度限制的路径是否存在

[力扣原题（完整题面）](https://leetcode.cn/problems/checking-existence-of-edge-length-limited-paths/description/)

### 题意

无向带权图 edgeList 允许重边。对每个查询 [p,q,limit]，判断是否存在 p 到 q 的路径，使路径上每条边的权重都严格小于 limit；按原查询顺序返回结果。

### 样例 1

```text
输入：n = 3, edgeList = [[0,1,2],[1,2,4]], queries = [[0,2,4],[0,2,5]]
输出：[false,true]
```

解释：限制为 4 时不能使用权重为 4 的边，限制为 5 时两条边都可使用。
