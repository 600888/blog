# 785. 判断二分图

[力扣原题（完整题面）](https://leetcode.cn/problems/is-graph-bipartite/description/)

### 题意

给定可能不连通的简单无向图邻接表 graph，判断能否把所有节点分成两个集合，使每条边的两个端点分属不同集合。

### 样例 1

```text
输入：graph = [[1,3],[0,2],[1,3],[0,2]]
输出：true
```

解释：划分为 {0,2} 和 {1,3} 后，每条边都跨越两个集合。
