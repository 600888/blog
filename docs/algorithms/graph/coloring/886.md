# 886. 可能的二分法

[力扣原题（完整题面）](https://leetcode.cn/problems/possible-bipartition/description/)

### 题意

把编号 1 到 n 的人分成两组，dislikes 中的 [a,b] 表示两人不能在同一组。判断是否存在满足全部限制的分组。

### 样例 1

```text
输入：n = 4, dislikes = [[1,2],[1,3],[2,4]]
输出：true
```

解释：可以把 {1,4} 分成一组，{2,3} 分成另一组。
