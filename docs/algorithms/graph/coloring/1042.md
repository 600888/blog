# 1042. 不邻接植花

[力扣原题（完整题面）](https://leetcode.cn/problems/flower-planting-with-no-adjacent/description/)

### 题意

n 座花园由无向路径连接，每座花园最多与三座其他花园相连。从四种花中给每座花园选一种，使相邻花园种类不同；返回任意合法方案。

### 样例 1

```text
输入：n = 3, paths = [[1,2],[2,3],[3,1]]
输出：[1,2,3]
```

解释：三座花园两两相邻，使用三个不同种类即可。
