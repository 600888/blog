# 2493. 将节点分成尽可能多的组

[力扣原题（完整题面）](https://leetcode.cn/problems/divide-nodes-into-the-maximum-number-of-groups/description/)

### 题意

把无向图中的全部节点分到编号连续且非空的组中，要求每条边两端所属组的编号差恰好为 1。返回最多组数，无法分组时返回 -1；图可能不连通。

### 样例 1

```text
输入：n = 3, edges = [[1,2],[2,3],[3,1]]
输出：-1
```

解释：三角形中不存在让每条边的端点组号差都为 1 的分组。
