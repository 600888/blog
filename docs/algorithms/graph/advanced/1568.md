# 1568. 使陆地分离的最少天数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-number-of-days-to-disconnect-island/description/)

### 题意

二进制网格按四方向连接陆地。每天可把一个陆地格子变为水，求让岛屿数不等于 1 的最少天数；没有岛屿也视为已分离。

### 样例 1

```text
输入：grid = [[1,1]]
输出：2
```

解释：去掉一个格子后仍有一座岛，去掉两个后岛屿数为 0。
