# 2097. 合法重新排列数对

[力扣原题（完整题面）](https://leetcode.cn/problems/valid-arrangement-of-pairs/description/)

### 题意

重排 pairs 中全部数对，使每个数对的第二个数等于下一个数对的第一个数。题目保证至少有一个合法排列，返回任意一种，每个数对恰好使用一次。

### 样例 1

```text
输入：pairs = [[5,1],[4,5],[11,9],[9,4]]
输出：[[11,9],[9,4],[4,5],[5,1]]
```

解释：相邻数对的连接点依次为 9、4、5。
