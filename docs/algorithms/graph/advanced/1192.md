# 1192. 查找集群内的关键连接

[力扣原题（完整题面）](https://leetcode.cn/problems/critical-connections-in-a-network/description/)

### 题意

给定连通无向网络，connections 记录服务器之间的连接。找出删除后会使网络不再连通的所有边，答案及边端点的顺序不限。

### 样例 1

```text
输入：n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
输出：[[1,3]]
```

解释：删除 [1,3] 会孤立节点 3；三角形上的任意一条边删除后仍有替代路径。
