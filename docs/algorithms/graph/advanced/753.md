# 753. 破解保险箱

[力扣原题（完整题面）](https://leetcode.cn/problems/cracking-the-safe/description/)

### 题意

密码长度为 n，每位数字在 0 到 k - 1 之间。保险箱每输入一位就检查最近的 n 位；构造一个最短字符串，让所有可能密码都作为连续子串出现，返回任意最短方案。

### 样例 1

```text
输入：n = 2, k = 2
输出："00110"
```

解释：连续长度为 2 的子串依次是 00、01、11、10，覆盖全部四种密码，最短长度为 5。
