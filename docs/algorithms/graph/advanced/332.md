# 332. 重新安排行程

[力扣原题（完整题面）](https://leetcode.cn/problems/reconstruct-itinerary/description/)

### 题意

tickets 中每张机票是一条有向航线。从 JFK 出发，把所有机票各使用一次组成行程；题目保证有解，多解时返回机场序列字典序最小的一种。

### 样例 1

```text
输入：tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]
输出：["JFK","MUC","LHR","SFO","SJC"]
```

解释：按连接关系依次使用四张机票，行程从 JFK 开始。
