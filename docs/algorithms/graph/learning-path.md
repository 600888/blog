## 4. 最短路径与最小生成树

1. [743. 网络延迟时间](./shortest-path/743.md) → [1514. 概率最大的路径](./shortest-path/1514.md)：先掌握非负权最短路，再修改路径评价方式。
2. [1631. 最小体力消耗路径](./mst/1631.md) → [778. 水位上升的泳池中游泳](./shortest-path/778.md)：路径代价取最大值，理解瓶颈路径与阈值连通性。
3. [787. K 站中转内最便宜的航班](./shortest-path/787.md) → [1334. 阈值距离内邻居最少的城市](./shortest-path/1334.md)：分别处理航班段数限制与全源最短距离。
4. [1368. 使网格图至少有一条有效路径的最小代价](./shortest-path/1368.md) → [2290. 到达角落需要移除障碍物的最小数目](./shortest-path/2290.md) → [1976. 到达目的地的方案数](./shortest-path/1976.md)：学习 0-1 BFS，再在最短距离之外维护方案数。
5. [1584. 连接所有点的最小费用](./mst/1584.md) → [1489. 找到最小生成树里的关键边和伪关键边](./mst/1489.md)：先分别用 Prim、Kruskal 求生成树，再分析关键边。回到 [1631. 最小体力消耗路径](./mst/1631.md)，比较并查集或生成树性质与 Dijkstra 的解法。

| 图与目标 | 优先学习的方法 |
| --- | --- |
| 每次移动代价相同，求最少步数 | BFS |
| 边权只有 0 和 1，求最小总代价 | 0-1 BFS |
| 非负边权，求单源最短距离 | Dijkstra |
| 限制最多经过多少条边 | 分层状态或按轮数进行 Bellman-Ford 松弛 |
| 小规模图，求任意两点间的距离 | Floyd |
| 无向图，连接全部节点且总代价最小 | Prim 或 Kruskal |
