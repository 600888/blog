# 图论专题

这份题单分为 11 类，共覆盖 68 道不同题目，按分类建立 70 个独立题目页。同题出现在其他专题或不同分类时，各自保存完整正文并使用独立链接。题目页先提供题意、样例和原题链接，解题思路与代码可以逐题补充。

每类按学习顺序排列，顺序综合考虑模型和方法的复杂程度，不等同于力扣难度标签。第一次学习可以从[建议学习路径](./learning-path.md)出发，完整题目也可从左侧目录逐类展开。

## 做题前先确认

1. 节点和边分别代表什么，节点编号从 0 还是 1 开始？
2. 图是有向还是无向、是否带权、是否可能不连通？
3. 要求可达性、最少步数、最小代价、路径数量，还是特定结构？
4. 搜索状态只包含节点，还是还需要次数、额度或已访问集合？
5. 路径长度按边数还是节点数计算，网格允许四方向还是八方向移动？
