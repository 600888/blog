# 207. 课程表

[力扣原题（完整题面）](https://leetcode.cn/problems/course-schedule/description/)

### 题意

课程编号为 0 到 numCourses - 1，prerequisites 中的 [a,b] 表示学 a 前必须先学 b。判断是否能完成全部课程，返回布尔值。

### 样例 1

```text
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
```

解释：两门课程互相依赖，无法开始学习。
