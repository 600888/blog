# 210. 课程表 II

[力扣原题（完整题面）](https://leetcode.cn/problems/course-schedule-ii/description/)

### 题意

prerequisites 中的 [a,b] 表示课程 b 必须先于课程 a 完成。返回一个满足所有依赖关系的课程顺序，多解时任意一个即可；无法完成全部课程时返回空数组。

### 样例 1

```text
输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,1,2,3]
```

解释：先学 0，再学 1 和 2，最后学 3；[0,2,1,3] 也合法。
