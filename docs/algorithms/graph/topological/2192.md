# 2192. 有向无环图中一个节点的所有祖先

[力扣原题（完整题面）](https://leetcode.cn/problems/all-ancestors-of-a-node-in-a-directed-acyclic-graph/description/)

### 题意

给定 n 个节点的有向无环图，edges 中 [u,v] 表示 u 指向 v。对每个节点列出所有能够沿有向边到达它的祖先，并将每个祖先列表升序排列。

### 样例 1

```text
输入：n = 3, edges = [[0,1],[1,2]]
输出：[[],[0],[0,1]]
```

解释：0 没有祖先，1 的祖先是 0，2 的祖先是 0 和 1。
