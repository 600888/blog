# 2050. 并行课程 III

[力扣原题（完整题面）](https://leetcode.cn/problems/parallel-courses-iii/description/)

### 题意

给定 `n` 门课程、先修关系 `relations` 和每门课程的耗时 `time`。满足先修要求后可以并行学习多门课程；求修完全部课程所需的最短月数。

### 样例 1

```text
输入：n = 3, relations = [[1,3],[2,3]], time = [3,2,5]
输出：8
```

解释：课程 `1`、`2` 可并行进行，课程 `3` 等课程 `1` 完成后开始，共需 `3 + 5 = 8` 个月。
