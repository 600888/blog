# 329. 矩阵中的最长递增路径

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-increasing-path-in-a-matrix/description/)

### 题意

给定矩阵 `matrix`，每次只能移到上下左右相邻且数值严格更大的格子；求最长递增路径包含的格子数。

### 样例 1

```text
输入：matrix = [[9,9,4],[6,6,8],[2,1,1]]
输出：4
```

解释：一条最长路径是 `1 → 2 → 6 → 9`。
