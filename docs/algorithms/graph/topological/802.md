# 802. 找到最终的安全状态

[力扣原题（完整题面）](https://leetcode.cn/problems/find-eventual-safe-states/description/)

### 题意

给定有向图的邻接表。若从一个节点出发的每一条可能路径最终都会到达没有出边的节点，则该节点安全；按编号升序返回所有安全节点。

### 样例 1

```text
输入：graph = [[1,2],[2,3],[5],[0],[5],[],[]]
输出：[2,4,5,6]
```

解释：0、1、3 能走入环；2、4、5、6 的所有走法都会终止。
