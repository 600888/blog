# 1462. 课程表 IV

[力扣原题（完整题面）](https://leetcode.cn/problems/course-schedule-iv/description/)

### 题意

无环的课程依赖中，[a,b] 表示 a 是 b 的直接先修课程，也可能通过其他课程形成间接依赖。对 queries 中每个 [u,v]，判断 u 是否是 v 的先修课程，按查询顺序返回布尔数组。

### 样例 1

```text
输入：numCourses = 3, prerequisites = [[0,1],[1,2]], queries = [[0,2],[2,0]]
输出：[true,false]
```

解释：0 通过 1 间接成为 2 的先修课程，而 2 不是 0 的先修课程。
