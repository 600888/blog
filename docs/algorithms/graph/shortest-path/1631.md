# 1631. 最小体力消耗路径

[力扣原题（完整题面）](https://leetcode.cn/problems/path-with-minimum-effort/description/)

### 题意

heights 记录网格高度，只能沿四方向移动。路径体力消耗等于沿途相邻格子高度差绝对值的最大值，求左上角到右下角路径的最小体力消耗。

### 样例 1

```text
输入：heights = [[1,2,2],[3,8,2],[5,3,5]]
输出：2
```

解释：沿高度 1 → 3 → 5 → 3 → 5 行走，最大相邻高度差为 2。
