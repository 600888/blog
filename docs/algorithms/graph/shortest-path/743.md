# 743. 网络延迟时间

[力扣原题（完整题面）](https://leetcode.cn/problems/network-delay-time/description/)

### 题意

times 中 [u,v,w] 表示一条传递耗时为 w 的有向边，节点编号为 1 到 n。从 k 发出信号，求所有节点收到信号的最早时刻；存在无法到达的节点则返回 -1。

### 样例 1

```text
输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2
```

解释：节点 1、3 在时刻 1 收到信号，节点 4 在时刻 2 收到信号。
