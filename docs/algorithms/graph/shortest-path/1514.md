# 1514. 概率最大的路径

[力扣原题（完整题面）](https://leetcode.cn/problems/path-with-maximum-probability/description/)

### 题意

无向图中每条边有通过成功率 succProb，路径成功率是沿途边成功率的乘积。求 start 到 end 的最大成功率；无法到达返回 0。

### 样例 1

```text
输入：n = 3, edges = [[0,1],[1,2],[0,2]], succProb = [0.5,0.5,0.2], start = 0, end = 2
输出：0.25
```

解释：经节点 1 的路径成功率为 0.5 × 0.5 = 0.25，高于直接到达的 0.2。
