# 778. 水位上升的泳池中游泳

[力扣原题（完整题面）](https://leetcode.cn/problems/swim-in-rising-water/description/)

### 题意

n × n 网格记录各位置高度，时刻 t 的水位为 t。只有当相邻两格的高度都不超过 t 时才能在四方向移动，移动本身不耗时；求从左上角到右下角的最早时刻。

### 样例 1

```text
输入：grid = [[0,2],[1,3]]
输出：3
```

解释：终点高度为 3，水位达到 3 后整张网格都可通行。
