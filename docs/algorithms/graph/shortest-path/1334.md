# 1334. 阈值距离内邻居最少的城市

[力扣原题（完整题面）](https://leetcode.cn/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance/description/)

### 题意

无向带权图中，对每座城市统计与它的最短距离不超过 distanceThreshold 的其他城市数。返回数量最少的城市；并列时返回编号最大的城市。

### 样例 1

```text
输入：n = 4, edges = [[0,1,3],[1,2,1],[1,3,4],[2,3,1]], distanceThreshold = 4
输出：3
```

解释：城市 0 与 3 都只能到达两个其他城市，按并列规则选择 3。
