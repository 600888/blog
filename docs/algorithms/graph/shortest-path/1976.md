# 1976. 到达目的地的方案数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-ways-to-arrive-at-destination/description/)

### 题意

连通无向图 roads 中的边有正整数通行时间。统计从节点 0 到节点 n - 1 的最短耗时路径有多少种，答案对 1000000007 取模。

### 样例 1

```text
输入：n = 3, roads = [[0,1,1],[1,2,1],[0,2,2]]
输出：2
```

解释：直接走 0 → 2 或走 0 → 1 → 2 都耗时 2。
