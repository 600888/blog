# 2290. 到达角落需要移除障碍物的最小数目

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-obstacle-removal-to-reach-corner/description/)

### 题意

grid 中 0 是空格，1 是可移除的障碍，起点和终点为空格。沿四方向从左上角走到右下角，求至少要移除多少个障碍。

### 样例 1

```text
输入：grid = [[0,1,1],[1,1,0],[1,1,0]]
输出：2
```

解释：走右、右、下、下需要移除两个障碍，其他路线不能更少。
