# 1368. 使网格图至少有一条有效路径的最小代价

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/description/)

### 题意

grid 中 1、2、3、4 分别表示向右、左、下、上。路径需遵循格子箭头；每个格子可花费 1 修改方向一次，求让左上角到右下角存在有效路径所需的最小总代价。

### 样例 1

```text
输入：grid = [[1,1],[1,1]]
输出：1
```

解释：先向右，再把右上格子的箭头改为向下，即可到达终点。
