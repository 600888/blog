# 787. K 站中转内最便宜的航班

[力扣原题（完整题面）](https://leetcode.cn/problems/cheapest-flights-within-k-stops/description/)

### 题意

flights 中 [u,v,price] 表示单向航班。求从 src 到 dst、最多经过 k 个中转城市的最低费用，即最多乘坐 k + 1 段航班；无合适路线返回 -1。

### 样例 1

```text
输入：n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 1
输出：200
```

解释：经城市 1 中转一次，总费用为 100 + 100 = 200。
