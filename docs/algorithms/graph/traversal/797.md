# 797. 所有可能的路径

[力扣原题（完整题面）](https://leetcode.cn/problems/all-paths-from-source-to-target/description/)

### 题意

graph 是有向无环图的邻接表。列出从节点 0 到节点 n - 1 的所有路径，答案顺序不限。

### 样例 1

```text
输入：graph = [[1,2],[3],[3],[]]
输出：[[0,1,3],[0,2,3]]
```

解释：两条路径分别经过节点 1 和节点 2。
