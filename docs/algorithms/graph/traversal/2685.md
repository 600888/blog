# 2685. 统计完全连通分量的数量

[力扣原题（完整题面）](https://leetcode.cn/problems/count-the-number-of-complete-components/description/)

### 题意

给定 n 个节点的简单无向图，统计其中任意两个不同节点之间都有边的连通分量数量。孤立节点也属于完全连通分量。

### 样例 1

```text
输入：n = 6, edges = [[0,1],[0,2],[1,2],[3,4]]
输出：3
```

解释：三角形 {0,1,2}、单边分量 {3,4} 和孤立节点 {5} 都符合条件。
