# 133. 克隆图

[力扣原题（完整题面）](https://leetcode.cn/problems/clone-graph/description/)

### 题意

输入是无向连通图中一个节点的引用，每个节点包含值和邻居列表。创建一份节点与连接关系相同、但不共享原节点对象的图，返回对应起点；空图返回空引用。

### 样例 1

```text
输入：adjList = [[2],[1]]
输出：[[2],[1]]
```

解释：两个新节点相互连接；输出邻接表相同，但新旧节点是不同对象。
