# 1971. 寻找图中是否存在路径

[力扣原题（完整题面）](https://leetcode.cn/problems/find-if-path-exists-in-graph/description/)

### 题意

给定编号为 0 到 n - 1 的无向图，以及起点 source 和终点 destination。判断两点之间是否存在路径，返回布尔值。

### 样例 1

```text
输入：n = 3, edges = [[0,1],[1,2]], source = 0, destination = 2
输出：true
```

解释：沿 0 → 1 → 2 可以到达终点。
