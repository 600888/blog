# 1162. 地图分析

[力扣原题（完整题面）](https://leetcode.cn/problems/as-far-from-land-as-possible/description/)

### 题意

n × n 的网格中，1 是陆地，0 是海洋。对每个海洋格子计算到最近陆地的曼哈顿距离，返回这些距离的最大值；全是陆地或全是海洋时返回 -1。

### 样例 1

```text
输入：grid = [[1,0,1],[0,0,0],[1,0,1]]
输出：2
```

解释：中心海洋格子到最近陆地的距离为 2，其他海洋格子的距离更小。
