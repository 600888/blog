# 127. 单词接龙

[力扣原题（完整题面）](https://leetcode.cn/problems/word-ladder/description/)

### 题意

每次只能修改单词的一个字母，修改后的单词必须在 wordList 中。求从 beginWord 到 endWord 的最短转换序列的单词数，起点不必在字典中；无法转换返回 0。

### 样例 1

```text
输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：5
```

解释：hit → hot → dot → dog → cog 是一条最短序列，共五个单词。
