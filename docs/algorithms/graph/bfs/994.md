# 994. 腐烂的橘子

[力扣原题（完整题面）](https://leetcode.cn/problems/rotting-oranges/description/)

### 题意

grid 中 0 是空格，1 是新鲜橘子，2 是腐烂橘子。每分钟所有腐烂橘子同时感染四方向相邻的新鲜橘子；返回全部腐烂所需的最少分钟数，无法完成时返回 -1。

### 样例 1

```text
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

解释：感染按距离初始腐烂橘子的层数扩展，最远的新鲜橘子在第 4 分钟腐烂。
