# 847. 访问所有节点的最短路径

[力扣原题（完整题面）](https://leetcode.cn/problems/shortest-path-visiting-all-nodes/description/)

### 题意

给定无向连通图的邻接表 graph，可从任意节点开始和结束，也可重复经过节点或边。求至少访问每个节点一次所需的最少边数。

### 样例 1

```text
输入：graph = [[1,2,3],[0],[0],[0]]
输出：4
```

解释：路径 1 → 0 → 2 → 0 → 3 访问了所有节点，共经过四条边。
