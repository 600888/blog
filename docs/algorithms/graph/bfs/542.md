# 542. 01 矩阵

[力扣原题（完整题面）](https://leetcode.cn/problems/01-matrix/description/)

### 题意

给定至少含一个 0 的二进制矩阵 mat，求每个位置到最近 0 的距离。每次只能向上下左右移动一格，返回同样大小的距离矩阵。

### 样例 1

```text
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]
```

解释：底部中间格子到最近的 0 需要两步，其余非零格子只需一步。
