# 1293. 网格中的最短路径

[力扣原题（完整题面）](https://leetcode.cn/problems/shortest-path-in-a-grid-with-obstacles-elimination/description/)

### 题意

二进制网格中，0 是空格，1 是障碍，起点和终点均为空格。允许最多消除 k 个障碍，沿四方向移动，求左上角到右下角的最少步数；无路径返回 -1。

### 样例 1

```text
输入：grid = [[0,1,0],[1,1,0],[0,0,0]], k = 1
输出：4
```

解释：移除 (0,1) 的障碍后，沿右、右、下、下到达终点，共四步；起点的两个相邻格子都是障碍，至少需要消除一个。
