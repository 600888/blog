# 685. 冗余连接 II

[力扣原题（完整题面）](https://leetcode.cn/problems/redundant-connection-ii/description/)

### 题意

一棵节点编号为 1 到 n 的有根有向树被额外加入一条有向边。删除一条边，使剩余图重新成为有根树；存在多个可删的边时，返回输入中出现最晚的那条。

### 样例 1

```text
输入：edges = [[1,2],[1,3],[2,3]]
输出：[2,3]
```

解释：删除 [2,3] 后节点 1 是根，节点 2、3 各有一个父节点；它比另一候选边出现更晚。
