# 2360. 图中的最长环

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-cycle-in-a-graph/description/)

### 题意

edges 表示每个节点至多一条出边的有向图，-1 表示没有出边。返回最长有向环包含的节点数；没有环时返回 -1。

### 样例 1

```text
输入：edges = [3,3,4,2,3]
输出：3
```

解释：节点 2 → 4 → 3 → 2 形成长度为 3 的环。
