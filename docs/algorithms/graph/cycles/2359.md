# 2359. 找到离给定两个节点最近的节点

[力扣原题（完整题面）](https://leetcode.cn/problems/find-closest-node-to-given-two-nodes/description/)

### 题意

有向图中每个节点至多一条出边，edges[i] 为后继，-1 表示无后继。找出 node1、node2 都能到达的节点，使两段距离的较大值最小；并列取最小编号，无解返回 -1。

### 样例 1

```text
输入：edges = [2,2,3,-1], node1 = 0, node2 = 1
输出：2
```

解释：两个起点到节点 2 的距离都为 1，比共同到达节点 3 更近。
