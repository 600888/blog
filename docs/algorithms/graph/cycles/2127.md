# 2127. 参加会议的最多员工数

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-employees-to-be-invited-to-a-meeting/description/)

### 题意

favorite[i] 是员工 i 希望相邻而坐的另一名员工。邀请部分员工围坐圆桌，要求每位被邀请的人都与自己的 favorite 相邻，求最多能邀请的人数。

### 样例 1

```text
输入：favorite = [2,2,1,2]
输出：3
```

解释：员工 0、1、2 围坐时，0 与 2 相邻，1 与 2 也相邻；四人无法同时满足要求。
