# 1559. 二维网格图中探测环

[力扣原题（完整题面）](https://leetcode.cn/problems/detect-cycles-in-2d-grid/description/)

### 题意

字符网格中只能向四方向相邻、且字符相同的格子移动。判断是否存在回到起点的环，环至少经过四个不同格子，且不能立即沿上一条边原路返回。

### 样例 1

```text
输入：grid = [["a","a"],["a","a"]]
输出：true
```

解释：四个 a 沿方形边界连接成环。
