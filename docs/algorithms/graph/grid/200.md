# 200. 岛屿数量

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-islands/description/)

### 题意

字符网格中，"1" 表示陆地，"0" 表示水。上下左右相邻的陆地属于同一岛屿，统计岛屿数量。

### 样例 1

```text
输入：grid = [["1","1","0"],["0","0","1"]]
输出：2
```

解释：左上方的两个陆地格子组成一座岛，右下方的格子组成另一座岛。
