# 695. 岛屿的最大面积

[力扣原题（完整题面）](https://leetcode.cn/problems/max-area-of-island/description/)

### 题意

整数网格中，1 表示陆地，0 表示水。岛屿按上下左右相邻关系连接，面积是陆地格子数；返回最大面积，没有陆地时返回 0。

### 样例 1

```text
输入：grid = [[1,1,0],[0,1,0],[0,0,1]]
输出：3
```

解释：左上方岛屿包含三个格子，右下方岛屿面积为 1。
