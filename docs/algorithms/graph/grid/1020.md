# 1020. 飞地的数量

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-enclaves/description/)

### 题意

grid 中 1 是陆地，0 是海洋。只能沿上下左右相邻的陆地移动，统计无法走到边界并离开网格的陆地格子数。

### 样例 1

```text
输入：grid = [[0,0,0],[0,1,0],[0,0,0]]
输出：1
```

解释：中心陆地无法到达任一边界。
