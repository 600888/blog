# 463. 岛屿的周长

[力扣原题（完整题面）](https://leetcode.cn/problems/island-perimeter/description/)

### 题意

grid 中 1 是陆地，0 是水，格子边长为 1。网格恰好有一座不含内部湖泊的岛屿，求它与水或网格外部接触的边的总长度。

### 样例 1

```text
输入：grid = [[1,1]]
输出：6
```

解释：两个格子各有四条边，共享的那条边不属于外轮廓。
