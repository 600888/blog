# 130. 被围绕的区域

[力扣原题（完整题面）](https://leetcode.cn/problems/surrounded-regions/description/)

### 题意

board 由字符 X 和 O 组成，区域按四方向相邻关系连接。把无法通过 O 到达棋盘边缘的区域全部原地改为 X；样例输出表示修改后的棋盘。

### 样例 1

```text
输入：board = [["X","X","X"],["X","O","X"],["X","X","X"]]
输出：[["X","X","X"],["X","X","X"],["X","X","X"]]
```

解释：中心 O 与棋盘边缘不连通，因此被替换。
