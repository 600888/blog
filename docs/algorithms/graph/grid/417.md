# 417. 太平洋大西洋水流问题

[力扣原题（完整题面）](https://leetcode.cn/problems/pacific-atlantic-water-flow/description/)

### 题意

heights 记录各格子的高度，水能沿四方向流向不高于当前格子的邻居。上边与左边连接太平洋，下边与右边连接大西洋；返回能同时流入两个海洋的格子坐标，顺序不限。

### 样例 1

```text
输入：heights = [[2,1],[1,2]]
输出：[[0,0],[0,1],[1,0],[1,1]]
```

解释：右上和左下格子接触两片海洋；另外两个格子也能沿不升高的路径到达两片海洋。
