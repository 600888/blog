# 733. 图像渲染

[力扣原题（完整题面）](https://leetcode.cn/problems/flood-fill/description/)

### 题意

从 image[sr][sc] 开始，把通过上下左右相邻关系连通、且颜色与起点原始颜色相同的所有像素改为 color。返回修改后的图像。

### 样例 1

```text
输入：image = [[1,1],[1,0]], sr = 0, sc = 0, color = 2
输出：[[2,2],[2,0]]
```

解释：三个值为 1 的像素连通，值为 0 的像素保持原色。
