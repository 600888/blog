# 1254. 统计封闭岛屿的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-closed-islands/description/)

### 题意

本题中 0 表示陆地，1 表示水。按四方向连接陆地，统计没有任何格子接触网格边界的岛屿数量。

### 样例 1

```text
输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：1
```

解释：中心的一座岛被水围住，且不接触边界。
