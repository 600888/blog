# 827. 最大人工岛

[力扣原题（完整题面）](https://leetcode.cn/problems/making-a-large-island/description/)

### 题意

在 n × n 的二进制网格中，最多把一个 0 改成 1。岛屿按四方向相连，返回操作后可能得到的最大岛屿面积。

### 样例 1

```text
输入：grid = [[1,0],[0,1]]
输出：3
```

解释：把任意一个 0 改为 1，便能连接原本分离的两个陆地格子。
