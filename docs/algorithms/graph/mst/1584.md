# 1584. 连接所有点的最小费用

[力扣原题（完整题面）](https://leetcode.cn/problems/min-cost-to-connect-all-points/description/)

### 题意

points 是平面上的不同点，连接两点的费用为曼哈顿距离。选择一些连接，使所有点连通且任意两点之间只有一条简单路径，求最小总费用。

### 样例 1

```text
输入：points = [[0,0],[2,0],[2,2]]
输出：4
```

解释：依次连接第一、第二个点和第二、第三个点，两条边各花费 2。
