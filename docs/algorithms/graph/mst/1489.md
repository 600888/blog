# 1489. 找到最小生成树里的关键边和伪关键边

[力扣原题（完整题面）](https://leetcode.cn/problems/find-critical-and-pseudo-critical-edges-in-minimum-spanning-tree/description/)

### 题意

给定连通带权无向图，按 edges 中的原始下标返回两组边：所有最小生成树都必须使用的关键边，以及只出现在部分最小生成树中的伪关键边。两组内部的顺序不限。

### 样例 1

```text
输入：n = 4, edges = [[0,1,1],[1,2,1],[2,3,1],[0,3,1]]
输出：[[],[0,1,2,3]]
```

解释：任意去掉一条边都能得到权重为 3 的生成树，所以没有关键边，四条边都是伪关键边。
