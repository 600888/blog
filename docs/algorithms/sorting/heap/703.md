# 703. 数据流中的第 K 大元素

[力扣原题（完整题面）](https://leetcode.cn/problems/kth-largest-element-in-a-stream/description/)

### 题意

设计 `KthLargest`：初始化整数 `k` 和数组 `nums`，每次调用 `add(val)` 后返回当前所有已见数字中第 `k` 大的值。

### 样例 1

```text
输入：操作 = ["KthLargest","add","add","add","add","add"], 参数 = [[3,[4,5,8,2]],[3],[5],[10],[9],[4]]
输出：[null,4,5,5,8,8]
```

解释：加入新数字后，第 `3` 大元素依次改变。
