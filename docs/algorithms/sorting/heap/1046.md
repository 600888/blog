# 1046. 最后一块石头的重量

[力扣原题（完整题面）](https://leetcode.cn/problems/last-stone-weight/description/)

### 题意

给定石头重量数组 `stones`，每次取最重的两块相撞：相等则都消失，不等则只留下重量差。求最后剩余石头的重量，没有则返回 `0`。

### 样例 1

```text
输入：stones = [2,7,4,1,8,1]
输出：1
```

解释：按规则反复让最重的两块相撞，最终剩下重量为 `1` 的石头。
