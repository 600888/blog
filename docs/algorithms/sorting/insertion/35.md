# 35. 搜索插入位置

[力扣原题（完整题面）](https://leetcode.cn/problems/search-insert-position/description/)

### 题意

给定严格递增的整数数组 `nums` 和 `target`。若 `target` 已存在，返回其下标；否则返回插入 `target` 后仍保持递增顺序的位置。要求 O(log n) 时间。

### 样例 1

```text
输入：nums = [1,3,5,6], target = 2
输出：1
```

解释：2 应插入在 1 与 3 之间，即下标 1。

### 练习提示

这是二分定位的延伸练习。找到插入位置只需 O(log n)，数组中实际搬移元素仍可能需要 O(n)。
