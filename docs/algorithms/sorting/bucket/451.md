# 451. 根据字符出现频率排序

[力扣原题（完整题面）](https://leetcode.cn/problems/sort-characters-by-frequency/description/)

### 题意

将字符串 s 的字符按出现次数从高到低排列，同一种字符集中放置。出现次数相同的字符可以任意安排顺序。

### 样例 1

```text
输入：s = "tree"
输出："eert"
```

解释：e 出现两次，排在只出现一次的 r、t 前面；"eetr" 也是合法结果。
