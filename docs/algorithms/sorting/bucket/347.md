# 347. 前 K 个高频元素

[力扣原题（完整题面）](https://leetcode.cn/problems/top-k-frequent-elements/description/)

### 题意

给定整数数组 `nums` 和整数 `k`，返回出现频率最高的 `k` 个不同元素，答案顺序不限。

### 样例 1

```text
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

解释：`1` 出现三次，`2` 出现两次。
