# 973. 最接近原点的 K 个点

[力扣原题（完整题面）](https://leetcode.cn/problems/k-closest-points-to-origin/description/)

### 题意

给定二维点集 `points` 和 k，返回欧几里得距离最接近原点 (0,0) 的 k 个点。答案中的点可以按任意顺序排列。

### 样例 1

```text
输入：points = [[1,3],[-2,2]], k = 1
输出：[[-2,2]]
```

解释：两点到原点的距离平方分别为 10 和 8，因此选择 [-2,2]。
