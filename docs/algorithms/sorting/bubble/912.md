# 912. 排序数组

[力扣原题（完整题面）](https://leetcode.cn/problems/sort-an-array/description/)

### 题意

给定整数数组 `nums`，将元素按非递减顺序排列并返回结果。题目要求不调用内置排序函数，时间复杂度达到 O(n log n)，并尽量减少额外空间。

### 样例 1

```text
输入：nums = [5,2,3,1]
输出：[1,2,3,5]
```

解释：输出包含原数组的全部元素，且相邻元素满足前一个不大于后一个。

### 练习提示

冒泡、选择、插入和本专题的折半增量希尔排序用于小规模手写练习，不能保证满足本题完整数据的时间要求。归并、堆排序可保证 O(n log n)，随机快速排序达到期望 O(n log n)。计数与基数排序需要结合整数值域或位数分析。
