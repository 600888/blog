# 十大排序题单

按十种排序算法组织，每种一个专题，均包含原理、过程演示、可编译的 C++17 模板、性质分析、练习题单与易错点。共覆盖 **29 道不同题目**，按分类建立 **44 个独立题目页**。同题出现在不同算法下时，各自保存完整正文并使用独立链接。题目页提供题意、样例、解释和原题链接，题目解法可逐题补充。

先阅读[建议学习路径](./learning-path.md)，再练习每种排序。前七种为比较排序，后三种利用键的值域、分布或位数。以下顺序是学习组织方式，不是性能排名。

## 性质速查

下面结论对应各专题的具体模板，包含调用栈与临时输出的额外空间。

| 算法 | 时间 | 额外空间 | 稳定性 | 原地性 |
| --- | --- | --- | --- | --- |
| [冒泡排序](./bubble/index.md) | 最好 O(n)；平均 / 最坏 O(n²) | O(1) | 稳定 | 是 |
| [选择排序](./selection/index.md) | 最好 / 平均 / 最坏 O(n²) | O(1) | 不稳定 | 是 |
| [插入排序](./insertion/index.md) | 最好 O(n)；平均 / 最坏 O(n²) | O(1) | 稳定 | 是 |
| [希尔排序](./shell/index.md) | 与增量有关；本模板最坏 O(n²) | O(1) | 不稳定 | 是 |
| [归并排序](./merge/index.md) | 最好 / 平均 / 最坏 O(n log n) | O(n) | 稳定 | 否 |
| [快速排序](./quick/index.md) | 期望 O(n log n)；最坏 O(n²) | 本模板 O(log n) 调用栈 | 不稳定 | 分区原地；有调用栈 |
| [堆排序](./heap/index.md) | 平均 / 最坏 O(n log n)；建堆 O(n) | O(1) | 不稳定 | 是 |
| [计数排序](./counting/index.md) | O(n + K)，K 为值域长度 | O(n + K) | 本模板稳定 | 否 |
| [桶排序](./bucket/index.md) | 均匀分布时期望 O(n + b)；最坏 O(n² + b) | O(n + b)，本模板 b = n | 本模板稳定 | 否 |
| [基数排序](./radix/index.md) | O(d(n + b))；本模板 d = 4、b = 256 | O(n + b) | 稳定 | 否 |

- **稳定性：**相等键排序后仍保持原相对顺序。例如先按姓名排序，再稳定地按成绩排序，相同成绩内仍保留姓名顺序。只排序裸整数时看不出这种区别。
- **原地性：**这里指是否需要与输入规模同阶的辅助数组；快排分区原地，但本模板另有 O(log n) 调用栈。
- **K、b、d：**K 是整数值域长度，b 是桶或单个位的取值数，d 是处理位数。O(n + K) 或 O(d(n + b)) 不应无条件简写为 O(n)。
- **希尔与桶：**希尔的增量序列、桶的数据分布与桶内算法都会改变时间结论；查看对应页面的具体假设。

## 统一练习：912. 排序数组

912. 排序数组可作为十种模板的小规模对照练习，在下面各算法题单中打开对应的独立页面。统一测试空数组、单元素、重复值、负数、有序和逆序输入。在线题面另有不调用内置排序以及 O(n log n) 的要求：冒泡、选择、插入、本页的希尔与普通桶模板都不能保证满足完整规模的时间要求。

比较排序中，归并和堆排序有 O(n log n) 最坏保证；随机三路快排达到期望 O(n log n)。计数排序需检查值域，基数排序需说明位宽；不要把手写演示等同于所有算法都能通过同一题的完整数据。

## 自查

1. 能说明每轮确定了什么，以及未处理区间在哪里。
2. 能解释稳定性来自哪条比较条件、输出方向或桶内算法。
3. 统计比较、交换、搬移次数，把输入有序与逆序的差异说明白。
4. 把递归栈、值域计数、桶和临时输出全部算入额外空间。
5. 题目只需要第 k 个元素、频次或一次合并时，判断是否需要完整排序。
