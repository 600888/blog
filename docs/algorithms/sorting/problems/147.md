# 147. 对链表进行插入排序

[力扣原题（完整题面）](https://leetcode.cn/problems/insertion-sort-list/description/)

### 题意

给定单链表头节点 `head`，使用插入排序将链表按非递减顺序排列，返回排序后的头节点。每次把未排序部分的一个节点插入已排序部分的合适位置。

### 样例 1

```text
输入：head = [4,2,1,3]
输出：[1,2,3,4]
```

解释：逐个取出节点并插入有序链表，最后所有节点按值递增排列。
