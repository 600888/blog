# 2343. 裁剪数字后查询第 K 小的数字

[力扣原题（完整题面）](https://leetcode.cn/problems/query-kth-smallest-trimmed-number/description/)

### 题意

`nums` 是由等长数字字符串组成的数组。每个查询 [k, `trim`] 只保留每个数字最右侧 `trim` 位，返回第 k 小裁剪数字的原下标。数值相同时，原下标较小者排在前面；每个查询独立裁剪，前导零保留。

### 样例 1

```text
输入：nums = ["102","473","251","814"], queries = [[1,1],[2,3],[4,2],[1,2]]
输出：[2,2,1,0]
```

解释：保留一位时为 2、3、1、4，最小数来自下标 2；保留三位时第二小为下标 2；保留两位时为 02、73、51、14，第四小来自下标 1，第一小来自下标 0。

### 练习提示

从个位向左逐位做稳定排序，可以逐步得到不同 trim 的顺序。初始下标顺序用于处理相等数字的名次。
