# 324. 摆动排序 II

[力扣原题（完整题面）](https://leetcode.cn/problems/wiggle-sort-ii/description/)

### 题意

原地重新排列 `nums`，使 `nums`[0] < `nums`[1] > `nums`[2] < `nums`[3] > …。题目保证存在合法排列；满足严格不等式的任何结果都可以。

### 样例 1

```text
输入：nums = [1,5,1,1,6,4]
输出：[1,6,1,5,1,4]
```

解释：相邻关系依次为 1 < 6 > 1 < 5 > 1 < 4，满足摆动条件。

### 练习提示

可以先练习排序后交错放置，再研究中位数选择、虚拟下标和三路划分。重复值也必须满足严格不等式。
