# 164. 最大间距

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-gap/description/)

### 题意

给定整数数组 `nums`，返回排序后相邻元素差值的最大值。元素不足两个时返回 0。题目要求线性时间和线性额外空间。

### 样例 1

```text
输入：nums = [3,6,9,1]
输出：3
```

解释：排序结果为 [1,3,6,9]，相邻差为 2、3、3。

### 练习提示

普通桶排序在单桶拥挤时可能退化为 O(n²)，不能直接当作本题的线性保证。可用只存桶内最小值和最大值的方法，或按固定位宽使用基数排序。
