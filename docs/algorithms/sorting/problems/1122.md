# 1122. 数组的相对排序

[力扣原题（完整题面）](https://leetcode.cn/problems/relative-sort-array/description/)

### 题意

`arr2` 的元素互不相同且都出现在 `arr1` 中。按 `arr2` 指定的顺序排列 `arr1` 中对应元素，其余元素按升序放在末尾。

### 样例 1

```text
输入：arr1 = [3,1,2,3,4], arr2 = [3,2]
输出：[3,3,2,1,4]
```

解释：先放 arr2 中的 3 和 2，再把未出现在 arr2 中的 1、4 升序放在末尾。
