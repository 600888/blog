# 1464. 数组中两元素的最大乘积

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-product-of-two-elements-in-an-array/description/)

### 题意

给定正整数数组 `nums`，选取两个不同下标 i、j，求 (`nums`[i] - 1) × (`nums`[j] - 1) 的最大值。

### 样例 1

```text
输入：nums = [3,4,5,2]
输出：12
```

解释：选择数值 4 和 5，得到 (4 - 1) × (5 - 1) = 12。
