# 283. 移动零

[力扣原题（完整题面）](https://leetcode.cn/problems/move-zeroes/description/)

### 题意

原地修改数组 `nums`，把所有 0 移到末尾，同时保持非零元素原有的相对顺序。

### 样例 1

```text
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
```

解释：非零元素仍按 1、3、12 的先后顺序出现。
