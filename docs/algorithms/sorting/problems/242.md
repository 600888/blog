# 242. 有效的字母异位词

[力扣原题（完整题面）](https://leetcode.cn/problems/valid-anagram/description/)

### 题意

给定由小写英文字母组成的字符串 s、t，判断两者是否包含完全相同的字符及出现次数。字符排列顺序可以不同。

### 样例 1

```text
输入：s = "anagram", t = "nagaram"
输出：true
```

解释：两个字符串中每种字母的出现次数都相同。

### 练习提示

这是计数思想的延伸，不必真的生成排序后的字符串。
