# 88. 合并两个有序数组

[力扣原题（完整题面）](https://leetcode.cn/problems/merge-sorted-array/description/)

### 题意

`nums1` 的前 m 个元素和 `nums2` 的前 n 个元素均已按非递减顺序排列。`nums1` 总长度为 m + n，末尾预留空间不属于有效输入。将两数组合并，结果原地写入 `nums1`。

### 样例 1

```text
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
```

解释：只合并 nums1 的前三个数与 nums2 的三个数，末尾三个 0 是预留位置。
