# 75. 颜色分类

[力扣原题（完整题面）](https://leetcode.cn/problems/sort-colors/description/)

### 题意

数组 `nums` 仅包含 0、1、2，分别表示三种颜色。原地排列，使所有 0 在前、1 在中、2 在后；不能直接调用内置排序函数。

### 样例 1

```text
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

解释：相同颜色连续出现，颜色顺序为 0、1、2。
