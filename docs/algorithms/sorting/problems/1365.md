# 1365. 有多少小于当前数字的数字

[力扣原题（完整题面）](https://leetcode.cn/problems/how-many-numbers-are-smaller-than-the-current-number/description/)

### 题意

对 `nums` 中的每个元素，统计数组里严格小于它的元素个数，按原下标顺序返回计数数组。相等元素不计入。

### 样例 1

```text
输入：nums = [8,1,2,2,3]
输出：[4,0,1,1,3]
```

解释：两个 2 都只有一个更小的元素 1；3 有三个更小的元素 1、2、2。
