# 414. 第三大的数

[力扣原题（完整题面）](https://leetcode.cn/problems/third-maximum-number/description/)

### 题意

返回数组中第三大的不同数值。如果不同数值不足三个，则返回最大值；相同数值只计一次。

### 样例 1

```text
输入：nums = [2,2,3,1]
输出：1
```

解释：不同数值按降序为 3、2、1，因此第三大是 1。
