# 选择排序

[返回十大排序目录](../index.md) · [建议学习路径](../learning-path.md)

## 原理

第 i 轮在后缀 [i, n) 中找到最小值，将它交换到 i。前缀逐步扩大，每轮最多交换一次。它把寻找位置和执行交换分开。

算法定义可参考 [NIST：选择排序](https://xlinux.nist.gov/dads/HTML/selectionSort.html)。以下模板和演示用于逐步理解实现，复杂度按本页给出的版本分析。

**循环 / 递归不变量：**开始第 i 轮时，[0, i) 已有序，并且包含全数组最小的 i 个元素。

## C++17 实现模板

函数接收整数数组并修改其结果。使用 int 下标的模板约定元素数不超过 INT_MAX。本专题的整数键按常见的 32 位 int 讨论；稳定性指比较相同键时，附属记录仍保持原相对顺序。

```cpp
#include <utility>
#include <vector>

void selectionSort(std::vector<int>& a) {
    const int n = static_cast<int>(a.size());
    for (int i = 0; i + 1 < n; ++i) {
        int best = i;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[best]) best = j;
        }
        if (best != i) std::swap(a[i], a[best]);
    }
}
```

best 是本轮最小值的下标。完整扫描后才交换；把交换放在内层循环里就不再是这里的选择排序。

## 性质与复杂度

| 性质 | 本模板 |
| --- | --- |
| 时间 | 最好 / 平均 / 最坏 O(n²) |
| 额外空间 | O(1) |
| 稳定性 | 不稳定 |
| 原地性 | 是 |

无论初始顺序如何，都要做 n(n - 1)/2 次比较，交换最多 n - 1 次。远距离交换会改变相等元素的顺序：[(2,a),(2,b),1] 第一轮变成 [1,(2,b),(2,a)]。

### 手写练习

对同一输入比较冒泡与选择排序的交换次数。把交换改成移走最小值、向右平移中间元素，思考怎样获得稳定版本及其搬移成本。

## 易错点

- 每轮都必须从 i 初始化 best。
- 相同值不更新 best，也不能保证远距离交换版本稳定。
- 选择前 k 个元素是部分排序，仍可能需要 O(nk) 时间。
- 输入已排序不会减少本模板的比较次数。
