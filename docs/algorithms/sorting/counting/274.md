# 274. H 指数

[力扣原题（完整题面）](https://leetcode.cn/problems/h-index/description/)

### 题意

`citations`[i] 表示第 i 篇论文的引用次数。返回最大的整数 h，使至少 h 篇论文各自被引用不少于 h 次。

### 样例 1

```text
输入：citations = [3,0,6,1,5]
输出：3
```

解释：有三篇论文的引用次数至少为 3，但没有四篇论文达到至少 4 次引用。

### 练习提示

若论文总数为 n，可把所有超过 n 的引用次数归入 n 桶，因为 h 不可能超过 n。
