# 1051. 高度检查器

[力扣原题（完整题面）](https://leetcode.cn/problems/height-checker/description/)

### 题意

`heights` 记录当前排列的学生身高。将身高按非递减顺序排列得到 `expected`，返回 `heights` 与 `expected` 对应位置不同的数量。

### 样例 1

```text
输入：heights = [1,1,4,2,1,3]
输出：3
```

解释：expected 为 [1,1,1,2,3,4]，下标 2、4、5 的身高与当前排列不同。
