# 148. 排序链表

[力扣原题（完整题面）](https://leetcode.cn/problems/sort-list/description/)

### 题意

给定单链表头节点 `head`，将链表按非递减顺序排列并返回新的头节点。进阶要求 O(n log n) 时间和 O(1) 额外空间。

### 样例 1

```text
输入：head = [4,2,1,3]
输出：[1,2,3,4]
```

解释：节点重新连接后，值的顺序为 1、2、3、4。

### 练习提示

自顶向下递归归并需要 O(log n) 调用栈；若要满足进阶空间要求，可练习自底向上的迭代归并。
