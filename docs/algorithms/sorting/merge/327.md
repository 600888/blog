# 327. 区间和的个数

[力扣原题（完整题面）](https://leetcode.cn/problems/count-of-range-sum/description/)

### 题意

给定整数数组 `nums` 以及 `lower`、`upper`，统计和位于闭区间 [`lower`, `upper`] 内的非空连续子数组数量。

### 样例 1

```text
输入：nums = [-2,5,-1], lower = -2, upper = 2
输出：3
```

解释：符合条件的下标区间为 [0,0]、[2,2] 和 [0,2]，和分别为 -2、-1、2。

### 练习提示

归并统计通常先构造前缀和。累计和及两前缀和之差应使用足够宽的整数类型。
