# 23. 合并 K 个升序链表

[力扣原题（完整题面）](https://leetcode.cn/problems/merge-k-sorted-lists/description/)

### 题意

给定 `k` 条按非递减顺序排列的链表，合并成一条有序链表并返回头节点。

### 样例 1

```text
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
```

解释：结果包含所有链表中的节点，保持非递减顺序。
