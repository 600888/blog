# 21. 合并两个有序链表

[力扣原题（完整题面）](https://leetcode.cn/problems/merge-two-sorted-lists/description/)

### 题意

给定两条按非递减顺序排列的链表 `list1`、`list2`，把节点合并为一条仍有序的链表并返回头节点。

### 样例 1

```text
输入：list1 = [1,2,4], list2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

解释：合并后保留两条链表的所有节点。
