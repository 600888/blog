# 315. 计算右侧小于当前元素的个数

[力扣原题（完整题面）](https://leetcode.cn/problems/count-of-smaller-numbers-after-self/description/)

### 题意

给定整数数组 `nums`，返回数组 `counts`，其中 `counts[i]` 是 `nums[i]` 右侧严格小于它的元素数量。

### 样例 1

```text
输入：nums = [5,2,6,1]
输出：[2,1,1,0]
```

解释：`5` 右侧的 `2` 和 `1` 都比它小。
