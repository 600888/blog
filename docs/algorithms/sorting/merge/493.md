# 493. 翻转对

[力扣原题（完整题面）](https://leetcode.cn/problems/reverse-pairs/description/)

### 题意

给定整数数组 `nums`，统计满足 `i < j` 且 `nums[i] > 2 × nums[j]` 的下标对数量。

### 样例 1

```text
输入：nums = [1,3,2,3,1]
输出：2
```

解释：两个值为 `3` 的元素分别与末尾的 `1` 构成翻转对。
