# 1094. 拼车

[力扣原题（完整题面）](https://leetcode.cn/problems/car-pooling/description/)

### 题意

车辆有 `capacity` 个座位，`trips[i] = [numPassengers, from, to]` 表示乘客在 `from` 上车、`to` 下车。判断沿途是否始终能容纳所有乘客。

### 样例 1

```text
输入：trips = [[2,1,5],[3,3,7]], capacity = 4
输出：false
```

解释：在位置 `3` 到 `5` 之间同时有 `5` 名乘客，超过容量。
