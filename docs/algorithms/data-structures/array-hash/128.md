# 128. 最长连续序列

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-consecutive-sequence/description/)

### 题意

给定未排序的整数数组 `nums`，求由连续整数构成的最长序列长度；这些整数在原数组中不要求相邻。

### 样例 1

```text
输入：nums = [100,4,200,1,3,2]
输出：4
```

解释：连续整数 `1,2,3,4` 均在数组中，长度为 `4`。
