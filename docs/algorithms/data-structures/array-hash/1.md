# 1. 两数之和

[力扣原题（完整题面）](https://leetcode.cn/problems/two-sum/description/)

### 题意

给定整数数组 `nums` 和目标值 `target`，找出和为目标值的两个不同元素，返回它们的下标。每组输入保证恰有一个答案。

### 样例 1

```text
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
```

解释：下标 `0` 和 `1` 的元素之和为 `2 + 7 = 9`。
