# 238. 除自身以外数组的乘积

[力扣原题（完整题面）](https://leetcode.cn/problems/product-of-array-except-self/description/)

### 题意

给定数组 `nums`，返回 `answer`，其中 `answer[i]` 等于除 `nums[i]` 以外所有元素的乘积；题目要求不使用除法。

### 样例 1

```text
输入：nums = [1,2,3,4]
输出：[24,12,8,6]
```

解释：例如下标 `1` 处的结果为 `1 × 3 × 4 = 12`。
