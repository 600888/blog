# 49. 字母异位词分组

[力扣原题（完整题面）](https://leetcode.cn/problems/group-anagrams/description/)

### 题意

给定字符串数组 `strs`，把互为字母异位词的字符串分到同一组。组与组内元素的顺序不限。

### 样例 1

```text
输入：strs = ["eat","tea","tan","ate","nat","bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

解释：同组字符串包含相同字符且每种字符的数量相同。
