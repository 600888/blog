# 304. 二维区域和检索 - 矩阵不可变

[力扣原题（完整题面）](https://leetcode.cn/problems/range-sum-query-2d-immutable/description/)

### 题意

给定固定矩阵 `matrix`，实现 `NumMatrix`，多次查询以 `(row1,col1)` 和 `(row2,col2)` 为对角的闭合矩形内的元素和。

### 样例 1

```text
输入：操作 = ["NumMatrix","sumRegion"], 参数 = [[[[1,2],[3,4]]],[0,0,1,1]]
输出：[null,10]
```

解释：查询覆盖整个矩阵，元素和为 `1 + 2 + 3 + 4 = 10`。
