# 303. 区域和检索 - 数组不可变

[力扣原题（完整题面）](https://leetcode.cn/problems/range-sum-query-immutable/description/)

### 题意

给定固定数组 `nums`，实现 `NumArray`，多次查询闭区间 `[left, right]` 内元素的和；数组不会修改。

### 样例 1

```text
输入：操作 = ["NumArray","sumRange","sumRange"], 参数 = [[[-2,0,3,-5,2,-1]],[0,2],[2,5]]
输出：[null,1,-1]
```

解释：两个区间和分别是 `-2 + 0 + 3 = 1` 与 `3 - 5 + 2 - 1 = -1`。
