# 721. 账户合并

[力扣原题（完整题面）](https://leetcode.cn/problems/accounts-merge/description/)

### 题意

给定账户列表，每个账户包含姓名和若干邮箱。只要两个账户共享邮箱，就属于同一个人；合并所有同人的邮箱，返回每个账户的姓名和排序后的邮箱列表，账户顺序不限。

### 样例 1

```text
输入：accounts = [["John","a@mail.com","b@mail.com"],["John","b@mail.com","c@mail.com"]]
输出：[["John","a@mail.com","b@mail.com","c@mail.com"]]
```

解释：两个账户共享 `"b@mail.com"`，因此应合并。
