# 1319. 连通网络的操作次数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-operations-to-make-network-connected/description/)

### 题意

有 `n` 台计算机及连接线 `connections`，每次可以拔下一根已有连接线并重新连接两台计算机。求使整个网络连通的最少操作数，不可能则返回 `-1`。

### 样例 1

```text
输入：n = 4, connections = [[0,1],[0,2],[1,2]]
输出：1
```

解释：前三台之间有一根冗余连接线，可用来连接第 `3` 台。
