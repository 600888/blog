# 684. 冗余连接

[力扣原题（完整题面）](https://leetcode.cn/problems/redundant-connection/description/)

### 题意

给定一棵树额外增加一条边后形成的无向图，找出一条可以删除、使图重新成为树的边；若有多个答案，返回输入中最后出现的那条。

### 样例 1

```text
输入：edges = [[1,2],[1,3],[2,3]]
输出：[2,3]
```

解释：删除最后一条边后，剩余两条边连通全部节点且没有环。
