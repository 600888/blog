# 990. 等式方程的可满足性

[力扣原题（完整题面）](https://leetcode.cn/problems/satisfiability-of-equality-equations/description/)

### 题意

给定形如 `a==b` 或 `a!=b` 的小写字母变量方程，判断是否能给每个变量赋值，使全部等式与不等式同时成立。

### 样例 1

```text
输入：equations = ["a==b","b!=a"]
输出：false
```

解释：同一对变量不能既相等又不相等。
