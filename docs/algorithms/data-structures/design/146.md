# 146. LRU 缓存

[力扣原题（完整题面）](https://leetcode.cn/problems/lru-cache/description/)

### 题意

设计容量为 `capacity` 的缓存，支持 `get(key)` 和 `put(key,value)`；容量满时淘汰最近最久未使用的键，读取或写入已有键都会更新使用顺序。

### 样例 1

```text
输入：操作 = ["LRUCache","put","put","get","put","get"], 参数 = [[2],[1,1],[2,2],[1],[3,3],[2]]
输出：[null,null,null,1,null,-1]
```

解释：访问键 `1` 后它变成最近使用项，插入键 `3` 时淘汰键 `2`。
