# 380. O(1) 时间插入、删除和获取随机元素

[力扣原题（完整题面）](https://leetcode.cn/problems/insert-delete-getrandom-o1/description/)

### 题意

设计集合 `RandomizedSet`，支持插入、删除与等概率随机返回当前任一元素；三种操作的平均时间复杂度都应为 `O(1)`。

### 样例 1

```text
输入：操作 = ["RandomizedSet","insert","getRandom","remove","insert","getRandom"], 参数 = [[],[1],[],[1],[2],[]]
输出：[null,true,1,true,true,2]
```

解释：两次随机查询时集合里分别只有 `1` 和 `2`。
