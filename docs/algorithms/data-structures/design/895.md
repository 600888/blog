# 895. 最大频率栈

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-frequency-stack/description/)

### 题意

设计 `FreqStack`，支持压入数字和弹出当前出现次数最高的数字；若最高频数字不止一个，弹出其中最近压入的那个。

### 样例 1

```text
输入：操作 = ["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"], 参数 = [[],[5],[7],[5],[7],[4],[5],[],[],[],[]]
输出：[null,null,null,null,null,null,null,5,7,5,4]
```

解释：每次弹出都先比较当前频率，再按最近压入顺序打破并列。
