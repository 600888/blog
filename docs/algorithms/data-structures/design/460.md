# 460. LFU 缓存

[力扣原题（完整题面）](https://leetcode.cn/problems/lfu-cache/description/)

### 题意

设计容量为 `capacity` 的缓存，支持 `get`、`put`；容量满时淘汰使用频率最低的键，频率并列时淘汰其中最近最久未使用的键。

### 样例 1

```text
输入：操作 = ["LFUCache","put","put","get","put","get","get"], 参数 = [[2],[1,1],[2,2],[1],[3,3],[2],[3]]
输出：[null,null,null,1,null,-1,3]
```

解释：键 `1` 被读取后频率高于键 `2`，插入键 `3` 时淘汰键 `2`。
