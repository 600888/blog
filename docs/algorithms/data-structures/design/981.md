# 981. 基于时间的键值存储

[力扣原题（完整题面）](https://leetcode.cn/problems/time-based-key-value-store/description/)

### 题意

设计 `TimeMap`，`set(key,value,timestamp)` 为键在给定时间记录值；`get(key,timestamp)` 返回时间不晚于查询时间的最近一次记录，若不存在则返回空字符串。

### 样例 1

```text
输入：操作 = ["TimeMap","set","get","get","set","get"], 参数 = [[],["foo","bar",1],["foo",1],["foo",3],["foo","bar2",4],["foo",4]]
输出：[null,null,"bar","bar",null,"bar2"]
```

解释：时间 `3` 查询时沿用时间 `1` 的值，时间 `4` 查询得到新值。
