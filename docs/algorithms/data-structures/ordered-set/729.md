# 729. 我的日程安排表 I

[力扣原题（完整题面）](https://leetcode.cn/problems/my-calendar-i/description/)

### 题意

设计日程表，`book(startTime,endTime)` 尝试添加半开时间区间 `[startTime,endTime)`；若与已有活动重叠则拒绝，返回是否预订成功。

### 样例 1

```text
输入：操作 = ["MyCalendar","book","book","book"], 参数 = [[],[10,20],[15,25],[20,30]]
输出：[null,true,false,true]
```

解释：`[15,25)` 与已有活动重叠，而 `[20,30)` 仅在边界相接。
