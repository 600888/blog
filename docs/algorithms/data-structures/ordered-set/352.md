# 352. 将数据流变为多个不相交区间

[力扣原题（完整题面）](https://leetcode.cn/problems/data-stream-as-disjoint-intervals/description/)

### 题意

设计 `SummaryRanges`，不断添加非负整数，并随时返回覆盖所有已添加整数的互不相交、按起点升序排列的最小闭区间集合。

### 样例 1

```text
输入：操作 = ["SummaryRanges","addNum","addNum","getIntervals","addNum","getIntervals"], 参数 = [[],[1],[3],[],[2],[]]
输出：[null,null,null,[[1,1],[3,3]],null,[[1,3]]]
```

解释：加入 `2` 后，三个连续整数合并为区间 `[1,3]`。
