# 855. 考场就座

[力扣原题（完整题面）](https://leetcode.cn/problems/exam-room/description/)

### 题意

考场有 `n` 个座位，编号 `0` 到 `n-1`。`seat()` 选一个空位，使它到最近已坐学生的距离最大，距离并列时选编号最小者；`leave(p)` 让位置 `p` 空出。

### 样例 1

```text
输入：操作 = ["ExamRoom","seat","seat","seat","seat","leave","seat"], 参数 = [[10],[],[],[],[],[4],[]]
输出：[null,0,9,4,2,null,5]
```

解释：离开座位 `4` 后，最优空位是 `5`。
