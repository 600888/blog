# 数据结构题单建议学习路径

每做一道题，先明确需要高效支持哪些操作：查找、插入、删除、取极值，还是区间查询。题目页目前提供题意、样例和原题链接。

## 1. 线性容器与哈希

1. [1. 两数之和](./array-hash/1.md) → [49. 字母异位词分组](./array-hash/49.md) → [128. 最长连续序列](./array-hash/128.md)：练习用哈希结构快速定位元素。
2. [303. 区域和检索 - 数组不可变](./array-hash/303.md) → [304. 二维区域和检索 - 矩阵不可变](./array-hash/304.md) → [1094. 拼车](./array-hash/1094.md)：练习前缀和与差分。
3. [206. 反转链表](./linked-list/206.md) → [21. 合并两个有序链表](./linked-list/21.md) → [141. 环形链表](./linked-list/141.md)：熟悉指针与节点连接。
4. [20. 有效的括号](./stack-queue/20.md) → [155. 最小栈](./stack-queue/155.md) → [232. 用栈实现队列](./stack-queue/232.md)：练习栈、队列的操作约束。

## 2. 树与堆

1. [94. 二叉树的中序遍历](./binary-tree/94.md) → [102. 二叉树的层序遍历](./binary-tree/102.md) → [105. 从前序与中序遍历序列构造二叉树](./binary-tree/105.md)：理解递归、队列与遍历顺序。
2. [98. 验证二叉搜索树](./binary-tree/98.md) → [230. 二叉搜索树中第 K 小的元素](./binary-tree/230.md) → [450. 删除二叉搜索树中的节点](./binary-tree/450.md)：利用并维护有序性质。
3. [1046. 最后一块石头的重量](./heap/1046.md) → [703. 数据流中的第 K 大元素](./heap/703.md) → [295. 数据流的中位数](./heap/295.md)：从单堆走向双堆。
4. [208. 实现 Trie](./trie/208.md) → [211. 添加与搜索单词](./trie/211.md) → [421. 数组中两个数的最大异或值](./trie/421.md)：从字符前缀扩展到按位字典树。

## 3. 连通性与动态区间

1. [547. 省份数量](./union-find/547.md) → [684. 冗余连接](./union-find/684.md) → [721. 账户合并](./union-find/721.md)：练习合并与查询所属集合。
2. [307. 区域和检索 - 数组可修改](./fenwick/307.md) → [315. 计算右侧小于当前元素的个数](./fenwick/315.md)：用树状数组维护动态前缀信息。
3. 回到 [307. 区域和检索 - 数组可修改](./fenwick/307.md)，尝试线段树实现，再练习 [732. 我的日程安排表 III](./segment-tree/732.md) 和 [2569. 更新数组后处理求和查询](./segment-tree/2569.md)。
4. [729. 我的日程安排表 I](./ordered-set/729.md) → [352. 将数据流变为多个不相交区间](./ordered-set/352.md)：练习按顺序维护区间。

## 4. 综合设计

1. [146. LRU 缓存](./design/146.md) → [460. LFU 缓存](./design/460.md)：对比时间顺序与使用频率的维护。
2. [380. O(1) 时间插入、删除和获取随机元素](./design/380.md) → [895. 最大频率栈](./design/895.md)：按操作目标组合多种结构。

其余题目可以在完成对应分类的入门题后，从左侧目录继续练习。
