# 212. 单词搜索 II

[力扣原题（完整题面）](https://leetcode.cn/problems/word-search-ii/description/)

### 题意

给定字符网格 `board` 和单词列表 `words`，找出网格中能由相邻格子按上下左右方向依次组成的单词；同一个单词路径中不能重复使用格子。

### 样例 1

```text
输入：board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]
输出：["eat","oath"]
```

解释：`"eat"` 和 `"oath"` 可以在网格中找到，答案顺序不限。
