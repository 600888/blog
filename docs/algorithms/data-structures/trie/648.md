# 648. 单词替换

[力扣原题（完整题面）](https://leetcode.cn/problems/replace-words/description/)

### 题意

给定词根字典 `dictionary` 和句子 `sentence`，把句子中每个有词根前缀的单词替换成最短的匹配词根；没有匹配则保持原样。

### 样例 1

```text
输入：dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"
输出："the cat was rat by the bat"
```

解释：`"cattle"`、`"rattled"`、`"battery"` 分别由相应词根替换。
