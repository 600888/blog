# 211. 添加与搜索单词 - 数据结构设计

[力扣原题（完整题面）](https://leetcode.cn/problems/design-add-and-search-words-data-structure/description/)

### 题意

设计单词集合，支持添加单词和搜索。搜索模式中的 `.` 可以匹配任意一个字母。

### 样例 1

```text
输入：操作 = ["WordDictionary","addWord","addWord","addWord","search","search","search","search"], 参数 = [[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
输出：[null,null,null,null,false,true,true,true]
```

解释：`".ad"` 可匹配 `"bad"`、`"dad"` 或 `"mad"`。
