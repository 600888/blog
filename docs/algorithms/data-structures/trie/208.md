# 208. 实现 Trie (前缀树)

[力扣原题（完整题面）](https://leetcode.cn/problems/implement-trie-prefix-tree/description/)

### 题意

设计前缀树 `Trie`，支持插入单词、判断完整单词是否存在，以及判断是否存在以某前缀开头的单词。

### 样例 1

```text
输入：操作 = ["Trie","insert","search","search","startsWith","insert","search"], 参数 = [[],["apple"],["apple"],["app"],["app"],["app"],["app"]]
输出：[null,null,true,false,true,null,true]
```

解释：插入 `"apple"` 后，`"app"` 只是前缀；再次插入 `"app"` 后它也是完整单词。
