# 421. 数组中两个数的最大异或值

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/description/)

### 题意

给定非负整数数组 `nums`，从中选两个元素，求它们按位异或结果的最大值。

### 样例 1

```text
输入：nums = [3,10,5,25,2,8]
输出：28
```

解释：`5` 与 `25` 的异或结果为 `28`。
