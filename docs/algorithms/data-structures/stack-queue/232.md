# 232. 用栈实现队列

[力扣原题（完整题面）](https://leetcode.cn/problems/implement-queue-using-stacks/description/)

### 题意

只用两个栈实现先进先出的队列，支持 `push`、`pop`、`peek` 和 `empty`。

### 样例 1

```text
输入：操作 = ["MyQueue","push","push","peek","pop","empty"], 参数 = [[],[1],[2],[],[],[]]
输出：[null,null,null,1,1,false]
```

解释：先加入的 `1` 先被查看和移除。
