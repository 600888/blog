# 155. 最小栈

[力扣原题（完整题面）](https://leetcode.cn/problems/min-stack/description/)

### 题意

设计栈 `MinStack`，支持 `push`、`pop`、`top`，并能通过 `getMin` 取得当前栈内最小元素。

### 样例 1

```text
输入：操作 = ["MinStack","push","push","push","getMin","pop","top","getMin"], 参数 = [[],[-2],[0],[-3],[],[],[],[]]
输出：[null,null,null,null,-3,null,0,-2]
```

解释：弹出 `-3` 后，栈内最小值变成 `-2`。
