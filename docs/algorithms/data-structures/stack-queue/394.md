# 394. 字符串解码

[力扣原题（完整题面）](https://leetcode.cn/problems/decode-string/description/)

### 题意

给定编码字符串 `s`，格式为 `k[encoded_string]` 的部分表示把括号内字符串重复 `k` 次；编码可以嵌套。返回解码后的字符串。

### 样例 1

```text
输入：s = "3[a2[c]]"
输出："accaccacc"
```

解释：`a2[c]` 先解成 `"acc"`，再重复三次。
