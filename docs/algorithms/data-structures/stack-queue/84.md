# 84. 柱状图中最大的矩形

[力扣原题（完整题面）](https://leetcode.cn/problems/largest-rectangle-in-histogram/description/)

### 题意

给定相邻柱子的高度数组 `heights`，每根柱子的宽度为 `1`；求柱状图中只由连续柱子构成的最大矩形面积。

### 样例 1

```text
输入：heights = [2,1,5,6,2,3]
输出：10
```

解释：高度为 `5`、`6` 的两根柱子可组成面积为 `5 × 2 = 10` 的矩形。
