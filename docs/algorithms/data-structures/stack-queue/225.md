# 225. 用队列实现栈

[力扣原题（完整题面）](https://leetcode.cn/problems/implement-stack-using-queues/description/)

### 题意

只用队列实现后进先出的栈，支持 `push`、`pop`、`top` 和 `empty`。

### 样例 1

```text
输入：操作 = ["MyStack","push","push","top","pop","empty"], 参数 = [[],[1],[2],[],[],[]]
输出：[null,null,null,2,2,false]
```

解释：后加入的 `2` 先被查看和移除。
