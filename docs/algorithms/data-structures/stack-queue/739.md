# 739. 每日温度

[力扣原题（完整题面）](https://leetcode.cn/problems/daily-temperatures/description/)

### 题意

给定每日温度数组 `temperatures`，对每一天返回还需等待几天才能遇到更高温度；之后不存在更高温度则返回 `0`。

### 样例 1

```text
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
```

解释：第 `2` 天下标的 `75` 要等四天才遇到 `76`。
