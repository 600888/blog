# 20. 有效的括号

[力扣原题（完整题面）](https://leetcode.cn/problems/valid-parentheses/description/)

### 题意

给定只含 `()`、`[]`、`{}` 的字符串 `s`，判断每个左括号能否按正确类型和嵌套顺序与右括号匹配。

### 样例 1

```text
输入：s = "({[]})"
输出：true
```

解释：括号类型与闭合顺序都正确。
