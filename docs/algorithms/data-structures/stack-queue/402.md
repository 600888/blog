# 402. 移掉 K 位数字

[力扣原题（完整题面）](https://leetcode.cn/problems/remove-k-digits/description/)

### 题意

给定非负整数的字符串 `num` 和整数 `k`，删除恰好 `k` 位数字，使剩余数字尽量小；结果不保留多余前导零。

### 样例 1

```text
输入：num = "1432219", k = 3
输出："1219"
```

解释：删去 `4`、`3` 和一个 `2`，得到最小结果 `"1219"`。
