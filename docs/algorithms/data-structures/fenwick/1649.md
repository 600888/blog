# 1649. 通过指令创建有序数组

[力扣原题（完整题面）](https://leetcode.cn/problems/create-sorted-array-through-instructions/description/)

### 题意

依次把 `instructions` 中的数插入有序数组。每次插入的代价是“已有元素中严格更小的数量”与“严格更大的数量”的较小值；求总代价，对 `10^9 + 7` 取模。

### 样例 1

```text
输入：instructions = [1,5,6,2]
输出：1
```

解释：插入最后的 `2` 时，更小的数有一个，更大的数有两个，代价为 `1`。
