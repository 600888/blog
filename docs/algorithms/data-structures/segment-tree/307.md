# 307. 区域和检索 - 数组可修改

[力扣原题（完整题面）](https://leetcode.cn/problems/range-sum-query-mutable/description/)

### 题意

设计 `NumArray`，支持把数组指定下标更新为新值，并多次查询闭区间 `[left,right]` 内元素之和。

### 样例 1

```text
输入：操作 = ["NumArray","sumRange","update","sumRange"], 参数 = [[[1,3,5]],[0,2],[1,2],[0,2]]
输出：[null,9,null,8]
```

解释：更新下标 `1` 后数组变为 `[1,2,5]`。
