# 2569. 更新数组后处理求和查询

[力扣原题（完整题面）](https://leetcode.cn/problems/handling-sum-queries-after-update/description/)

### 题意

给定等长数组 `nums1`（只含 `0`、`1`）、`nums2` 和查询序列。三种操作分别是翻转 `nums1` 的一个区间、按 `nums1[i] × p` 增加所有 `nums2[i]`、输出 `nums2` 的元素和；返回所有求和操作的结果。

### 样例 1

```text
输入：nums1 = [1,0,1], nums2 = [0,0,0], queries = [[1,1,1],[2,1,0],[3,0,0]]
输出：[3]
```

解释：翻转后 `nums1 = [1,1,1]`，第二种操作使 `nums2` 变成 `[1,1,1]`。
