# 732. 我的日程安排表 III

[力扣原题（完整题面）](https://leetcode.cn/problems/my-calendar-iii/description/)

### 题意

设计日程表，每次添加半开区间 `[startTime,endTime)` 的活动，返回到目前为止最多有多少个活动在同一时刻重叠。

### 样例 1

```text
输入：操作 = ["MyCalendarThree","book","book","book","book","book","book"], 参数 = [[],[10,20],[50,60],[10,40],[5,15],[5,10],[25,55]]
输出：[null,1,1,2,3,3,3]
```

解释：加入 `[5,15)` 后，部分时刻有三个活动重叠。
