# 699. 掉落的方块

[力扣原题（完整题面）](https://leetcode.cn/problems/falling-squares/description/)

### 题意

给定按顺序掉落的正方形 `[left,sideLength]`。正方形落在横轴或已有正方形上方，与已有方块只接触边界不算重叠；返回每次掉落后的整体最大高度。

### 样例 1

```text
输入：positions = [[1,2],[2,3],[6,1]]
输出：[2,5,5]
```

解释：第二块与第一块水平重叠，因此叠到高度 `5`。
