# 715. Range 模块

[力扣原题（完整题面）](https://leetcode.cn/problems/range-module/description/)

### 题意

设计 `RangeModule`，维护已跟踪的实数区间，支持添加半开区间 `[left,right)`、移除区间，以及查询某区间是否完全处于已跟踪范围内。

### 样例 1

```text
输入：操作 = ["RangeModule","addRange","removeRange","queryRange","queryRange","queryRange"], 参数 = [[],[10,20],[14,16],[10,14],[13,15],[16,17]]
输出：[null,null,null,true,false,true]
```

解释：移除 `[14,16)` 后，跨过该缺口的 `[13,15)` 不再被完整跟踪。
