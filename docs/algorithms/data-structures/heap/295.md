# 295. 数据流的中位数

[力扣原题（完整题面）](https://leetcode.cn/problems/find-median-from-data-stream/description/)

### 题意

设计 `MedianFinder`，支持不断添加整数，并随时返回当前所有数字的中位数；数量为偶数时取中间两个数的平均值。

### 样例 1

```text
输入：操作 = ["MedianFinder","addNum","addNum","findMedian","addNum","findMedian"], 参数 = [[],[1],[2],[],[3],[]]
输出：[null,null,null,1.5,null,2.0]
```

解释：数字 `[1,2]` 的中位数为 `1.5`，加入 `3` 后为 `2`。
