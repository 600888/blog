# 215. 数组中的第 K 个最大元素

[力扣原题（完整题面）](https://leetcode.cn/problems/kth-largest-element-in-an-array/description/)

### 题意

给定数组 `nums` 和整数 `k`，返回按从大到小排列后的第 `k` 个元素；重复值也分别占据名次。

### 样例 1

```text
输入：nums = [3,2,1,5,6,4], k = 2
输出：5
```

解释：降序排序后为 `[6,5,4,3,2,1]`。
