# 480. 滑动窗口中位数

[力扣原题（完整题面）](https://leetcode.cn/problems/sliding-window-median/description/)

### 题意

给定数组 `nums` 和窗口长度 `k`，窗口每次向右移动一格，返回每个窗口的中位数。窗口长度为偶数时，中位数是中间两个数的平均值。

### 样例 1

```text
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[1,-1,-1,3,5,6]
```

解释：第一个窗口排序后为 `[-1,1,3]`，中位数是 `1`。
