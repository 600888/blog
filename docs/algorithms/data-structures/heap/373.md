# 373. 查找和最小的 K 对数字

[力扣原题（完整题面）](https://leetcode.cn/problems/find-k-pairs-with-smallest-sums/description/)

### 题意

给定两个非递减数组 `nums1`、`nums2` 和整数 `k`，从两数组各取一个元素组成数对，返回和最小的 `k` 个数对，答案顺序不限。

### 样例 1

```text
输入：nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出：[[1,2],[1,4],[1,6]]
```

解释：这三个数对的和分别是 `3`、`5`、`7`。
