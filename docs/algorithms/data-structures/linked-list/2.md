# 2. 两数相加

[力扣原题（完整题面）](https://leetcode.cn/problems/add-two-numbers/description/)

### 题意

两条链表 `l1`、`l2` 分别按逆序存放非负整数的各位数字。求两数之和，并以相同的逆序链表形式返回。

### 样例 1

```text
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
```

解释：两数分别是 `342` 和 `465`，和为 `807`。
