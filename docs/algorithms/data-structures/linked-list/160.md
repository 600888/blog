# 160. 相交链表

[力扣原题（完整题面）](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/)

### 题意

给定两条单链表的头节点，返回它们的第一个公共节点；若不相交则返回 `null`。相交指两链表引用同一个节点，而非仅节点值相等。

### 样例 1

```text
输入：listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：值为 8 的公共节点
```

解释：两条链表从值为 `8` 的同一个节点起共享后续节点。
