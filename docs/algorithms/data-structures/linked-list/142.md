# 142. 环形链表 II

[力扣原题（完整题面）](https://leetcode.cn/problems/linked-list-cycle-ii/description/)

### 题意

给定可能有环的链表，若存在环，返回第一个进入环的节点；否则返回 `null`。样例中的 `pos` 表示尾节点连接回的下标。

### 样例 1

```text
输入：head = [3,2,0,-4], pos = 1
输出：下标 1 的节点（值为 2）
```

解释：尾节点指回值为 `2` 的节点，该节点是环的入口。
