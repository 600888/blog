# 141. 环形链表

[力扣原题（完整题面）](https://leetcode.cn/problems/linked-list-cycle/description/)

### 题意

给定链表头节点 `head`，判断沿着 `next` 指针前进是否会再次到达已访问过的节点。样例中的 `pos` 表示尾节点连接回的下标。

### 样例 1

```text
输入：head = [3,2,0,-4], pos = 1
输出：true
```

解释：尾节点连回下标 `1` 的节点，形成环。
