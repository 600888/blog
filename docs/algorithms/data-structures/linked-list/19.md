# 19. 删除链表的倒数第 N 个结点

[力扣原题（完整题面）](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/)

### 题意

给定链表头节点 `head` 和整数 `n`，删除倒数第 `n` 个节点，返回删除后的头节点。

### 样例 1

```text
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

解释：倒数第二个节点的值为 `4`。
