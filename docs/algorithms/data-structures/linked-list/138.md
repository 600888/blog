# 138. 随机链表的复制

[力扣原题（完整题面）](https://leetcode.cn/problems/copy-list-with-random-pointer/description/)

### 题意

链表节点除了 `next`，还有可指向链表中任意节点或 `null` 的 `random` 指针。返回一条与原链表结构和值相同、但所有节点都是新节点的深拷贝。

### 样例 1

```text
输入：head = [[1,1],[2,0]]
输出：[[1,1],[2,0]]
```

解释：每对数据表示 `[节点值, random 指向的节点下标]`；返回节点不可复用原节点。
