# 94. 二叉树的中序遍历

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-tree-inorder-traversal/description/)

### 题意

给定二叉树根节点 `root`，按“左子树、根节点、右子树”的顺序返回所有节点的值。

### 样例 1

```text
输入：root = [1,null,2,3]
输出：[1,3,2]
```

解释：先访问根 `1`，再访问节点 `2` 的左孩子 `3`，最后访问 `2`。
