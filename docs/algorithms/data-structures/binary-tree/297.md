# 297. 二叉树的序列化与反序列化

[力扣原题（完整题面）](https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/description/)

### 题意

设计二叉树的序列化与反序列化方法：把树转换为可存储的字符串，再从该字符串恢复出结构和值相同的树。序列化格式可以自行设计。

### 样例 1

```text
输入：root = [1,2,3,null,null,4,5]
输出：反序列化后：[1,2,3,null,null,4,5]
```

解释：恢复出的树与原树具有相同的节点结构和值。
