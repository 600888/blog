# 105. 从前序与中序遍历序列构造二叉树

[力扣原题（完整题面）](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

### 题意

给定一棵无重复值二叉树的前序遍历 `preorder` 和中序遍历 `inorder`，重建并返回该树。

### 样例 1

```text
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]
```

解释：前序的首元素 `3` 是根节点。
