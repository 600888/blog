# 230. 二叉搜索树中第 K 小的元素

[力扣原题（完整题面）](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/description/)

### 题意

给定二叉搜索树根节点 `root` 和整数 `k`，返回树中第 `k` 小的节点值，`k` 从 `1` 开始计数。

### 样例 1

```text
输入：root = [3,1,4,null,2], k = 1
输出：1
```

解释：树中的最小值是 `1`。
