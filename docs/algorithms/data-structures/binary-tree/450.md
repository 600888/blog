# 450. 删除二叉搜索树中的节点

[力扣原题（完整题面）](https://leetcode.cn/problems/delete-node-in-a-bst/description/)

### 题意

给定二叉搜索树根节点 `root` 和值 `key`，删除值为 `key` 的节点并保持二叉搜索树性质，返回新根节点。结果可能不唯一。

### 样例 1

```text
输入：root = [5,3,6,2,4,null,7], key = 3
输出：[5,4,6,2,null,null,7]
```

解释：可以用节点 `4` 替换被删除的节点 `3`。
