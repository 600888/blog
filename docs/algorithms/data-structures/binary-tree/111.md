# 111. 二叉树的最小深度

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-depth-of-binary-tree/description/)

### 题意

给定二叉树根节点 `root`，求从根到最近叶节点所经过的节点数。叶节点必须没有左右孩子。

### 样例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：2
```

解释：节点 `9` 是距离根最近的叶节点。
