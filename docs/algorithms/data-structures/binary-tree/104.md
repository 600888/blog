# 104. 二叉树的最大深度

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/)

### 题意

给定二叉树根节点 `root`，求从根到最远叶节点所经过的节点数。

### 样例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：3
```

解释：从根到节点 `15` 或 `7` 都经过三个节点。
