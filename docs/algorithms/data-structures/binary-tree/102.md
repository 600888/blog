# 102. 二叉树的层序遍历

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

### 题意

给定二叉树根节点 `root`，从上到下逐层、每层从左到右返回节点值，每一层放在单独数组中。

### 样例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
```

解释：树共有三层。
