# 226. 翻转二叉树

[力扣原题（完整题面）](https://leetcode.cn/problems/invert-binary-tree/description/)

### 题意

给定二叉树根节点 `root`，交换树中每个节点的左右子树，返回翻转后的根节点。

### 样例 1

```text
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

解释：根节点及其子节点的左右孩子都被交换。
