# 235. 二叉搜索树的最近公共祖先

[力扣原题（完整题面）](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/description/)

### 题意

给定二叉搜索树根节点以及两个节点 `p`、`q`，返回它们的最近公共祖先。

### 样例 1

```text
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6
```

解释：节点 `2` 和 `8` 分别位于根 `6` 的左右子树。
