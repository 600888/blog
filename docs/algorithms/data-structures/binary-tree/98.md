# 98. 验证二叉搜索树

[力扣原题（完整题面）](https://leetcode.cn/problems/validate-binary-search-tree/description/)

### 题意

判断二叉树是否为二叉搜索树：对每个节点，其左子树所有值都严格小于该节点，右子树所有值都严格大于该节点。

### 样例 1

```text
输入：root = [2,1,3]
输出：true
```

解释：节点 `1 < 2 < 3`，满足二叉搜索树条件。
