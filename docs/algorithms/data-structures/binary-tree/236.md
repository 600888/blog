# 236. 二叉树的最近公共祖先

[力扣原题（完整题面）](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

### 题意

给定二叉树根节点及两个节点 `p`、`q`，返回它们最近的公共祖先；一个节点也可以是自己的祖先。

### 样例 1

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
```

解释：根节点 `3` 是节点 `5` 和 `1` 的最近公共祖先。
