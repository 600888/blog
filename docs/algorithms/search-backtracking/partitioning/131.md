# 131. 分割回文串

[力扣原题（完整题面）](https://leetcode.cn/problems/palindrome-partitioning/description/)

### 题意

把 s 连续切分成若干非空子串，要求每一段都是回文。返回全部分割方案，子串必须按原顺序拼回 s。

### 样例 1

```text
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

解释：可以逐字符切分，也可以把前两个 a 合为一段回文。
