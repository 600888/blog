# 140. 单词拆分 II

[力扣原题（完整题面）](https://leetcode.cn/problems/word-break-ii/description/)

### 题意

把 s 连续分割为 wordDict 中的单词，以空格连接成句子。字典中的单词可以重复使用，返回全部可行句子，顺序不限；没有方案则返回空数组。

### 样例 1

```text
输入：s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
输出：["cats and dog","cat sand dog"]
```

解释：两种切分分别选择 cats 与 and，或 cat 与 sand，末尾都为 dog。
