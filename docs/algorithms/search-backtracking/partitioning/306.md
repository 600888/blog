# 306. 累加数

[力扣原题（完整题面）](https://leetcode.cn/problems/additive-number/description/)

### 题意

判断数字字符串 num 能否连续切分成至少三个非负整数，使第三个起的每个数都等于前两个数之和。除数字 0 本身外，各段不得有前导零。

### 样例 1

```text
输入：num = "112358"
输出：true
```

解释：可分成 1、1、2、3、5、8，后续每个数都等于前两个数之和。
