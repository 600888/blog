# 842. 将数组拆分成斐波那契序列

[力扣原题（完整题面）](https://leetcode.cn/problems/split-array-into-fibonacci-sequence/description/)

### 题意

把数字字符串 num 连续切分成至少三个整数，要求每项在 0 到 2147483647 之间，第三项起等于前两项之和。各段不得有多余前导零；返回任一合法序列，无解返回空数组。

### 样例 1

```text
输入：num = "123456579"
输出：[123,456,579]
```

解释：123 + 456 = 579，三个整数按顺序拼接后恰好还原输入。
