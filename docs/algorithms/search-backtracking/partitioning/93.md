# 93. 复原 IP 地址

[力扣原题（完整题面）](https://leetcode.cn/problems/restore-ip-addresses/description/)

### 题意

在数字字符串 s 中加入三个点，划分出四段整数，每段在 0 到 255 之间且不能有多余前导零。不得删除或重排数字，返回所有合法 IPv4 地址，顺序不限。

### 样例 1

```text
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

解释：前两段都是 255，剩余数字有两种合法切法。
