# 473. 火柴拼正方形

[力扣原题（完整题面）](https://leetcode.cn/problems/matchsticks-to-square/description/)

### 题意

matchsticks 记录每根火柴的长度，必须把每根火柴恰好使用一次，允许首尾连接但不允许折断。判断能否把它们分成四条等长的边组成正方形。

### 样例 1

```text
输入：matchsticks = [1,1,2,2,2]
输出：true
```

解释：边长为 2，其中一边由两根长度为 1 的火柴组成，另外三边各用一根长度为 2 的火柴。
