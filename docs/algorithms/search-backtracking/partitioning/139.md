# 139. 单词拆分

[力扣原题（完整题面）](https://leetcode.cn/problems/word-break/description/)

### 题意

给定字符串 `s` 和词典 `wordDict`，判断能否将 `s` 分割为一个或多个词典中的单词；同一单词可以重复使用。

### 样例 1

```text
输入：s = "leetcode", wordDict = ["leet","code"]
输出：true
```

解释：分割为 `"leet"` 和 `"code"`。
