# 1593. 拆分字符串使唯一子字符串的数目最大

[力扣原题（完整题面）](https://leetcode.cn/problems/split-a-string-into-the-max-number-of-unique-substrings/description/)

### 题意

把 s 连续切分成若干非空子串，要求所有子串互不相同。求最多能切出多少段，各段必须按原顺序拼回 s。

### 样例 1

```text
输入：s = "ababccc"
输出：5
```

解释：分成 a、b、ab、c、cc 可得到五个不同子串，无法得到更多段。
