# 60. 排列序列

[力扣原题（完整题面）](https://leetcode.cn/problems/permutation-sequence/description/)

### 题意

把数字 1 到 n 的全部排列按字典序从小到大排列，k 从 1 开始计数。返回第 k 个排列对应的字符串。

### 样例 1

```text
输入：n = 3, k = 3
输出："213"
```

解释：排列依次为 123、132、213、231、312、321，第三个是 213。
