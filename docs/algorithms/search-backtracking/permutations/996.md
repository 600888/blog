# 996. 正方形数组的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-squareful-arrays/description/)

### 题意

重排 nums，使每一对相邻元素的和都是完全平方数。返回满足要求的不同排列数量，数值序列相同的排列只计一次。

### 样例 1

```text
输入：nums = [1,17,8]
输出：2
```

解释：合法排列为 [1,8,17] 和 [17,8,1]，相邻和分别为 9 与 25。
