# 47. 全排列 II

[力扣原题（完整题面）](https://leetcode.cn/problems/permutations-ii/description/)

### 题意

nums 可以含有重复整数。返回使用全部元素形成的所有不同排列，相同数值序列只返回一次，答案顺序不限。

### 样例 1

```text
输入：nums = [1,1,2]
输出：[[1,1,2],[1,2,1],[2,1,1]]
```

解释：两个 1 无法按值区分，排列由 2 所在的位置决定。
