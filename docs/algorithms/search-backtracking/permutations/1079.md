# 1079. 活字印刷

[力扣原题（完整题面）](https://leetcode.cn/problems/letter-tile-possibilities/description/)

### 题意

tiles 中每个字符代表一块字模，每块最多使用一次。可选择部分或全部字模并排列，统计能够印出的不同非空字母序列数量。

### 样例 1

```text
输入：tiles = "AAB"
输出：8
```

解释：序列为 A、B、AA、AB、BA、AAB、ABA、BAA，共八种。
