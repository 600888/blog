# 22. 括号生成

[力扣原题（完整题面）](https://leetcode.cn/problems/generate-parentheses/description/)

### 题意

给定括号对数 n，返回所有由 n 个左括号和 n 个右括号组成的有效括号字符串，答案顺序不限。

### 样例 1

```text
输入：n = 2
输出：["(())","()()"]
```

解释：两个括号对只有嵌套和并列这两种有效安排。
