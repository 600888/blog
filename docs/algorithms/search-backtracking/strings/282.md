# 282. 给表达式添加运算符

[力扣原题（完整题面）](https://leetcode.cn/problems/expression-add-operators/description/)

### 题意

在数字字符串 num 的某些相邻数字之间插入 +、- 或 *，也可以把连续数字作为一个整数。返回计算结果等于 target 的全部表达式；整数不能有多余前导零，乘法优先于加减。

### 样例 1

```text
输入：num = "123", target = 6
输出：["1+2+3","1*2*3"]
```

解释：这两个表达式的结果都为 6，其余合法插入方式不能得到目标值。
