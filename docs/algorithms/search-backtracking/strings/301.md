# 301. 删除无效的括号

[力扣原题（完整题面）](https://leetcode.cn/problems/remove-invalid-parentheses/description/)

### 题意

s 由字母和括号组成，只允许删除括号。删除尽可能少的括号，使剩余括号配对合法，返回全部不同结果，顺序不限，字母保留。

### 样例 1

```text
输入：s = "()())()"
输出：["(())()","()()()"]
```

解释：至少需要删去一个右括号，按不同位置删除可得到这两个有效结果。
