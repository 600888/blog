# 1415. 长度为 n 的开心字符串中字典序第 k 小的字符串

[力扣原题（完整题面）](https://leetcode.cn/problems/the-k-th-lexicographical-string-of-all-happy-strings-of-length-n/description/)

### 题意

开心字符串只含 a、b、c，且相邻字符不同。将长度为 n 的全部开心字符串按字典序排列，返回从 1 开始计数的第 k 个；不足 k 个时返回空字符串。

### 样例 1

```text
输入：n = 3, k = 9
输出："cab"
```

解释：前八个字符串以 a 或 b 开头，第九个为 cab。
