# 17. 电话号码的字母组合

[力扣原题（完整题面）](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/)

### 题意

digits 仅包含数字 2 到 9，为每位数字选取对应电话按键上的一个字母，返回全部组合，顺序不限。映射为 2→abc、3→def、4→ghi、5→jkl、6→mno、7→pqrs、8→tuv、9→wxyz。

### 样例 1

```text
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

解释：第一位从 abc 中选一个字母，第二位从 def 中选一个字母，共九种组合。
