# 搜索与回溯建议学习路径

题目页目前提供题意、样例、解释和原题链接。练习时先画出一个小输入的搜索树，再明确状态、候选、终止条件与需要撤销的修改。完整目录见[搜索与回溯专题](./index.md)。

## 1. 理解状态与路径恢复

1. [112. 路径总和](./basics/112.md) → [257. 二叉树的所有路径](./basics/257.md) → [113. 路径总和 II](./basics/113.md)：从判断是否存在路径，逐步做到记录全部路径；收集答案时应保存当前路径的副本。
2. [841. 钥匙和房间](./basics/841.md) → [733. 图像渲染](./basics/733.md)：用 DFS 处理可达性，理解为什么访问标记在遍历结束后通常保留。
3. [797. 所有可能的路径](./basics/797.md) → [1091. 二进制矩阵中的最短路径](./basics/1091.md)：比较枚举全部路径与求最短步数的不同目标。

| 场景 | 标记的含义 | 返回上一层时的处理 |
| --- | --- | --- |
| 可达性遍历 | 该节点已经探索过 | 保留全局标记，避免重复探索 |
| 排列或不可重复格子的路径 | 该元素或格子已在当前路径中使用 | 撤销标记，让其他分支仍可选择 |
| 全部路径枚举 | 当前前缀对应一条不同方案 | 恢复路径；不能简单以“到过终点或中间节点”跳过其他前缀 |
| 记忆化搜索 | 某完整状态的后续结果已算出 | 缓存结果；状态必须包含决定后续结果的全部信息 |

## 2. 子集、组合与排列

1. [78. 子集](./subsets/78.md) → [1863. 找出所有子集的异或总和再求和](./subsets/1863.md) → [784. 字母大小写全排列](./subsets/784.md)：练习选或不选、叶子统计与逐位置选择。
2. [90. 子集 II](./subsets/90.md) → [491. 非递减子序列](./subsets/491.md) → [2044. 统计按位或能得到最大值的子集数目](./subsets/2044.md) → [1239. 串联字符串的最大长度](./subsets/1239.md)：分别处理相同值结果去重、原顺序限制、按下标计数与字符冲突。
3. [77. 组合](./combinations/77.md) → [39. 组合总和](./combinations/39.md) → [40. 组合总和 II](./combinations/40.md) → [216. 组合总和 III](./combinations/216.md)：比较固定数量、可重复使用、每项使用一次和数量加总和双重约束。
4. [46. 全排列](./permutations/46.md) → [47. 全排列 II](./permutations/47.md) → [1079. 活字印刷](./permutations/1079.md)：用已使用标记或字符频次控制排列，再处理重复值。
5. [526. 优美的排列](./permutations/526.md) → [996. 正方形数组的数目](./permutations/996.md) → [60. 排列序列](./permutations/60.md)：增加位置或相邻限制，最后比较完整枚举与按分支数量跳过结果。

| 模型 | 顺序是否区分结果 | 常见状态 |
| --- | --- | --- |
| 子集 | 不区分选择顺序 | 当前下标与已选元素 |
| 组合 | 不区分选择顺序 | 起始下标、剩余数量或剩余目标 |
| 排列 | 区分顺序 | 当前长度、已使用元素或剩余频次 |

去重规则必须按题意决定：90 中选择两个相同值的不同下标可能产生同一答案；2044 与 1863 中，下标选择不同就需要分别计数。491 需要保持原下标顺序，不能先排序数组再求子序列。

掌握组合后，可练习 [1286. 字母组合迭代器](./combinations/1286.md) 的按序输出和 [2397. 被列覆盖的最多行数](./combinations/2397.md) 的固定列数选择。

## 3. 字符串构造与连续分割

1. [17. 电话号码的字母组合](./strings/17.md) → [22. 括号生成](./strings/22.md) → [1415. 长度为 n 的开心字符串中字典序第 k 小的字符串](./strings/1415.md)：明确每一位的候选，在构造过程中保持前缀合法。
2. [131. 分割回文串](./partitioning/131.md) → [93. 复原 IP 地址](./partitioning/93.md)：枚举下一个切分点，分别检查回文和 IP 段是否合法。
3. [306. 累加数](./partitioning/306.md) → [842. 将数组拆分成斐波那契序列](./partitioning/842.md)：先确定前两个数，利用加法关系约束后续分段，处理前导零与数值范围。
4. [139. 单词拆分](./partitioning/139.md) → [140. 单词拆分 II](./partitioning/140.md) → [1593. 拆分字符串使唯一子字符串的数目最大](./partitioning/1593.md)：从可行性判断转向收集全部句子和最大化分段数。
5. [282. 给表达式添加运算符](./strings/282.md) → [301. 删除无效的括号](./strings/301.md)：进阶处理运算优先级与最少删除次数。

140 可以缓存某后缀的全部拼接结果，或缓存后缀是否可行以剪枝；1593 的后续选择还依赖已选子串集合，不能仅用当前下标缓存答案。

## 4. 集合分组与网格路径

1. [473. 火柴拼正方形](./partitioning/473.md) → [698. 划分为 k 个相等的子集](./partitioning/698.md)：把元素分配到等容量的桶中；排序较长元素优先尝试，并比较负载相同的桶是否等价。
2. [79. 单词搜索](./grid/79.md) → [212. 单词搜索 II](./grid/212.md)：维护当前路径内的格子标记，逐步加入 Trie 的前缀剪枝。
3. [980. 不同路径 III](./grid/980.md) → [1219. 黄金矿工](./grid/1219.md)：从到达目标转为全覆盖路径计数和任意起终点的路径最优值。
4. [329. 矩阵中的最长递增路径](./grid/329.md)：严格递增使搜索关系无环，可缓存从每个格子出发的最长后续路径。

集合分组不要求所选元素在原数组中连续；字符串分割的每一段必须连续，并按原顺序拼回输入。不要混用两类状态。

## 5. 约束满足

1. [51. N 皇后](./constraints/51.md) → [52. N 皇后 II](./constraints/52.md)：逐行放置皇后，维护列和两种斜线占用；比较返回方案与只计数量。
2. [37. 解数独](./constraints/37.md)：维护行、列、宫的候选，尝试优先填写候选较少的空格。
3. [1718. 构建字典序最大的可行序列](./constraints/1718.md)：一次放置成对数字；优先尝试较大数字以满足字典序目标。
4. 回到 [526. 优美的排列](./constraints/526.md)，对比逐位置回溯和已使用集合的状态压缩。

选择、递归、撤销必须成对处理；找到一个可行解后能否立即返回，取决于题目要的是任意解、全部解还是特定最优解。

## 6. 最少操作与全部最短方案

1. [752. 打开转盘锁](./advanced/752.md) → [127. 单词接龙](./advanced/127.md)：把一次合法操作看作一条单位代价边，用 BFS 求最少操作或最短序列长度。
2. [126. 单词接龙 II](./advanced/126.md)：先确定最短层次，再在前驱图上回溯全部最短序列。
3. [847. 访问所有节点的最短路径](./advanced/847.md)：状态中加入已访问集合，同一节点搭配不同集合属于不同状态。

126 中同一层到达同一个单词的多个前驱都可能产生不同的最短方案，需要保留这些前驱关系，不能只保留首次到达的那条路径。

## 7. 记忆化与最优解剪枝（进阶）

1. [638. 大礼包](./advanced/638.md) → [691. 贴纸拼词](./advanced/691.md)：分别用剩余商品需求和剩余字符需求描述后续问题，缓存重复状态。
2. [464. 我能赢吗](./advanced/464.md)：状态包含已选择数字集合，区分当前玩家与后续玩家的胜负。
3. [1723. 完成所有工作的最短时间](./advanced/1723.md) → [2305. 公平分发饼干](./advanced/2305.md)：维护桶负载和当前最优值，结合对称状态与目标值界限剪枝。
4. [488. 祖玛游戏](./advanced/488.md) → [1240. 铺瓷砖](./advanced/1240.md)：选学复杂局面搜索，完整记录手牌或覆盖状态，验证剪枝不会排除最优方案。

记忆化需要完整状态，也需要正确处理递归依赖与终止条件；对有环的状态图，单纯缓存已完成结果不能替代访问检测。

完成代表题后，可以从[完整题单](./index.md#完整题单)补齐变形。每次加入去重或剪枝前，先用小输入枚举全部结果，确认方案集合或最优值保持一致。
