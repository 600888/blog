# 90. 子集 II

[力扣原题（完整题面）](https://leetcode.cn/problems/subsets-ii/description/)

### 题意

nums 可能含有重复整数。返回按元素值区分的所有不同子集，包含空集；相同元素值组成的结果只返回一次，顺序不限。

### 样例 1

```text
输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]
```

解释：两个 2 可以同时选取，但只选一个 2 时不应产生两份相同结果。
