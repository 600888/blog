# 1863. 找出所有子集的异或总和再求和

[力扣原题（完整题面）](https://leetcode.cn/problems/sum-of-all-subset-xor-totals/description/)

### 题意

每个子集的异或总和是其中所有元素按位异或的结果，空集的值为 0。求 nums 所有子集异或总和的总和；下标选择不同的子集分别计入，即使元素值相同。

### 样例 1

```text
输入：nums = [1,3]
输出：6
```

解释：空集、[1]、[3]、[1,3] 的异或值分别为 0、1、3、2，总和为 6。
