# 78. 子集

[力扣原题（完整题面）](https://leetcode.cn/problems/subsets/description/)

### 题意

nums 中的整数互不相同。返回所有子集，包含空集与全集，不得有重复结果，答案顺序不限。

### 样例 1

```text
输入：nums = [1,2]
输出：[[],[1],[2],[1,2]]
```

解释：对两个元素分别选择保留或跳过，共得到四个子集。
