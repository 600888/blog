# 491. 非递减子序列

[力扣原题（完整题面）](https://leetcode.cn/problems/non-decreasing-subsequences/description/)

### 题意

从 nums 中保留部分元素，维持原下标顺序，返回长度至少为 2 的全部不同非递减子序列。相邻元素允许相等，答案顺序不限。

### 样例 1

```text
输入：nums = [4,4,3,2,1]
输出：[[4,4]]
```

解释：只有两个 4 能按原顺序组成长度至少为 2 的非递减序列。
