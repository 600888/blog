# 2044. 统计按位或能得到最大值的子集数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-number-of-maximum-bitwise-or-subsets/description/)

### 题意

在 nums 的所有非空子集中，先确定能够得到的最大按位或值，再统计达到该值的子集数量。选择的下标不同就视为不同子集，即使元素值相同。

### 样例 1

```text
输入：nums = [3,1]
输出：2
```

解释：最大按位或值为 3，子集 [3] 和 [3,1] 都能达到它。
