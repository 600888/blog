# 1239. 串联字符串的最大长度

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-length-of-a-concatenated-string-with-unique-characters/description/)

### 题意

按原顺序选择字符串数组 arr 的一个子序列并拼接，要求拼接结果中的所有字符互不重复。返回满足条件的最大长度，可以不选任何字符串。

### 样例 1

```text
输入：arr = ["un","iq","ue"]
输出：4
```

解释：拼接 un 与 iq，或 iq 与 ue，都能得到长度为 4 且无重复字符的字符串。
