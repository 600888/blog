# 784. 字母大小写全排列

[力扣原题（完整题面）](https://leetcode.cn/problems/letter-case-permutation/description/)

### 题意

s 由英文字母和数字组成，每个字母可独立改成大写或小写，数字保持不变。返回所有可能得到的字符串，顺序不限。

### 样例 1

```text
输入：s = "a1b2"
输出：["a1b2","a1B2","A1b2","A1B2"]
```

解释：两个字母各有两种大小写选择，共四种字符串。
