# 1723. 完成所有工作的最短时间

[力扣原题（完整题面）](https://leetcode.cn/problems/find-minimum-time-to-finish-all-jobs/description/)

### 题意

jobs[i] 是第 i 项工作的耗时，把全部工作分配给 k 位工人，每项工作只能交给一个工人。每位工人的总耗时是其任务耗时之和，求让最大总耗时最小的分配结果。

### 样例 1

```text
输入：jobs = [1,2,4,7,8], k = 2
输出：11
```

解释：分成 [1,2,8] 与 [4,7]，两位工人的总耗时都是 11。
