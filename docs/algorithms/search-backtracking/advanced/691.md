# 691. 贴纸拼词

[力扣原题（完整题面）](https://leetcode.cn/problems/stickers-to-spell-word/description/)

### 题意

每种贴纸上有一个小写单词，可无限次使用同种贴纸。每张贴纸的字母可拆开并重排，求组成 target 最少需要多少张贴纸；无法组成返回 -1，允许剩余字母不用。

### 样例 1

```text
输入：stickers = ["with","example","science"], target = "thehat"
输出：3
```

解释：使用两张 with 和一张 example 即可；目标含两个 t 和两个 h，另需 a，因此两张贴纸不够。
