# 2305. 公平分发饼干

[力扣原题（完整题面）](https://leetcode.cn/problems/fair-distribution-of-cookies/description/)

### 题意

cookies[i] 是一袋饼干的数量，把所有袋子分给 k 个孩子，同一袋不能拆开。一个方案的不公平程度为收到最多饼干的孩子的总数，求最小不公平程度。

### 样例 1

```text
输入：cookies = [8,15,10,20,8], k = 2
输出：31
```

解释：分成 [8,15,8] 与 [10,20]，总数分别为 31 和 30；总数为 61，所以最大值不可能小于 31。
