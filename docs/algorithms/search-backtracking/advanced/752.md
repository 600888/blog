# 752. 打开转盘锁

[力扣原题（完整题面）](https://leetcode.cn/problems/open-the-lock/description/)

### 题意

四位转盘锁从 0000 开始，每次只能把一位数字向前或向后转一格，0 与 9 相邻。不得进入 deadends 中的状态，求到 target 的最少次数；无法到达返回 -1。

### 样例 1

```text
输入：deadends = ["8888"], target = "0009"
输出：1
```

解释：最后一位从 0 反向转到 9 即可，途中不会进入禁用状态。
