# 488. 祖玛游戏

[力扣原题（完整题面）](https://leetcode.cn/problems/zuma-game/description/)

### 题意

board 是一排颜色为 R、Y、B、G、W 的球，hand 是可用的球。每步从手中取一球插到任意位置，连续至少三个同色球会消除，并反复触发连锁消除。求清空 board 最少需要插入多少球；无法清空返回 -1。

### 样例 1

```text
输入：board = "G", hand = "GGGGG"
输出：2
```

解释：插入两个 G 后得到 GGG 并消除；仅插入一个不能满足消除条件。
