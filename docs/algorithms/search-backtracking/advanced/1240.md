# 1240. 铺瓷砖

[力扣原题（完整题面）](https://leetcode.cn/problems/tiling-a-rectangle-with-the-fewest-squares/description/)

### 题意

用边长为正整数的正方形瓷砖铺满 n × m 的矩形，瓷砖不得重叠或超出边界。返回所需瓷砖的最少数量。

### 样例 1

```text
输入：n = 2, m = 3
输出：3
```

解释：用一个 2 × 2 和两个 1 × 1 正方形即可；两个正方形不能铺满该矩形。
