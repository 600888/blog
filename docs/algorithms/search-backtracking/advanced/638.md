# 638. 大礼包

[力扣原题（完整题面）](https://leetcode.cn/problems/shopping-offers/description/)

### 题意

price 是各商品单价，needs 是准确需要的数量。special 每项的前若干整数表示礼包内各商品数量，最后一项是礼包价格；礼包可以反复购买。求恰好满足 needs 的最低费用，不允许买超。

### 样例 1

```text
输入：price = [2,5], special = [[3,0,5],[1,2,10]], needs = [3,2]
输出：14
```

解释：购买价格为 10 的第二种礼包，再单买两个第一种商品花费 4，总费用为 14。
