# 126. 单词接龙 II

[力扣原题（完整题面）](https://leetcode.cn/problems/word-ladder-ii/description/)

### 题意

从 beginWord 转换到 endWord，每步只能改一个字母，修改后的单词必须在 wordList 中，起点不必在字典中。返回全部最短转换序列，以单词列表表示；无解返回空数组。

### 样例 1

```text
输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：[["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]
```

解释：最短序列包含五个单词，分别经过 dot、dog 或 lot、log。
