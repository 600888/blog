# 464. 我能赢吗

[力扣原题（完整题面）](https://leetcode.cn/problems/can-i-win/description/)

### 题意

两人轮流从 `1` 到 `maxChoosableInteger` 中选一个未用过的整数，累计所选数字；先使累计值达到或超过 `desiredTotal` 的人获胜。双方最优时，判断先手能否获胜。

### 样例 1

```text
输入：maxChoosableInteger = 10, desiredTotal = 11
输出：false
```

解释：先手选 `x` 后，后手可以选 `11-x`，立即达到目标。
