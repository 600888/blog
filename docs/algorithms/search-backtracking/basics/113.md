# 113. 路径总和 II

[力扣原题（完整题面）](https://leetcode.cn/problems/path-sum-ii/description/)

### 题意

给定二叉树 root 和整数 targetSum，返回所有从根到叶子、节点值之和等于 targetSum 的路径。答案记录节点值，顺序不限；样例中 root 用层序数组表示，null 表示空节点。

### 样例 1

```text
输入：root = [1,2,3], targetSum = 3
输出：[[1,2]]
```

解释：只有根到左侧叶子的路径满足目标和。
