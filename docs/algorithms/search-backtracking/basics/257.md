# 257. 二叉树的所有路径

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-tree-paths/description/)

### 题意

返回二叉树中所有从根到叶子的路径，以字符串形式用 -> 连接沿途节点值，答案顺序不限。样例中 root 用层序数组表示，null 表示空节点。

### 样例 1

```text
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
```

解释：树有两个叶子节点，分别为 5 和 3。
