# 112. 路径总和

[力扣原题（完整题面）](https://leetcode.cn/problems/path-sum/description/)

### 题意

给定二叉树 root 和整数 targetSum，判断是否存在从根到叶子的路径，使沿途节点值之和等于 targetSum。叶子节点没有任何子节点；样例中 root 用层序数组表示，null 表示空节点。

### 样例 1

```text
输入：root = [1,2,3], targetSum = 3
输出：true
```

解释：路径 1 → 2 以叶子节点结束，节点值之和为 3。
