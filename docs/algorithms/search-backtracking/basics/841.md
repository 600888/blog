# 841. 钥匙和房间

[力扣原题（完整题面）](https://leetcode.cn/problems/keys-and-rooms/description/)

### 题意

最初只能进入 0 号房间；rooms[i] 记录房间 i 中能获得的钥匙。进入房间后可拿走全部钥匙，判断是否能进入所有房间。

### 样例 1

```text
输入：rooms = [[1],[2],[3],[]]
输出：true
```

解释：从 0 号房间出发，依次获得进入 1、2、3 号房间的钥匙。
