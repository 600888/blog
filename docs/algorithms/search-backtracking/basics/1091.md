# 1091. 二进制矩阵中的最短路径

[力扣原题（完整题面）](https://leetcode.cn/problems/shortest-path-in-binary-matrix/description/)

### 题意

在 n × n 网格中，0 可通行，1 不可通行。允许沿八个方向移动，求左上角到右下角的最短畅通路径，长度按经过的格子数计算；无路径返回 -1。

### 样例 1

```text
输入：grid = [[0,1],[1,0]]
输出：2
```

解释：沿对角线可直接到达终点，路径包含两个格子。
