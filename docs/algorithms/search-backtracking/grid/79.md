# 79. 单词搜索

[力扣原题（完整题面）](https://leetcode.cn/problems/word-search/description/)

### 题意

在字符网格 board 中寻找 word，路径只能沿上下左右相邻格子移动，并按顺序组成单词。同一条路径中不能重复使用格子；存在路径返回 true，否则返回 false。

### 样例 1

```text
输入：board = [["A","B"],["C","D"]], word = "ABD"
输出：true
```

解释：从左上角向右再向下，依次读到 A、B、D。
