# 1219. 黄金矿工

[力扣原题（完整题面）](https://leetcode.cn/problems/path-with-maximum-gold/description/)

### 题意

grid 的正整数表示格子中的黄金量，0 表示不可进入的空格。可以从任意有黄金的格子出发，在四方向移动且不得重复进入格子，也可随时停止，求最多能收集的黄金量。

### 样例 1

```text
输入：grid = [[0,6,0],[5,8,7],[0,9,0]]
输出：24
```

解释：走过黄金量为 9 → 8 → 7 的三个格子，共收集 24。
