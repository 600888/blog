# 51. N 皇后

[力扣原题（完整题面）](https://leetcode.cn/problems/n-queens/description/)

### 题意

在 n × n 棋盘上放置 n 个皇后，使任意两个皇后不在同一行、同一列或同一斜线上。返回全部不同棋盘方案，每行用字符串表示，Q 为皇后，. 为空位。

### 样例 1

```text
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
```

解释：两个方案的皇后列号分别为 [1,3,0,2] 与 [2,0,3,1]，均不存在攻击冲突。
