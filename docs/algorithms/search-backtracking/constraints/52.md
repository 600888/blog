# 52. N 皇后 II

[力扣原题（完整题面）](https://leetcode.cn/problems/n-queens-ii/description/)

### 题意

在 n × n 棋盘上放置 n 个皇后，要求它们不同行、不同列且不在同一斜线上。返回满足要求的不同方案总数。

### 样例 1

```text
输入：n = 4
输出：2
```

解释：4 × 4 棋盘存在两个合法放置方案。
