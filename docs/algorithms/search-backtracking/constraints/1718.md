# 1718. 构建字典序最大的可行序列

[力扣原题（完整题面）](https://leetcode.cn/problems/construct-the-lexicographically-largest-valid-sequence/description/)

### 题意

构造长度为 2n - 1 的序列：1 出现一次，2 到 n 各出现两次，两个值为 i 的位置下标差恰好为 i。返回满足要求且字典序最大的序列，题目保证有解。

### 样例 1

```text
输入：n = 3
输出：[3,1,2,3,2]
```

解释：两个 3 的下标差为 3，两个 2 的下标差为 2，1 只出现一次；该合法序列字典序最大。
