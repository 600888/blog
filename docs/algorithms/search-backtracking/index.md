# 搜索与回溯专题

这份题单分为 9 类，共覆盖 60 道不同题目，按分类建立 61 个独立题目页。同题出现在图论、数据结构、动态规划或其他分类时，各自保存完整正文并使用独立链接。题目页先提供题意、样例、解释和原题链接，解题思路与代码可以逐题补充。

每类按模型和方法的学习顺序排列，不等同于力扣难度标签。第一次学习可以从[建议学习路径](./learning-path.md)开始，再从完整题单或左侧目录补齐变形。

## 搜索前先写清楚

1. 每一层选择什么：一个元素、一个位置、一个切分点，还是一次操作？
2. 状态需要哪些信息：起始下标、剩余目标、已使用元素、当前路径或剩余资源？
3. 何时收集答案，何时应立即停止当前分支？
4. 哪些修改属于当前路径，递归返回时必须怎样恢复？
5. 返回存在性、全部方案、方案数还是最优值，是否需要对重复答案去重？

| 可行性剪枝 | 剩余数量、总和、段长或约束是否还允许完成？ | [216. 组合总和 III](./combinations/216.md)、[93. 复原 IP 地址](./partitioning/93.md)、[37. 解数独](./constraints/37.md) |

| 最优值界限 | 当前状态即使继续，也无法改善已有答案吗？ | [1593. 拆分字符串使唯一子字符串的数目最大](./partitioning/1593.md)、[2305. 公平分发饼干](./advanced/2305.md)、[1240. 铺瓷砖](./advanced/1240.md) |

这些方法贯穿各分类，不单独堆成一个去重或剪枝题库。它们是否适用取决于题意和状态定义；不能为去重而丢失合法方案。
