# 1286. 字母组合迭代器

[力扣原题（完整题面）](https://leetcode.cn/problems/iterator-for-combination/description/)

### 题意

实现 CombinationIterator：构造函数接收已按升序排列且互不重复的小写字母 characters 和长度 combinationLength。next() 按字典序返回下一个固定长度组合，hasNext() 判断是否还有组合。

### 样例 1

```text
输入：操作 = ["CombinationIterator","next","hasNext","next","hasNext","next","hasNext"], 参数 = [["abc",2],[],[],[],[],[],[]]
输出：[null,"ab",true,"ac",true,"bc",false]
```

解释：长度为 2 的组合依次为 ab、ac、bc；返回 bc 后不再有下一项。
