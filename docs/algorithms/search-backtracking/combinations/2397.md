# 2397. 被列覆盖的最多行数

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-rows-covered-by-columns/description/)

### 题意

从二进制矩阵 matrix 中恰好选择 numSelect 个不同列。若一行所有值为 1 的位置都在所选列中，则该行被覆盖；全零行也算覆盖。返回最多能覆盖的行数。

### 样例 1

```text
输入：matrix = [[1,0],[0,1],[0,0]], numSelect = 1
输出：2
```

解释：选择任意一列都能覆盖对应的含 1 行以及最后的全零行。
