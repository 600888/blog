# 77. 组合

[力扣原题（完整题面）](https://leetcode.cn/problems/combinations/description/)

### 题意

从整数 1 到 n 中选出 k 个不同数字，返回所有组合。组合不区分内部顺序，答案顺序不限。

### 样例 1

```text
输入：n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

解释：从四个数中选两个，共有六种不同组合。
