# 39. 组合总和

[力扣原题（完整题面）](https://leetcode.cn/problems/combination-sum/description/)

### 题意

candidates 是互不相同的正整数，每个数字可重复使用任意多次。返回元素和等于 target 的全部不同组合，组合不区分顺序。

### 样例 1

```text
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
```

解释：2 可以选取两次，与 3 组成 7；也可以直接选取 7。
