# 40. 组合总和 II

[力扣原题（完整题面）](https://leetcode.cn/problems/combination-sum-ii/description/)

### 题意

正整数数组 candidates 可以有重复元素，但每个下标的数字在一个组合中至多使用一次。返回元素和等于 target 的全部不同组合，重复的结果只保留一份。

### 样例 1

```text
输入：candidates = [2,5,2,1,2], target = 5
输出：[[1,2,2],[5]]
```

解释：可以选取 1 和两个不同下标的 2，也可以单独选取 5；不同的 2 选择不应产生重复结果。
