# 216. 组合总和 III

[力扣原题（完整题面）](https://leetcode.cn/problems/combination-sum-iii/description/)

### 题意

从 1 到 9 中选出恰好 k 个不同数字，使它们的和为 n。返回所有不同组合，每个数字最多使用一次，答案顺序不限。

### 样例 1

```text
输入：k = 3, n = 7
输出：[[1,2,4]]
```

解释：1、2、4 是唯一满足数量与总和要求的组合。
