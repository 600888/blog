# 动态规划专题

这份题单按状态所依附的结构和转移方式分为十类，共 64 题。每道题的页面先列出题意和样例，解题思路与代码留待后续逐题补充。

## 题目分类

| 分类 | 练习重点 | 从这里开始 |
| --- | --- | --- |
| 一、线性与序列 DP | 从前面的状态转移，处理子数组、子序列和字符串 | [70. 爬楼梯](./linear/basic/70.md)、[300. 最长递增子序列](./linear/sequence/300.md) |
| 二、网格与路径 DP | 在网格或分层结构上统计路径、计算最优值 | [62. 不同路径](./grid/62.md)、[64. 最小路径和](./grid/64.md) |
| 三、背包问题 | 区分每项使用一次或多次，以及可行性、最优值、方案数 | [416. 分割等和子集](./knapsack/zero-one/416.md)、[322. 零钱兑换](./knapsack/unbounded/322.md) |
| 四、状态机 DP | 显式记录持有、卖出、冷冻等阶段 | [121. 买卖股票的最佳时机](./state-machine/121.md)、[801. 使序列递增的最小交换次数](./state-machine/801.md) |
| 五、区间与博弈 DP | 在区间内选择切分点，或分析双方最优决策 | [516. 最长回文子序列](./interval/516.md)、[486. 预测赢家](./game/486.md) |
| 六、树形 DP | 汇总子树状态，进阶到换根计算 | [337. 打家劫舍 III](./tree/337.md)、[834. 树中距离之和](./tree/834.md) |
| 七、概率 DP | 用状态表示事件发生的概率 | [688. 骑士在棋盘上的概率](./probability/688.md)、[837. 新 21 点](./probability/837.md) |
| 八、状态压缩 DP | 用二进制集合记录已选元素 | [526. 优美的排列](./bitmask/526.md)、[464. 我能赢吗](./bitmask/464.md) |
| 九、数位 DP | 按十进制数位构造符合范围与条件的整数 | [233. 数字 1 的个数](./digit/233.md)、[902. 最大为 N 的数字组合](./digit/902.md) |
| 十、DAG 上的 DP | 沿有向无环的依赖关系转移状态 | [329. 矩阵中的最长递增路径](./dag/329.md)、[2050. 并行课程 III](./dag/2050.md) |

想按由浅入深的顺序练习，可以看[建议学习路径](./learning-path.md)。完整题单也可以从左侧目录逐类展开。
