# 486. 预测赢家

[力扣原题（完整题面）](https://leetcode.cn/problems/predict-the-winner/description/)

### 题意

两名玩家轮流从数组 `nums` 的左端或右端取一个数计入自己得分，双方都采用最优策略。判断先手最终得分能否不低于后手。

### 样例 1

```text
输入：nums = [1,5,2]
输出：false
```

解释：无论先手先取 `1` 还是 `2`，后手都能取到 `5`。
