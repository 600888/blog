# 1406. 石子游戏 III

[力扣原题（完整题面）](https://leetcode.cn/problems/stone-game-iii/description/)

### 题意

两名玩家轮流从剩余石子数组 `stoneValue` 的开头取 `1`、`2` 或 `3` 个，得分为所取石子价值之和。双方最优时，返回获胜者 `"Alice"`、`"Bob"`，或平局 `"Tie"`。

### 样例 1

```text
输入：stoneValue = [1,2,3,7]
输出："Bob"
```

解释：先手无论第一轮取几个，后手都能取得更高总分。
