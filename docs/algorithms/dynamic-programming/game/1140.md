# 1140. 石子游戏 II

[力扣原题（完整题面）](https://leetcode.cn/problems/stone-game-ii/description/)

### 题意

石子排成一行，玩家轮流从剩余石子堆最前面取 `1` 到 `2M` 堆，初始 `M = 1`，每轮令 `M` 为原值与所取堆数的较大者。双方最优时，求先手能取得的最多石子数。

### 样例 1

```text
输入：piles = [2,7,9,4,4]
输出：10
```

解释：双方都采取最优策略时，先手最多得到 `10` 个石子。
