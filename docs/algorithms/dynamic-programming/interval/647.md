# 647. 回文子串

[力扣原题（完整题面）](https://leetcode.cn/problems/palindromic-substrings/description/)

### 题意

给定字符串 `s`，统计回文连续子串的数量；内容相同但起始位置不同的子串分别计数。

### 样例 1

```text
输入：s = "aaa"
输出：6
```

解释：三个单字符、两个 `"aa"` 和一个 `"aaa"` 都是回文串。
