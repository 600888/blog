# 516. 最长回文子序列

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-palindromic-subsequence/description/)

### 题意

给定字符串 `s`，求最长回文子序列的长度。可以跳过字符，但剩余字符的相对顺序不能改变。

### 样例 1

```text
输入：s = "bbbab"
输出：4
```

解释：可以选出子序列 `"bbbb"`。
