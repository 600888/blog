# 312. 戳气球

[力扣原题（完整题面）](https://leetcode.cn/problems/burst-balloons/description/)

### 题意

给定气球数值数组 `nums`，每戳破一个气球获得其当前左右相邻气球数值的乘积，边界外视为 `1`。求全部戳破后的最大硬币数。

### 样例 1

```text
输入：nums = [3,1,5,8]
输出：167
```

解释：通过选择合适的戳破顺序，最多得到 `167` 枚硬币。
