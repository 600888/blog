# 1547. 切棍子的最小成本

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-cost-to-cut-a-stick/description/)

### 题意

给定长度为 `n` 的木棍和必须切割的位置数组 `cuts`。每次切割的成本等于当前被切木棍的长度；求完成所有切割的最小总成本。

### 样例 1

```text
输入：n = 7, cuts = [1,3,4,5]
输出：16
```

解释：切割顺序会影响成本，最优顺序的总成本为 `16`。
