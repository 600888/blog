# 375. 猜数字大小 II

[力扣原题（完整题面）](https://leetcode.cn/problems/guess-number-higher-or-lower-ii/description/)

### 题意

在 `1` 到 `n` 中猜隐藏数字，每猜错一次需支付所猜数字的金额，并得知答案偏大还是偏小。求保证最终猜中所需准备的最少金额。

### 样例 1

```text
输入：n = 10
输出：16
```

解释：采用最优猜测策略，最坏情况下需要支付 `16`。
