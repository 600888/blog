# 1039. 多边形三角剖分的最低得分

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-score-triangulation-of-polygon/description/)

### 题意

给定凸多边形各顶点的数值 `values`，三角剖分中每个三角形得分为三个顶点值的乘积；求所有三角形得分之和的最小值。

### 样例 1

```text
输入：values = [1,2,3]
输出：6
```

解释：三个顶点只能组成一个三角形，得分为 `1 × 2 × 3 = 6`。
