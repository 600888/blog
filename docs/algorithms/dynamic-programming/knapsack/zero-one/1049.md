# 1049. 最后一块石头的重量 II

[力扣原题（完整题面）](https://leetcode.cn/problems/last-stone-weight-ii/description/)

### 题意

给定石头重量数组 `stones`，每次选两块石头相撞：重量相同则都消失，否则留下重量差。求最终可能剩下的最小重量，没有石头则为 `0`。

### 样例 1

```text
输入：stones = [2,7,4,1,8,1]
输出：1
```

解释：可以安排碰撞顺序，使最后一块石头重 `1`。
