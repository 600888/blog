# 879. 盈利计划

[力扣原题（完整题面）](https://leetcode.cn/problems/profitable-schemes/description/)

### 题意

有 `n` 名员工，每份工作需要 `group[i]` 人并产生 `profit[i]` 利润，同一员工不能参加两份工作。统计员工总数不超过 `n`、总利润至少为 `minProfit` 的工作选择方案数，答案对 `10^9 + 7` 取模。

### 样例 1

```text
输入：n = 5, minProfit = 3, group = [2,2], profit = [2,3]
输出：2
```

解释：可以只做第二份工作，或两份工作都做。
