# 494. 目标和

[力扣原题（完整题面）](https://leetcode.cn/problems/target-sum/description/)

### 题意

给定非负整数数组 `nums`，给每个数前添加 `+` 或 `-`，统计表达式结果恰好为 `target` 的方案数。

### 样例 1

```text
输入：nums = [1,1,1,1,1], target = 3
输出：5
```

解释：恰好给五个 `1` 中的一个添加负号，有五种下标选择。
