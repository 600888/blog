# 416. 分割等和子集

[力扣原题（完整题面）](https://leetcode.cn/problems/partition-equal-subset-sum/description/)

### 题意

给定正整数数组 `nums`，判断能否把所有元素分成两个元素和相等的子集。

### 样例 1

```text
输入：nums = [1,5,11,5]
输出：true
```

解释：可分为 `[1,5,5]` 和 `[11]`，两组和均为 `11`。
