# 474. 一和零

[力扣原题（完整题面）](https://leetcode.cn/problems/ones-and-zeroes/description/)

### 题意

给定只含 `0`、`1` 的字符串数组 `strs`，最多使用 `m` 个 `0` 和 `n` 个 `1`，求最多能选择多少个字符串；每个字符串最多选一次。

### 样例 1

```text
输入：strs = ["10","0001","111001","1","0"], m = 5, n = 3
输出：4
```

解释：可选择 `"10"`、`"0001"`、`"1"`、`"0"`。
