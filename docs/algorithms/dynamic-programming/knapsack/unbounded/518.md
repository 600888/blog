# 518. 零钱兑换 II

[力扣原题（完整题面）](https://leetcode.cn/problems/coin-change-ii/description/)

### 题意

给定金额 `amount` 和不同面额的硬币 `coins`，每种硬币可无限使用；求凑出金额的不同组合数，硬币顺序不同不另计。

### 样例 1

```text
输入：amount = 5, coins = [1,2,5]
输出：4
```

解释：四种组合是 `5`、`2+2+1`、`2+1+1+1` 和五枚 `1`。
