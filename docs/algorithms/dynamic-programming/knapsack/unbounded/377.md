# 377. 组合总和 IV

[力扣原题（完整题面）](https://leetcode.cn/problems/combination-sum-iv/description/)

### 题意

给定互不相同的正整数数组 `nums` 和整数 `target`，统计元素和等于目标值的有序序列数量；元素可重复使用，顺序不同分别计数。

### 样例 1

```text
输入：nums = [1,2,3], target = 4
输出：7
```

解释：例如 `1+3` 与 `3+1` 是两种不同序列。
