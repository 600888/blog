# 322. 零钱兑换

[力扣原题（完整题面）](https://leetcode.cn/problems/coin-change/description/)

### 题意

给定不同面额的硬币 `coins` 和金额 `amount`，每种硬币可无限使用；求凑出该金额所需的最少硬币数，无法凑出则返回 `-1`。

### 样例 1

```text
输入：coins = [1,2,5], amount = 11
输出：3
```

解释：使用两枚 `5` 和一枚 `1`。
