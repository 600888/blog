# 2328. 网格图中递增路径的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-increasing-paths-in-a-grid/description/)

### 题意

给定整数网格 `grid`，每步可移动到上下左右相邻且数值严格更大的格子。统计从任意格子出发的所有非空递增路径数量，单格路径也计入，答案对 `10^9 + 7` 取模。

### 样例 1

```text
输入：grid = [[1],[2]]
输出：3
```

解释：两条单格路径和一条 `1 → 2` 路径。
