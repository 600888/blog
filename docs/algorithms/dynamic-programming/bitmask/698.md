# 698. 划分为 k 个相等的子集

[力扣原题（完整题面）](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/description/)

### 题意

给定整数数组 `nums` 和正整数 `k`，判断能否把所有元素分成恰好 `k` 个非空子集，使每个子集的元素和相同。

### 样例 1

```text
输入：nums = [4,3,2,3,5,2,1], k = 4
输出：true
```

解释：可分成 `[5]`、`[4,1]`、`[3,2]` 和 `[3,2]`，每组和为 `5`。
