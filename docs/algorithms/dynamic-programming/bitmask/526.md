# 526. 优美的排列

[力扣原题（完整题面）](https://leetcode.cn/problems/beautiful-arrangement/description/)

### 题意

将 `1` 到 `n` 排列在下标 `1` 到 `n` 的位置上。若每个位置 `i` 都满足“第 `i` 个数能被 `i` 整除，或 `i` 能被该数整除”，求符合条件的排列数。

### 样例 1

```text
输入：n = 2
输出：2
```

解释：`[1,2]` 和 `[2,1]` 都符合要求。
