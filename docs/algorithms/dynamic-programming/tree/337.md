# 337. 打家劫舍 III

[力扣原题（完整题面）](https://leetcode.cn/problems/house-robber-iii/description/)

### 题意

给定二叉树，每个节点有金额。不能同时偷直接相连的父子节点；求能偷到的最大金额。

### 样例 1

```text
输入：root = [3,2,3,null,3,null,1]
输出：7
```

解释：可偷根节点 `3` 以及两个叶节点 `3`、`1`，共 `7`。
