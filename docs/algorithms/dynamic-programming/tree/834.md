# 834. 树中距离之和

[力扣原题（完整题面）](https://leetcode.cn/problems/sum-of-distances-in-tree/description/)

### 题意

给定 `n` 个节点和边数组 `edges` 构成的无向树，返回数组 `answer`，其中 `answer[i]` 是节点 `i` 到其他所有节点的距离之和。

### 样例 1

```text
输入：n = 2, edges = [[0,1]]
输出：[1,1]
```

解释：两个节点之间距离为 `1`。
