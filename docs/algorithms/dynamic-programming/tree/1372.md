# 1372. 二叉树中的最长交错路径

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-zigzag-path-in-a-binary-tree/description/)

### 题意

二叉树中的交错路径每走一条边都要在左、右方向间交替。给定根节点 `root`，求最长交错路径的边数。

### 样例 1

```text
输入：root = [1,null,2,3]
输出：2
```

解释：沿 `1 → 2 → 3` 依次向右、向左，共两条边。
