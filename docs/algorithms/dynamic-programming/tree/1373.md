# 1373. 二叉搜索子树的最大键值和

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-sum-bst-in-binary-tree/description/)

### 题意

给定二叉树，寻找其中节点值之和最大的二叉搜索子树，返回其节点值之和。二叉搜索树要求每个节点的左子树所有值严格小于该节点，右子树所有值严格大于该节点；如果所有节点值都为负，可返回空树的和 `0`。

### 样例 1

```text
输入：root = [2,1,3]
输出：6
```

解释：整棵树就是二叉搜索树，节点值之和为 `6`。
