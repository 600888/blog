# 968. 监控二叉树

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-tree-cameras/description/)

### 题意

在二叉树节点放置摄像头后，它可以监控自身、父节点和直接子节点。求监控整棵树所需的最少摄像头数。

### 样例 1

```text
输入：root = [0,0,null,0,0]
输出：1
```

解释：在左孩子上放一台摄像头即可覆盖全部节点。
