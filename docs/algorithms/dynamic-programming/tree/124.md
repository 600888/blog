# 124. 二叉树中的最大路径和

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-tree-maximum-path-sum/description/)

### 题意

给定二叉树，路径可从任意节点出发，沿父子边经过若干互不重复的节点并在任意节点结束；求路径节点值之和的最大值。

### 样例 1

```text
输入：root = [-10,9,20,null,null,15,7]
输出：42
```

解释：路径 `15 → 20 → 7` 的和为 `42`。
