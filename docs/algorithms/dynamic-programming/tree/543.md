# 543. 二叉树的直径

[力扣原题（完整题面）](https://leetcode.cn/problems/diameter-of-binary-tree/description/)

### 题意

给定二叉树，求任意两个节点之间最长路径的边数；路径可以不经过根节点。

### 样例 1

```text
输入：root = [1,2,3,4,5]
输出：3
```

解释：从节点 `4` 或 `5` 经 `2`、`1` 到 `3`，共三条边。
