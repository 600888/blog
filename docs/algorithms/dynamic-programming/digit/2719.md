# 2719. 统计整数数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-of-integers/description/)

### 题意

给定十进制数字字符串 `num1`、`num2` 及整数 `min_sum`、`max_sum`，统计闭区间 `[num1, num2]` 内数位和落在 `[min_sum, max_sum]` 的整数数量，答案对 `10^9 + 7` 取模。

### 样例 1

```text
输入：num1 = "1", num2 = "5", min_sum = 1, max_sum = 5
输出：5
```

解释：`1` 到 `5` 的数位和均在指定范围内。
