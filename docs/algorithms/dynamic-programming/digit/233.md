# 233. 数字 1 的个数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-digit-one/description/)

### 题意

给定非负整数 `n`，统计从 `0` 到 `n` 的所有整数中，数字 `1` 在十进制表示里出现的总次数。

### 样例 1

```text
输入：n = 13
输出：6
```

解释：`1`、`10`、`11`、`12`、`13` 中共出现六次数字 `1`。
