# 1012. 至少有 1 位重复的数字

[力扣原题（完整题面）](https://leetcode.cn/problems/numbers-with-repeated-digits/description/)

### 题意

给定正整数 `n`，统计 `1` 到 `n` 中十进制表示至少有一位数字重复的整数数量。

### 样例 1

```text
输入：n = 20
输出：1
```

解释：只有 `11` 含重复数字。
