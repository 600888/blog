# 902. 最大为 N 的数字组合

[力扣原题（完整题面）](https://leetcode.cn/problems/numbers-at-most-n-given-digit-set/description/)

### 题意

给定可用数字字符数组 `digits` 和整数 `n`，每个字符可重复使用，统计能组成多少个不含前导零且不大于 `n` 的正整数。

### 样例 1

```text
输入：digits = ["1","3","5","7"], n = 100
输出：20
```

解释：四个一位数和十六个两位数都不超过 `100`。
