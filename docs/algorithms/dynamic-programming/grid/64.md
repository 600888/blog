# 64. 最小路径和

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-path-sum/description/)

### 题意

给定非负整数网格 `grid`，从左上角到右下角，每步只能向右或向下；求路径上所有格子数字之和的最小值。

### 样例 1

```text
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
```

解释：路径 `1 → 3 → 1 → 1 → 1` 的和为 `7`。
