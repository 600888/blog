# 63. 不同路径 II

[力扣原题（完整题面）](https://leetcode.cn/problems/unique-paths-ii/description/)

### 题意

给定障碍网格 `obstacleGrid`，`1` 表示障碍，`0` 表示空地。机器人从左上角出发，只能向右或向下，求避开障碍到右下角的路径数。

### 样例 1

```text
输入：obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
输出：2
```

解释：从中间障碍的上方或下方绕行，各有一条路径。
