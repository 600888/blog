# 120. 三角形最小路径和

[力扣原题（完整题面）](https://leetcode.cn/problems/triangle/description/)

### 题意

给定数字三角形 `triangle`，从顶端走到底层，每步只能移到下一行相邻的两个位置之一；求路径数字之和的最小值。

### 样例 1

```text
输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
```

解释：路径 `2 → 3 → 5 → 1` 的和为 `11`。
