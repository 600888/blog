# 174. 地下城游戏

[力扣原题（完整题面）](https://leetcode.cn/problems/dungeon-game/description/)

### 题意

骑士从地牢左上角到右下角，每步只能向右或向下。格子数字会增加或减少生命值，生命值必须始终至少为 `1`；求出发时所需的最小生命值。

### 样例 1

```text
输入：dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]]
输出：7
```

解释：初始生命值为 `7` 时存在一条始终存活的路线。
