# 931. 下降路径最小和

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-falling-path-sum/description/)

### 题意

给定方阵 `matrix`，下降路径从首行任意格开始，每步走到下一行同列或相邻列；求到末行的最小路径和。

### 样例 1

```text
输入：matrix = [[2,1,3],[6,5,4],[7,8,9]]
输出：13
```

解释：路径 `1 → 5 → 7` 的和为 `13`。
