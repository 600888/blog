# 72. 编辑距离

[力扣原题（完整题面）](https://leetcode.cn/problems/edit-distance/description/)

### 题意

给定字符串 `word1` 和 `word2`，每次可以插入、删除或替换一个字符；求将 `word1` 变成 `word2` 的最少操作次数。

### 样例 1

```text
输入：word1 = "horse", word2 = "ros"
输出：3
```

解释：可以替换 `h`、删除一个 `r`、再删除 `e`，共三步。
