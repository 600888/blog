# 300. 最长递增子序列

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-increasing-subsequence/description/)

### 题意

给定整数数组 `nums`，求严格递增子序列的最长长度。子序列可以跳过元素，但要保持原有顺序。

### 样例 1

```text
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
```

解释：例如子序列 `[2,3,7,101]` 的长度为 `4`。
