# 1143. 最长公共子序列

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-common-subsequence/description/)

### 题意

给定字符串 `text1` 和 `text2`，求二者最长公共子序列的长度；子序列可以跳过字符，但不能改变字符顺序。

### 样例 1

```text
输入：text1 = "abcde", text2 = "ace"
输出：3
```

解释：`"ace"` 是两个字符串的公共子序列。
