# 115. 不同的子序列

[力扣原题（完整题面）](https://leetcode.cn/problems/distinct-subsequences/description/)

### 题意

给定字符串 `s` 和 `t`，统计从 `s` 中删除若干字符且不改变其余字符顺序后，得到 `t` 的不同下标选择方案数。

### 样例 1

```text
输入：s = "rabbbit", t = "rabbit"
输出：3
```

解释：从 `s` 中三个 `b` 里选两个，可形成三种不同的子序列。
