# 673. 最长递增子序列的个数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-longest-increasing-subsequence/description/)

### 题意

给定数组 `nums`，统计最长严格递增子序列的个数。下标选择不同的子序列分别计数。

### 样例 1

```text
输入：nums = [1,3,5,4,7]
输出：2
```

解释：最长长度为 `4`，对应 `[1,3,5,7]` 和 `[1,3,4,7]`。
