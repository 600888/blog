# 213. 打家劫舍 II

[力扣原题（完整题面）](https://leetcode.cn/problems/house-robber-ii/description/)

### 题意

房屋围成一圈，首尾两间也相邻。给定金额数组 `nums`，不能偷相邻房屋；求最大可偷金额。

### 样例 1

```text
输入：nums = [2,3,2]
输出：3
```

解释：首尾两间不能同时偷，选择中间房屋可获得 `3`。
