# 91. 解码方法

[力扣原题（完整题面）](https://leetcode.cn/problems/decode-ways/description/)

### 题意

数字串按 `1` 到 `26` 映射到字母 `A` 到 `Z`。给定字符串 `s`，求将整个字符串译码的不同方法数；含 `0` 时只能与有效的前一位合并。

### 样例 1

```text
输入：s = "226"
输出：3
```

解释：可分成 `2,2,6`、`22,6` 或 `2,26`。
