# 746. 使用最小花费爬楼梯

[力扣原题（完整题面）](https://leetcode.cn/problems/min-cost-climbing-stairs/description/)

### 题意

数组 `cost[i]` 表示踩上第 `i` 阶台阶的花费。每次可以向上走一阶或两阶，可从下标 `0` 或 `1` 开始；求到达楼顶的最小总花费。

### 样例 1

```text
输入：cost = [10,15,20]
输出：15
```

解释：从下标 `1` 的台阶起步，支付 `15` 后直接到楼顶。
