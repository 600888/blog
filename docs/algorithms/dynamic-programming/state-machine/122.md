# 122. 买卖股票的最佳时机 II

[力扣原题（完整题面）](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/description/)

### 题意

给定每日股价 `prices`，可以多次买卖，但同时最多持有一股；求最大总利润。

### 样例 1

```text
输入：prices = [7,1,5,3,6,4]
输出：7
```

解释：在 `1→5` 和 `3→6` 两段分别获利 `4`、`3`。
