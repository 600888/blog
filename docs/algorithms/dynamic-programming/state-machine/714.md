# 714. 买卖股票的最佳时机含手续费

[力扣原题（完整题面）](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/description/)

### 题意

给定每日股价 `prices` 和手续费 `fee`，可多次买卖但不能同时持有多股，每完成一笔交易支付一次手续费；求最大总利润。

### 样例 1

```text
输入：prices = [1,3,2,8,4,9], fee = 2
输出：8
```

解释：在 `1→8` 与 `4→9` 两笔交易中，扣除手续费后共获利 `8`。
