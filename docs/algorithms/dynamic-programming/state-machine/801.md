# 801. 使序列递增的最小交换次数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-swaps-to-make-sequences-increasing/description/)

### 题意

给定等长数组 `nums1`、`nums2`，一次操作可交换两数组同一下标的元素。求使两个数组都严格递增的最少交换次数。

### 样例 1

```text
输入：nums1 = [1,3,5,4], nums2 = [1,2,3,7]
输出：1
```

解释：交换最后一个位置的 `4` 和 `7` 后，两数组都严格递增。
