# 188. 买卖股票的最佳时机 IV

[力扣原题（完整题面）](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/description/)

### 题意

给定每日股价 `prices` 和整数 `k`，最多完成 `k` 笔买入后卖出的交易，不能同时持有多股；求最大总利润。

### 样例 1

```text
输入：k = 2, prices = [2,4,1]
输出：2
```

解释：在价格 `2` 时买入、`4` 时卖出，获利 `2`。
