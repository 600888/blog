# 309. 买卖股票的最佳时机含冷冻期

[力扣原题（完整题面）](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/)

### 题意

给定每日股价 `prices`，可以多次买卖且不能同时持有多股；卖出后的第二天不能买入。求最大总利润。

### 样例 1

```text
输入：prices = [1,2,3,0,2]
输出：3
```

解释：第一、二天交易获利 `1`，冷冻一天后再在 `0→2` 获利 `2`。
