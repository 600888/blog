# 121. 买卖股票的最佳时机

[力扣原题（完整题面）](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/)

### 题意

给定每日股价 `prices`，最多进行一次买入和之后的卖出，求最大利润；可以不交易。

### 样例 1

```text
输入：prices = [7,1,5,3,6,4]
输出：5
```

解释：价格为 `1` 时买入、`6` 时卖出，利润为 `5`。
