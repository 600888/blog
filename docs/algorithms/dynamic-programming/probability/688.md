# 688. 骑士在棋盘上的概率

[力扣原题（完整题面）](https://leetcode.cn/problems/knight-probability-in-chessboard/description/)

### 题意

棋盘大小为 `n × n`，骑士从 `(row, column)` 出发，每步等概率选择八种走法之一。求走完 `k` 步后仍在棋盘内的概率。

### 样例 1

```text
输入：n = 3, k = 2, row = 0, column = 0
输出：0.0625
```

解释：两步均留在棋盘内的概率为 `4 / 64`。
