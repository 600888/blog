# 837. 新 21 点

[力扣原题（完整题面）](https://leetcode.cn/problems/new-21-game/description/)

### 题意

玩家从 `0` 分开始，分数低于 `k` 时每次等概率抽取 `1` 到 `maxPts` 分并累加，达到至少 `k` 分后停止。求最终得分不超过 `n` 的概率。

### 样例 1

```text
输入：n = 6, k = 1, maxPts = 10
输出：0.6
```

解释：只抽一次时，十种结果中有六种不超过 `6`。
