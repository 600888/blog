# 808. 分汤

[力扣原题（完整题面）](https://leetcode.cn/problems/soup-servings/description/)

### 题意

两种汤 A、B 各有 `n` 毫升，每轮等概率选择以下四种操作之一：

1. 取走 A 的 `100` 毫升、B 的 `0` 毫升；
2. 取走 A 的 `75` 毫升、B 的 `25` 毫升；
3. 取走 A 的 `50` 毫升、B 的 `50` 毫升；
4. 取走 A 的 `25` 毫升、B 的 `75` 毫升。

取走的量超过剩余量时，该汤视为取完；一旦任一汤取完就停止。返回“A 先取完”的概率加上“两者同时取完”概率的一半。

### 样例 1

```text
输入：n = 50
输出：0.625
```

解释：四种等概率操作的贡献分别为 `1`、`1`、`0.5`、`0`，平均为 `0.625`。
