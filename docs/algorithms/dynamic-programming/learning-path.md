# 动态规划建议学习路径

题目页目前提供题意、样例和原题链接。做题时可以先写清楚“状态表示什么”，再确定转移来源、初始条件和遍历顺序。

## 1. 建立一维状态

1. [70. 爬楼梯](./linear/basic/70.md) → [746. 使用最小花费爬楼梯](./linear/basic/746.md)：练习从前一两步转移。
2. [198. 打家劫舍](./linear/basic/198.md) → [213. 打家劫舍 II](./linear/basic/213.md)：练习选或不选，以及环形边界。
3. [53. 最大子数组和](./linear/basic/53.md) → [152. 乘积最大子数组](./linear/basic/152.md)：练习以当前位置结尾的最优状态。
4. [91. 解码方法](./linear/basic/91.md)：练习方案计数和无效状态。

## 2. 从网格走向双序列

1. [62. 不同路径](./grid/62.md) → [63. 不同路径 II](./grid/63.md) → [64. 最小路径和](./grid/64.md)：在相同网格上分别处理计数与最小值。
2. [120. 三角形最小路径和](./grid/120.md) → [931. 下降路径最小和](./grid/931.md) → [174. 地下城游戏](./grid/174.md)：练习不同方向的状态转移。
3. [300. 最长递增子序列](./linear/sequence/300.md) → [673. 最长递增子序列的个数](./linear/sequence/673.md)：从最优长度过渡到最优方案数。
4. [1143. 最长公共子序列](./linear/sequence/1143.md) → [72. 编辑距离](./linear/sequence/72.md) → [115. 不同的子序列](./linear/sequence/115.md)：练习双字符串状态。

## 3. 背包与状态机

1. [416. 分割等和子集](./knapsack/zero-one/416.md) → [494. 目标和](./knapsack/zero-one/494.md) → [474. 一和零](./knapsack/zero-one/474.md)：依次练习可行性、方案数和双容量。
2. [322. 零钱兑换](./knapsack/unbounded/322.md) → [518. 零钱兑换 II](./knapsack/unbounded/518.md) → [377. 组合总和 IV](./knapsack/unbounded/377.md)：比较最少数量、无序组合与有序序列。
3. [121. 买卖股票的最佳时机](./state-machine/121.md) → [122. 买卖股票的最佳时机 II](./state-machine/122.md) → [309. 买卖股票的最佳时机含冷冻期](./state-machine/309.md)：逐步增加交易状态。

## 4. 区间、树与高阶状态

1. [516. 最长回文子序列](./interval/516.md) → [312. 戳气球](./interval/312.md) → [486. 预测赢家](./game/486.md)：从短区间推到长区间。
2. [337. 打家劫舍 III](./tree/337.md) → [968. 监控二叉树](./tree/968.md) → [834. 树中距离之和](./tree/834.md)：从子树汇总进阶到换根。
3. [688. 骑士在棋盘上的概率](./probability/688.md) → [808. 分汤](./probability/808.md) → [837. 新 21 点](./probability/837.md)：练习概率状态和边界条件。
4. [526. 优美的排列](./bitmask/526.md) → [233. 数字 1 的个数](./digit/233.md) → [329. 矩阵中的最长递增路径](./dag/329.md)：分别接触集合、数位和 DAG 上的状态设计。

其余题目可以在完成对应分类的入门题后，从左侧目录继续练习。
