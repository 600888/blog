# 滑动窗口题单

这份题单分为 7 类，共覆盖 63 道不同题目，按分类建立 65 个独立题目页。209. 长度最小的子数组与 1248. 统计「优美子数组」在不同分类下各有一页，各自保存完整正文并使用独立链接。题目页提供题意、样例、解题思路和原题链接。

分类大体按定长、不定长（求最长与求最短）、计数、字符串匹配、数据结构维护的顺序排列，顺序是学习组织方式，不等同于力扣难度标签。第一次学习可以从[建议学习路径](./learning-path.md)出发，完整题目也可从左侧目录逐类展开。

## 做题前先确认

1. 窗口长度是固定值 `k`，还是随约束变化的不定长？
2. 窗口内维护的状态是和、乘积、频次、元素种数，还是最值？
3. 要求最长、最短，还是统计合法窗口的个数？
4. 计数问题中，窗口"越长越合法"还是"越短越合法"，能否用"至多"相减求"恰好"？
5. 左端收缩的触发条件是什么，收缩到什么时候停止？
6. 元素有负数或 0 时，"和越大越单调"的结论还成立吗？

## 自查

1. 能说清窗口扩到什么时候合法、收缩到什么时候停止，每轮状态如何增量更新。
2. 定长与不定长的循环写法不同：定长"先进后出"，不定长"先扩张再收缩"。
3. 计数题能判断以左端点还是右端点计数，并用"至多"相减处理"恰好"。
4. 含负数时不再使用普通滑动窗口，改用前缀和哈希或单调队列。
5. 窗口最值问题能写出单调队列的进出队条件，并说明队头为什么就是答案。
