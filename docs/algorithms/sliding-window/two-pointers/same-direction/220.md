# 220. 存在重复元素 III

[力扣原题（完整题面）](https://leetcode.cn/problems/contains-duplicate-iii/description/)

### 题意

给定数组 `nums`、整数 `indexDiff` 和 `valueDiff`，判断是否存在不同下标 `i`、`j`，使下标差不超过 `indexDiff`，且元素值之差的绝对值不超过 `valueDiff`。

### 样例 1

```text
输入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0
输出：true
```

解释：下标 `0` 和 `3` 的元素值相同，两项限制都满足。
