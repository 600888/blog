# 219. 存在重复元素 II

[力扣原题（完整题面）](https://leetcode.cn/problems/contains-duplicate-ii/description/)

### 题意

给定整数数组 `nums` 和整数 `k`，判断是否存在两个不同下标 `i`、`j`，使 `nums[i] = nums[j]` 且下标距离不超过 `k`。

### 样例 1

```text
输入：nums = [1,2,3,1], k = 3
输出：true
```

解释：下标 `0` 和 `3` 的元素相同，距离为 `3`。
