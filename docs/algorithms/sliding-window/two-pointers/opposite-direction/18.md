# 18. 四数之和

[力扣原题（完整题面）](https://leetcode.cn/problems/4sum/description/)

### 题意

给定整数数组 `nums` 和目标值 `target`，找出所有和为 `target` 的四元组，四元组须使用四个不同下标；答案中不能有重复的数值组合，顺序不限。

### 样例 1

```text
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

解释：列出的三组四元组之和都为 `0`。
