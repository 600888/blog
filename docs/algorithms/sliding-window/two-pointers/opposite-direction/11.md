# 11. 盛最多水的容器

[力扣原题（完整题面）](https://leetcode.cn/problems/container-with-most-water/description/)

### 题意

给定各位置的竖线高度 `height`，选两条竖线与横轴构成容器。水量等于两线间距乘以较短线高度；求最大水量。

### 样例 1

```text
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
```

解释：下标 `1` 和 `8` 的竖线围成的面积为 `7 × 7 = 49`。
