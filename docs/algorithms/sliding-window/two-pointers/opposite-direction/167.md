# 167. 两数之和 II - 输入有序数组

[力扣原题（完整题面）](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/description/)

### 题意

给定按非递减顺序排列的数组 `numbers` 和目标值 `target`，找出和为目标值的两个不同元素，返回它们从 `1` 开始计数的下标。

### 样例 1

```text
输入：numbers = [2,7,11,15], target = 9
输出：[1,2]
```

解释：`numbers[0] + numbers[1] = 2 + 7 = 9`。
