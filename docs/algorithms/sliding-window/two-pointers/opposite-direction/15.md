# 15. 三数之和

[力扣原题（完整题面）](https://leetcode.cn/problems/3sum/description/)

### 题意

给定整数数组 `nums`，找出所有和为 `0` 的三元组，三元组须使用三个不同下标；答案中不能有重复的数值组合，顺序不限。

### 样例 1

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

解释：这两组三个数的和均为 `0`。
