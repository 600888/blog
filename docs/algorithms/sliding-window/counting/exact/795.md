# 795. 区间子数组个数

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-subarrays-with-bounded-maximum/description/)

### 题意

给定数组 `nums` 和两个整数 `left`、`right`，统计最大元素落在闭区间 `[left, right]` 内的非空连续子数组数量。

### 样例 1

```text
输入：nums = [2,1,4,3], left = 2, right = 3
输出：3
```

解释：满足条件的是 `[2]`、`[2,1]` 和 `[3]`。
