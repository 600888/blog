# 992. K 个不同整数的子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/subarrays-with-k-different-integers/description/)

### 题意

给定数组 `nums` 和整数 `k`，统计恰好包含 `k` 种不同整数的非空连续子数组数量。

### 样例 1

```text
输入：nums = [1,2,1,2,3], k = 2
输出：7
```

解释：例如 `[1,2,1]` 恰好包含两种整数。
