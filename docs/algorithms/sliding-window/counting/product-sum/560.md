# 560. 和为 K 的子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/subarray-sum-equals-k/description/)

### 题意

给定整数数组 `nums` 和整数 `k`，统计元素和恰好等于 `k` 的非空连续子数组数量。数组可以包含负数。

### 样例 1

```text
输入：nums = [1,1,1], k = 2
输出：2
```

解释：两个相邻元素组成的子数组各有一个。
