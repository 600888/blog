# 713. 子数组乘积小于 K

[力扣原题（完整题面）](https://leetcode.cn/problems/subarray-product-less-than-k/description/)

### 题意

给定正整数数组 `nums` 和整数 `k`，统计元素乘积严格小于 `k` 的非空连续子数组数量。

### 样例 1

```text
输入：nums = [10,5,2,6], k = 100
输出：8
```

解释：例如 `[10,5]` 的乘积为 `50`，而 `[10,5,2]` 的乘积等于 `100`，不计入。

### 样例 2

```text
输入：nums = [1,2,3], k = 0
输出：0
```

解释：所有元素都是正整数，乘积至少为 `1`，不可能严格小于 `0`。

### 解题思路

不定长滑动窗口的计数问题。核心观察：**数组元素全为正整数**，所以窗口越往右扩，乘积只会不变或变大；越往左缩，乘积只会不变或变小。这个单调性保证了每个元素进入、离开窗口各一次，整体 `O(n)`。

做法：

1. 右端点 `r` 逐个向右，把 `nums[r]` 乘进窗口乘积 `mul`。
2. 如果 `mul >= k`，收缩左端点 `l`，直到窗口乘积重新小于 `k`。
3. 收缩结束后，`[l, r]` 是以 `r` 结尾的**最长**合法窗口。以 `r` 结尾的合法子数组个数就是 `r - l + 1`（左端点可以是 `l, l+1, ..., r` 中的任意一个），全部累加到答案。

这里有个容易忽略的边界：`k <= 1` 时答案为 0（正整数乘积至少为 1）。代码里收缩条件写成 `mul >= k && l < r`，即收缩到**只剩单个元素**就停手，不再把最后一个元素也除掉——否则乘积会变成 0，状态被破坏；之后靠 `if (mul < k)` 判断，单个元素也不满足时就不计数，`k <= 1` 的情况自然被跳过。

### 我的代码

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        int l = 0, r = 0;
        int n = nums.size();
        int mul = 1;   // 当前窗口 [l, r] 内所有元素的乘积
        int cnt = 0;   // 答案：乘积严格小于 k 的子数组个数
        for (r = 0; r < n; ++r) {
            mul *= nums[r];  // 右端点入窗
            // 乘积超过 k 就收缩左端点；l < r 保证至少保留一个元素，
            // 避免把窗口清空后 mul 被除成 0（同时覆盖 k <= 1 的情况）
            while (mul >= k && l < r) {
                mul /= nums[l];
                l++;
            }
            // 此时 [l, r] 是以 r 结尾的最长合法窗口，
            // 以 r 结尾的合法子数组共有 r - l + 1 个：
            // [l..r], [l+1..r], ..., [r..r]
            if (mul < k) cnt += r - l + 1;
        }
        return cnt;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 都只单向前进，每个元素至多进出窗口各一次。空间复杂度 `O(1)`。

为什么能用 `cnt += r - l + 1` 一次累加而不重复统计？因为每轮固定的是**子数组右端点** `r`，不同轮次的子数组结尾不同，天然不重不漏。
