# 1248. 统计「优美子数组」

[力扣原题（完整题面）](https://leetcode.cn/problems/count-number-of-nice-subarrays/description/)

### 题意

给定数组 `nums` 和整数 `k`，统计恰好包含 `k` 个奇数的非空连续子数组数量。

### 样例 1

```text
输入：nums = [1,1,2,1,1], k = 3
输出：2
```

解释：符合要求的是前四个元素和后四个元素构成的两个子数组。

### 样例 2

```text
输入：nums = [2,4,6], k = 1
输出：0
```

解释：数组里没有奇数，不存在包含 1 个奇数的子数组。

### 解题思路

「恰好包含 k 个奇数」不好直接用窗口维护（窗口右移时奇数个数可能不变，无法判断该不该计数），所以做一个转化：

**恰好 k = 大于等于 k − 大于 k**

「奇数个数大于等于 k」是单调的：窗口越往左扩，奇数只多不少。固定右端点 `r`，用一个左指针把窗口内奇数个数收缩到 `k-1` 以内，此时左端点落在收缩线左边的子数组 `[l, r]` 全部满足「≥ k 个奇数」，个数恰好等于收缩后的左指针位置。同理再用一个左指针统计「> k 个奇数」的部分，两者相减就是「恰好 k」。

代码里用两个独立的左指针：

- `left1` 的收缩条件是 `sum1 >= k`。收缩结束后 `[left1, r]` 内奇数数 `<= k-1`，于是左端点为 `0, 1, ..., left1-1` 的子数组 `[l, r]` 都有 `>= k` 个奇数，共 `left1` 个；
- `left2` 的收缩条件是 `sum2 > k`。收缩结束后 `[left2, r]` 内奇数数 `<= k`，于是左端点为 `0, 1, ..., left2-1` 的子数组 `[l, r]` 都有 `> k` 个奇数，共 `left2` 个。

每轮 `ans += left1; ans -= left2`，累加的就是以 `r` 结尾、恰好 k 个奇数的子数组个数。两个左指针都只单向前进，互不影响。

### 我的代码

```cpp
class Solution {
public:
    int numberOfSubarrays(vector<int>& nums, int k) {
        int left1 = 0, left2 = 0, r = 0;
        int n = nums.size();
        int ans = 0, sum1 = 0, sum2 = 0;  // sum1/sum2：两个窗口内各自的奇数个数
        for (r = 0; r < n; ++r) {
            // 右端点入窗，是奇数就计数
            if (nums[r] % 2 != 0) {
                sum1++;
                sum2++;
            }
            // left1：把窗口收缩到奇数数 <= k-1
            // 左端点在 left1 左侧的子数组 [l, r] 都有 >= k 个奇数，共 left1 个
            while (sum1 >= k) {
                if (nums[left1] % 2 != 0) sum1--;
                left1++;
            }
            // left2：把窗口收缩到奇数数 <= k
            // 左端点在 left2 左侧的子数组 [l, r] 都有 > k 个奇数，共 left2 个
            while (sum2 > k) {
                if (nums[left2] % 2 != 0) sum2--;
                left2++;
            }
            // 恰好 k = (>= k 的个数) - (> k 的个数) = left1 - left2
            ans += left1;
            ans -= left2;
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`r` 走一遍，`left1`、`left2` 各自单向前进，最多各走 `n` 步。空间复杂度 `O(1)`。

对比 713：那题是「乘积小于 k」本身就有单调性，一个窗口直接计数；这题「恰好 k」没有可直接累计的单调性，需要拆成「≥ k」减「> k」两笔账，用双左指针分别统计。
