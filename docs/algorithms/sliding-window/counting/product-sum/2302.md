# 2302. 统计得分小于 K 的子数组数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-subarrays-with-score-less-than-k/description/)

### 题意

非空子数组的得分等于“元素和 × 子数组长度”。给定正整数数组 `nums` 和整数 `k`，统计得分严格小于 `k` 的连续子数组数量。

### 样例 1

```text
输入：nums = [2,1,4,3,5], k = 10
输出：6
```

解释：符合要求的单元素子数组有 `5` 个，另有 `[2,1]`。
