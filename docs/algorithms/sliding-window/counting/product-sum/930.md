# 930. 二进制子数组的和

[力扣原题（完整题面）](https://leetcode.cn/problems/binary-subarrays-with-sum/description/)

### 题意

给定二进制数组 `nums` 和整数 `goal`，统计元素和恰好等于 `goal` 的非空连续子数组数量。

### 样例 1

```text
输入：nums = [1,0,1,0,1], goal = 2
输出：4
```

解释：四个不同位置的连续子数组之和为 `2`。

### 样例 2

```text
输入：nums = [0,0,0,0,0], goal = 0
输出：15
```

解释：任意非空子数组的和都是 `0`，共 `5 × 6 / 2 = 15` 个。

### 解题思路

设 `sum` 为扫到下标 `i` 时的前缀和，区间 `[j+1, i]` 的元素和为 `sum - prefix(j)`。它等于 `goal` 当且仅当 `prefix(j) = sum - goal`。于是用哈希表 `mp` 记录每个前缀和出现的次数：每扫到一个位置，先查 `sum - goal` 出现过多少次并累加进答案，再把当前前缀和 `sum` 登记进表。

`mp[0] = 1` 代表空前缀，处理"从下标 `0` 开始的子数组"。

**顺序是关键**：必须先累加答案、再执行 `mp[sum]++`。反过来写时，若 `goal = 0`，当前前缀和会先把自己配对进去，把空区间也计入答案。

本题元素只有 `0/1`，也可以用"至多 `goal` 减至多 `goal - 1`"的滑动窗口求解（见分类页的"恰好 K 与至多 K"）；前缀和哈希的好处是对含负数的数组同样成立，与 560. 和为 K 的子数组是同一套模板。另外 `map` 可以换成 `unordered_map`，均摊 `O(1)`；`find` 之后再用 `[]` 取值是两次查找，用迭代器一次取出也可以，属于微优化。

### 我的代码

```cpp
class Solution {
public:
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        int sum = 0;                 // 当前前缀和 nums[0..i]
        map<int, int> mp;            // 每个前缀和出现的次数
        int ans = 0;
        mp[0] = 1;                   // 空前缀，处理从下标 0 开始的子数组
        for (int i = 0; i < nums.size(); ++i) {
            sum += nums[i];
            if (mp.find(sum - goal) != mp.end())  // 以 i 结尾、和为 goal 的子数组个数
                ans += mp[sum - goal];
            mp[sum]++;               // 先累加答案，再登记当前前缀和
        }
        return ans;
    }
};
```

时间复杂度 `O(n log n)`（`map` 操作 `O(log n)`，换 `unordered_map` 为均摊 `O(n)`）；空间复杂度 `O(n)`，哈希表最多存 `n` 个不同前缀和。
