# 2444. 统计定界子数组的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-subarrays-with-fixed-bounds/description/)

### 题意

给定数组 `nums` 和整数 `minK`、`maxK`，统计最小值恰好为 `minK` 且最大值恰好为 `maxK` 的非空连续子数组数量。

### 样例 1

```text
输入：nums = [1,3,5,2,7,5], minK = 1, maxK = 5
输出：2
```

解释：符合要求的是 `[1,3,5]` 和 `[1,3,5,2]`。
