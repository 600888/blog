# 2537. 统计好子数组的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-the-number-of-good-subarrays/description/)

### 题意

一个子数组中，若满足 `i < j` 且 `nums[i] = nums[j]` 的下标对至少有 `k` 个，就称它为好子数组。统计好子数组的数量。

### 样例 1

```text
输入：nums = [1,1,1,1,1], k = 3
输出：6
```

解释：任意长度至少为 `3` 的子数组都符合要求，共有 `3 + 2 + 1 = 6` 个。
