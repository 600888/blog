# 1759. 统计同构子字符串的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-number-of-homogenous-substrings/description/)

### 题意

同构子串指所有字符都相同的非空连续子串。统计字符串 `s` 中同构子串的数量，相同内容但位置不同的子串分别计数；答案对 `10^9 + 7` 取模。

### 样例 1

```text
输入：s = "abbcccaa"
输出：13
```

解释：四段相同字符分别贡献 `1`、`3`、`6`、`3` 个子串。
