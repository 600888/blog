# 2799. 统计完全子数组的数目

[力扣原题（完整题面）](https://leetcode.cn/problems/count-complete-subarrays-in-an-array/description/)

### 题意

如果一个连续子数组包含了整个 `nums` 中出现过的所有不同整数，就称它为完全子数组。统计完全子数组的数量。

### 样例 1

```text
输入：nums = [1,3,1,2,2]
输出：4
```

解释：整个数组包含 `1`、`2`、`3` 三种整数，符合要求的子数组有 `4` 个。
