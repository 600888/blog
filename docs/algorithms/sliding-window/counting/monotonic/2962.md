# 2962. 统计最大元素出现至少 K 次的子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/count-subarrays-where-max-element-appears-at-least-k-times/description/)

### 题意

先找出整个数组 `nums` 的最大值，再统计该最大值在其中至少出现 `k` 次的非空连续子数组数量。

### 样例 1

```text
输入：nums = [1,3,2,3,3], k = 2
输出：6
```

解释：全局最大值为 `3`，共有 `6` 个子数组至少包含两个 `3`。
