# 1358. 包含所有三种字符的子字符串数目

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-substrings-containing-all-three-characters/description/)

### 题意

给定只由 `a`、`b`、`c` 组成的字符串 `s`，统计同时包含这三种字符的连续子串数量。

### 样例 1

```text
输入：s = "abcabc"
输出：10
```

解释：例如 `"abc"`、`"abca"` 和 `"bca"` 都符合要求。
