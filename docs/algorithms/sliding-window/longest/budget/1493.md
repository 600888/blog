# 1493. 删掉一个元素以后全为 1 的最长子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/description/)

### 题意

给定二进制数组 `nums`，必须删除恰好一个元素，求删除后剩余数组中最长的连续 `1` 的长度。

### 样例 1

```text
输入：nums = [1,1,0,1]
输出：3
```

解释：删掉中间的 `0` 后，三个 `1` 连在一起。

### 解题思路

「删除恰好一个元素后全为 `1`」等价于「找一个最长子数组，其中 `0` 的个数**不超过 1**」，答案再减去被删掉的那一个元素。这正好是 [1004. 最大连续 1 的个数 III](/algorithms/sliding-window/longest/budget/1004) 取 `k = 1` 的版本，直接套不定长滑动窗口（求最长）模板：

- 右指针 `r` 一直向右扩张，遇到 `0` 就让计数器 `mp[0]++`；
- 当窗口内 `0` 的个数超过 `1`（`mp[0] > 1`）时不合法，左指针 `l` 右移收缩，移出 `0` 时计数减一，直到重新满足 `mp[0] <= 1`；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

最后返回 `ans - 1`，对应「必须删除恰好一个元素」：

- 若窗口里确实含一个 `0`，删掉它，剩余长度为窗口长度减一；
- 若整个数组全是 `1`（比如 `[1,1,1]`），也必须删掉一个 `1`，答案同样是窗口长度减一。

所以无论哪种情况 `ans - 1` 都是对的，不需要对全 `1` 数组特判。这也是本题和 1004 在实现上唯一的区别：1004 允许"最多"翻转 `k` 个、可以一个都不翻，直接返回 `ans`；本题是"恰好"删一个，要减一。

### 我的代码

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int l = 0, r = 0;
        int n = nums.size();
        int ans = 0;
        unordered_map<int, int> mp;
        for (r = 0; r < n; ++r) {
            if (nums[r] == 0) mp[0]++;
            while (mp[0] > 1) {
                if (nums[l] == 0) mp[0]--;  // 如果左侧元素为0，计数-1
                l++;  // 移动左指针
            }
            ans = max(ans, r - l + 1);
        }
        return ans - 1;  // 必须删除恰好一个元素
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次，均摊 `O(1)`。空间复杂度 `O(1)`：哈希表最多只有键 `0` 一个条目（本题只有 `0/1`，换成 `int zeroCount` 更直接；保留哈希表是为了贴近通用模板，与 1004 的写法保持一致）。

两个细节：

- 收缩条件是 `mp[0] > 1` 而不是 `> 0`：允许窗口内保留一个 `0`，它就是将来要删掉的那个元素，这样 `1,1,0,1` 这类跨越 `0` 的连续段才能被统计到；
- `return ans - 1` 同时处理了"没有 `0` 可删"的边界——全 `1` 数组窗口长度为 `n`，减一后正好是 `n - 1`，无需额外判断。
