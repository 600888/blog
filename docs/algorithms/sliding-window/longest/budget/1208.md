# 1208. 尽可能使字符串相等

[力扣原题（完整题面）](https://leetcode.cn/problems/get-equal-substrings-within-budget/description/)

### 题意

给定等长字符串 `s`、`t` 和预算 `maxCost`，把 `s[i]` 改成 `t[i]` 的花费是两个字符编码之差的绝对值。求总花费不超过预算的最长对应连续子串长度。

### 样例 1

```text
输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3
```

解释：前三个位置各花费 `1`，可以一起转换。

### 解题思路

先做一步转化：把每个位置的变换消耗 `costs[i] = |s[i] - t[i]|` 预处理成数组，问题就变成了「求元素和不超过 `maxCost` 的最长子数组」——和 [1004. 最大连续 1 的个数 III](/algorithms/sliding-window/longest/budget/1004) 是同一个"预算内求最长窗口"的模板，只是把"窗口内 `0` 的个数"换成了"窗口内消耗之和"：

- 右指针 `r` 一直向右扩张，`sum += costs[r]` 累加消耗；
- 当总花费超预算（`sum > maxCost`）时不合法，左指针 `l` 右移收缩，`sum -= costs[l]`，直到重新满足 `sum <= maxCost`；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

由于 `l` 只会前进不会回退，且每轮结束窗口一定合法，答案就是所有合法窗口长度的最大值。本题没有 1493 那样的"恰好减一"问题——"尽可能使相等"允许一个都不转，直接返回 `ans` 即可。

### 我的代码

```cpp
class Solution {
public:
    int equalSubstring(string s, string t, int maxCost) {
        int len = s.size();
        int sum = 0;
        int l = 0, r = 0;
        // 求最长连续子串和问题的变种
        // 先把变换每个位置的消耗记录到一个数组中
        vector<int> costs;
        for (int i = 0; i < len; ++i) {
            int a = s[i] - 'a';
            int b = t[i] - 'a';
            int curCost = abs(a - b);  // 变换当前字符的消耗值
            costs.push_back(curCost);
        }
        int ans = 0;
        for (r = 0; r < len; ++r) {
            sum += costs[r];
            while (sum > maxCost) {
                sum -= costs[l];
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：预处理一遍，`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(n)`：`costs` 数组占 `O(n)`。

可以优化到 `O(1)` 空间：收缩时 `s[l]`、`t[l]` 仍然可以直接按下标访问，所以完全不必要先存数组，进入时算一次 `abs(s[r] - t[r])` 加进 `sum`、收缩时同样现算减掉即可。这里保留预处理写法，是把"转化成消耗数组"这一步显式写出来，思路更清晰——先识别出它是「子数组和 ≤ 预算」这一类问题，再套窗口模板。
