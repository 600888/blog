# 2024. 考试的最大困扰度

[力扣原题（完整题面）](https://leetcode.cn/problems/maximize-the-confusion-of-an-exam/description/)

### 题意

给定只含 `T` 和 `F` 的答题串 `answerKey`，最多修改 `k` 个字符，求修改后连续相同答案的最大长度。

### 样例 1

```text
输入：answerKey = "TTFF", k = 2
输出：4
```

解释：将两个 `F` 都改成 `T`，四个答案就相同了。
