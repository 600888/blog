# 2024. 考试的最大困扰度

[力扣原题（完整题面）](https://leetcode.cn/problems/maximize-the-confusion-of-an-exam/description/)

### 题意

给定只含 `T` 和 `F` 的答题串 `answerKey`，最多修改 `k` 个字符，求修改后连续相同答案的最大长度。

### 样例 1

```text
输入：answerKey = "TTFF", k = 2
输出：4
```

解释：将两个 `F` 都改成 `T`，四个答案就相同了。

### 解题思路

最终全部相同的答案有两种可能：全 `T` 或全 `F`，两者互相独立，可以各求一遍取最大值。

以「全 `T`」为目标：等价于「子串中 `F` 的个数不超过 `k`」（`F` 就是要被改掉的那些）。以「全 `F`」为目标同理：等价于「子串中 `T` 的个数不超过 `k`」。两个方向都是 [1004. 最大连续 1 的个数 III](/algorithms/sliding-window/longest/budget/1004) 的预算窗口模板：

- 右指针 `r` 扩张，对应字符计数 `+1`；
- 窗口内"异类"字符数超预算时，左指针 `l` 右移收缩，移出异类时计数减一；
- 每轮合法后用 `r - l + 1` 更新答案。

跑两遍（一遍限制 `F`、一遍限制 `T`），答案取两次的最大值。注意方向别搞混：**收缩条件限制的是"异类"**——想得到最长全 `T`，窗口里要限制的是 `F` 的数量，而不是 `T`。

### 我的代码

```cpp
class Solution {
public:
    int maxConsecutiveAnswers(string answerKey, int k) {
        // 求两遍滑动窗口，两者取最大值
        int l = 0, r = 0;
        unordered_map<int, int> mp;
        int ans = 0;
        // 第一遍：限制窗口内 T 的个数，求最长连续 F
        for (r = 0; r < answerKey.size(); ++r) {
            int x = answerKey[r];
            mp[x]++;
            while (mp['T'] > k) {
                if (answerKey[l] == 'T') mp['T']--;
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        // 第二遍：限制窗口内 F 的个数，求最长连续 T
        l = 0, r = 0;
        mp.clear();
        for (r = 0; r < answerKey.size(); ++r) {
            int x = answerKey[r];
            mp[x]++;
            while (mp['F'] > k) {
                if (answerKey[l] == 'F') mp['F']--;
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：两遍扫描，`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(1)`：哈希表最多只有 `'T'`、`'F'` 两个键。

几个细节：

- 第二遍开始前要 `l = 0, r = 0` 并 `mp.clear()` 重置窗口状态，否则第一遍的计数会污染第二遍的判断；
- `mp` 声明为 `unordered_map<int, int>`，键实际是字符 `'T'`/`'F'`（隐式转成 int），能正常工作；直接用 `unordered_map<char, int>` 或者两个 `int` 计数变量会更直白；
- 两遍扫描除了限制的字符和判断条件不同，其余完全一样，也可以抽成一个 `helper(answerKey, k, target)` 函数避免重复。
