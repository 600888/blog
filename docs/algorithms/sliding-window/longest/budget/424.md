# 424. 替换后的最长重复字符

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-repeating-character-replacement/description/)

### 题意

给定大写字母字符串 `s`，最多替换 `k` 个字符，求替换后由同一字符组成的最长连续子串长度。

### 样例 1

```text
输入：s = "AABABBA", k = 1
输出：4
```

解释：例如把 `"AABA"` 中的 `B` 改为 `A`，得到长度为 `4` 的重复字符段。

### 解题思路

「最多替换 `k` 个字符」等价于「窗口内出现次数最多的字符以外的其他字符总数不超过 `k`」，即窗口长度 `r - l + 1` 减去窗口内最大出现次数 `maxn` 不超过 `k`。求满足条件的最长子串，是不定长滑动窗口（求最长）：

- 右指针 `r` 一直向右扩张，用计数表 `cnt` 维护窗口内每种字符的出现次数，并顺手用 `cnt[s[r]]` 更新历史最大出现次数 `maxn`；
- 当 `r - l + 1 - maxn > k` 时窗口不合法，左指针 `l` 右移一步（移出 `s[l]` 时计数减一）；
- 每轮用 `r - l + 1` 更新答案。

与 1004 题相比有两个不同的写法细节：

- **收缩用 `if` 而不是 `while`**：每轮窗口只扩张 1 个字符，不合法时"超支"最多为 1，右移一次 `l` 就能恢复合法，不需要 `while`；
- **`maxn` 在左移时不回退（允许偏大）**：这是本题最经典的优化。`maxn` 只增不减，记录的是历史最大频次，而非当前窗口的真实最大频次。这不会影响正确性——答案只会在窗口能扩张得更大时更新，而窗口能否扩张取决于"新的更大频次"，历史 `maxn` 偏大只会让窗口保持原长不收缩（滑动），不会让答案虚大：若当前窗口真实频次不足 `maxn`，`r - l + 1` 也不会超过历史最优长度。

### 我的代码

```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        map<int, int> cnt;
        int l = 0, r = 0, n = s.size();
        int maxn = 0, ans = 0;
        for (r = 0; r < n; ++r) {
            cnt[s[r] - 'A']++;
            maxn = max(maxn, cnt[s[r] - 'A']);  // 记录当前最多的字符串
            if (r - l + 1 - maxn > k) {
                cnt[s[l] - 'A']--;
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(1)`：计数表至多 26 个大写字母（若把 `map` 换成 `int cnt[26]` 数组则更直接，`map` 在这里只是写法习惯）。

两个细节：

- `r - l + 1 - maxn > k` 的含义：窗口内需要被替换的字符数 = 窗口总长 − 出现最多的字符个数，只要这个数超过预算 `k` 就不合法；
- 由"`if` 收缩 + `maxn` 不回退"可知窗口长度单调不减，其实答案就等于最终窗口长度，代码里的 `ans = max(ans, ...)` 只是把这一事实显式写出来，不影响正确性。
