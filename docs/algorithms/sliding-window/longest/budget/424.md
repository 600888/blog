# 424. 替换后的最长重复字符

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-repeating-character-replacement/description/)

### 题意

给定大写字母字符串 `s`，最多替换 `k` 个字符，求替换后由同一字符组成的最长连续子串长度。

### 样例 1

```text
输入：s = "AABABBA", k = 1
输出：4
```

解释：例如把 `"AABA"` 中的 `B` 改为 `A`，得到长度为 `4` 的重复字符段。
