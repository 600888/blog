# 2958. 最多 K 个重复元素的最长子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/length-of-longest-subarray-with-at-most-k-frequency/description/)

### 题意

给定数组 `nums` 和整数 `k`，求最长连续子数组的长度，要求其中每个整数最多出现 `k` 次。

### 样例 1

```text
输入：nums = [1,2,3,1,2,3,1,2], k = 2
输出：6
```

解释：前六个元素中每个整数都恰好出现两次。

### 解题思路

「每个元素最多出现 `k` 次」等价于「窗口内任意元素的出现次数不超过 `k`」。求满足条件的最长子数组，是不定长滑动窗口（求最长）：

- 右指针 `r` 一直向右扩张，哈希表 `cnt` 维护窗口内每个元素的出现次数；
- 当刚进窗口的 `nums[r]` 出现次数超过 `k`（`cnt[nums[r]] > k`）时窗口不合法，左指针 `l` 右移收缩，移出元素时计数减一，直到 `cnt[nums[r]] <= k`；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

和 3、1695 两题比较：那两题的收缩条件是 `r - l + 1 > cnt.size()`（依赖种类数，需要 `erase` 清理零计数键）；本题的收缩条件直接落在"刚进窗口的那个元素"上——只有 `nums[r]` 的计数可能超标，其他元素本来就合法，所以收缩条件只需盯住 `cnt[nums[r]] > k`，且计数减到 `0` 也不影响条件判断，**不需要 `erase`**。

另一个细节：收缩用 `while` 而不是 `if`——新进入的 `nums[r]` 让窗口的"超支量"最多为 1，但最坏情况下要把左边大量同类元素都移出去才能把 `cnt[nums[r]]` 降到 `k`，一次 `l++` 往往不够（例如 `[1,1,1,1], k=2` 进最后一个 1 后要连移两个）。

### 我的代码

```cpp
class Solution {
public:
    int maxSubarrayLength(vector<int>& nums, int k) {
        int l = 0, r = 0, n = nums.size();
        int ans = 0;
        unordered_map<int, int> cnt;
        for (r = 0; r < n; ++r) {
            cnt[nums[r]]++;              // 右端元素进入窗口
            while (cnt[nums[r]] > k) {   // nums[r] 出现次数超过限制，收缩窗口
                cnt[nums[l]]--;          // 移出左端元素，直到 nums[r] 不超标
                l++;
            }
            ans = max(ans, r - l + 1);   // 此刻每个元素出现次数均 <= k，结算
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(min(n, |Σ|))`：哈希表只存窗口内出现过的元素。

两个细节：

- **收缩条件只盯 `nums[r]`**：右端进入前窗口合法，只有新元素可能超标，因此不需要遍历检查所有元素的次数，条件写 `cnt[nums[r]] > k` 即可，收敛也更快；
- **本题不需要 `erase` 零计数键**：与 3/1695 题的本质区别在于本题的合法性判断不依赖 `cnt.size()`（种类数），只依赖单个元素的计数值，零计数键留在表里不影响任何判断（只是多占点内存）。
