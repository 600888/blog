# 2958. 最多 K 个重复元素的最长子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/length-of-longest-subarray-with-at-most-k-frequency/description/)

### 题意

给定数组 `nums` 和整数 `k`，求最长连续子数组的长度，要求其中每个整数最多出现 `k` 次。

### 样例 1

```text
输入：nums = [1,2,3,1,2,3,1,2], k = 2
输出：6
```

解释：前六个元素中每个整数都恰好出现两次。
