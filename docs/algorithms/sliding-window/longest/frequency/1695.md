# 1695. 删除子数组的最大得分

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-erasure-value/description/)

### 题意

给定正整数数组 `nums`，删除一个元素互不相同的非空连续子数组，得分为该子数组元素之和；求最大得分。

### 样例 1

```text
输入：nums = [4,2,4,5,6]
输出：17
```

解释：选择 `[2,4,5,6]`，得分为 `17`。
