# 1695. 删除子数组的最大得分

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-erasure-value/description/)

### 题意

给定正整数数组 `nums`，删除一个元素互不相同的非空连续子数组，得分为该子数组元素之和；求最大得分。

### 样例 1

```text
输入：nums = [4,2,4,5,6]
输出：17
```

解释：选择 `[2,4,5,6]`，得分为 `17`。

### 解题思路

「删除一个元素互不相同的子数组」就是「找一个所有元素互不相同的连续子数组」，求其元素和的最大值——本质是 3 题（无重复字符的最长子串）的变体：判断条件完全一样（窗口长度与 `cnt.size()` 比大小），只是把"求最长长度"换成了"求窗口元素和的最大值"：

- 右指针 `r` 一直向右扩张，`cnt` 维护窗口内元素出现次数，同时用 `sum` 累加窗口元素和；
- 当 `r - l + 1 > cnt.size()` 时窗口内有重复元素，左指针 `l` 右移收缩，移出 `nums[l]` 时计数减一（减到 `0` 就 `erase`，保证 `cnt.size()` 是真实种类数）、`sum` 同步减去该元素；
- 每轮窗口合法后用 `sum` 更新答案。

与 3 题相比唯一的区别：结算时取的是 `sum`（窗口和）而不是 `r - l + 1`（窗口长度）。注意 `sum` 的维护要和指针移动严格同步——右端进窗口时加、左端出窗口时减，不能只在一侧维护。

### 我的代码

```cpp
class Solution {
public:
    int maximumUniqueSubarray(vector<int>& nums) {
        int ans = 0;
        int l = 0, r = 0, n = nums.size();
        int sum = 0;
        unordered_map<int, int> cnt;
        for (r = 0; r < n; ++r) {
            cnt[nums[r]]++;       // 右端元素进入窗口
            sum += nums[r];       // 窗口和同步累加
            while (r - l + 1 > cnt.size()) {  // 窗口内有重复元素，收缩
                cnt[nums[l]]--;
                if (cnt[nums[l]] == 0) {
                    cnt.erase(nums[l]);       // 计数为 0 必须删除，否则种类数虚大
                }
                sum -= nums[l];   // 左端元素移出窗口
                l++;
            }
            ans = max(ans, sum);  // 此刻窗口内元素互不相同，结算最大和
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(min(n, |Σ|))`：哈希表只存窗口内出现过的元素。

两个细节：

- **`cnt.erase` 不能省**：本题收缩条件同样是 `r - l + 1 > cnt.size()`，依赖"种类数"这个值，残留计数为 `0` 的键会让种类数虚大、收缩条件失效，答案出错；
- 题目保证元素为**正整数**，所以窗口和随窗口长度单调变化，合法窗口越和越大不会出现"更短反而更大"的干扰，标准模板直接适用；若元素可负，本题的正确性前提就不再成立。
