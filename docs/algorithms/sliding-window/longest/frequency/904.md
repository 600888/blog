# 904. 水果成篮

[力扣原题（完整题面）](https://leetcode.cn/problems/fruit-into-baskets/description/)

### 题意

给定数组 `fruits`，每个数字代表一种水果。只能选取一段连续位置，且其中最多有两种水果；求最多能采摘多少个。

### 样例 1

```text
输入：fruits = [1,2,1]
输出：3
```

解释：整段数组只有两种水果，可以全部采摘。

### 解题思路

「两个篮子各装一种水果」去掉故事外壳，就是「找一个元素种类不超过 2 的最长连续子数组」——这是 3 题条件的一般化：3 题要求种类数不超过 `1`（即无重复），本题放宽到不超过 `2`，判断条件从 `r - l + 1 > cnt.size()` 的临界值从 1 变成 2 而已：

- 右指针 `r` 一直向右扩张，哈希表 `cnt` 维护窗口内每种水果的出现次数；
- 当 `cnt.size() > 2` 时窗口内水果种类超标，左指针 `l` 右移收缩，移出 `fruits[l]` 时计数减一，减到 `0` 就 `erase`，保证 `cnt.size()` 是真实种类数，直到重新回到 `2` 种以内；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

与 2958/3090 题对比：那两题收缩条件只盯刚进窗口的单个元素计数，**不需要 `erase`**；本题的合法性判断依赖种类数 `cnt.size()`（和 3/1695 一样），所以**必须 `erase` 零计数键**，否则种类数虚大、窗口永远收缩不下来。

### 我的代码

```cpp
class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        // 题目转换为：一段连续子串，里面的元素种类不能超过两个
        int l = 0, r = 0, n = fruits.size();
        unordered_map<int, int> cnt;
        int ans = 0;
        for (r = 0; r < n; ++r) {
            cnt[fruits[r]]++;       // 右端水果进入窗口
            while (cnt.size() > 2) {  // 如果当前采摘水果后，导致种类大于2，移动左端点
                cnt[fruits[l]]--;
                if (cnt[fruits[l]] == 0) {
                    cnt.erase(fruits[l]);  // 计数为 0 必须删除，否则种类数虚大
                }
                l++;
            }
            ans = max(ans, r - l + 1);  // 此刻窗口内至多两种水果，结算
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(1)`：`cnt.size()` 永远不超过 `3`（一旦超过立刻收缩），至多存 `3` 个键。

两个细节：

- **`cnt.erase` 不能省**：本题条件 `cnt.size() > 2` 直接依赖种类数，残留零计数键会让种类数虚大，窗口会一直收缩过头甚至答案出错；
- **`k` 写死为 `2`**：本题就是"种类数不超过 k"模板的 `k = 2` 特例，把 `2` 抽成参数即得通用解（"最多 K 种不同数字"一类题直接套用）。「无重复」（3 题）是这个家族里 `k = 1` 的另一端。
