# 904. 水果成篮

[力扣原题（完整题面）](https://leetcode.cn/problems/fruit-into-baskets/description/)

### 题意

给定数组 `fruits`，每个数字代表一种水果。只能选取一段连续位置，且其中最多有两种水果；求最多能采摘多少个。

### 样例 1

```text
输入：fruits = [1,2,1]
输出：3
```

解释：整段数组只有两种水果，可以全部采摘。
