# 3090. 每个字符最多出现两次的最长子串

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-length-substring-with-two-occurrences/description/)

### 题意

给定字符串 `s`，求最长连续子串的长度，要求其中每种字符最多出现两次。

### 样例 1

```text
输入：s = "aababc"
输出：5
```

解释：`"ababc"` 中 `a` 和 `b` 都出现两次，`c` 出现一次。

### 解题思路

「每种字符最多出现两次」就是把 2958 题的 `k` 固定为 `2`——判断条件、收缩逻辑完全一样，只是把"任意元素出现次数不超过 `k`"换成"任意字符出现次数不超过 `2`"：

- 右指针 `r` 一直向右扩张，哈希表 `cnt` 维护窗口内每种字符的出现次数；
- 当刚进窗口的 `s[r]` 出现次数超过 `2`（`cnt[s[r]] > 2`）时窗口不合法，左指针 `l` 右移收缩，移出字符时计数减一，直到 `cnt[s[r]] <= 2`；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

和 2958 题相同的两个细节在这里依然成立：收缩条件只盯刚进窗口的 `s[r]`（其他字符本来就合法）；合法性判断不依赖种类数 `cnt.size()`，所以**不需要 `erase` 零计数键**。收缩也必须用 `while`，例如 `"aaaa"` 进最后一个 `a` 时要把前面两个 `a` 都移出去才能恢复合法。

### 我的代码

```cpp
class Solution {
public:
    int maximumLengthSubstring(string s) {
        int l = 0, r = 0, n = s.size();
        int ans = 0;
        unordered_map<int, int> cnt;
        for (r = 0; r < n; ++r) {
            cnt[s[r]]++;             // 右端字符进入窗口
            while (cnt[s[r]] > 2) {  // s[r] 出现次数超过 2，收缩窗口
                cnt[s[l]]--;         // 移出左端字符，直到 s[r] 不超标
                l++;
            }
            ans = max(ans, r - l + 1);  // 此刻每种字符最多出现两次，结算
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(min(n, |Σ|))`：本题字符集只有小写字母，可视为 `O(26)` 即 `O(1)`；写法上也可以用 `int cnt[26]` 数组代替哈希表，更省常量。

两个细节：

- **本题就是 2958 的 `k = 2` 特例**：模板完全一致，理解了 2958 的"收缩条件只盯 `nums[r]`"和"不需要 `erase`"，本题无需额外思考；
- **数据范围小**（`n ≤ 100`），本题暴力枚举所有子串 `O(n²)` 甚至更差的做法也能过，但窗口写法是这一组题的标准练手姿势。
