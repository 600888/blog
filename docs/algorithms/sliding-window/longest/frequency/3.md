# 3. 无重复字符的最长子串

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)

### 题意

给定字符串 `s`，求不含重复字符的最长连续子串长度。

### 样例 1

```text
输入：s = "abcabcbb"
输出：3
```

解释：`"abc"` 是一个长度为 `3` 的无重复字符子串。

### 解题思路

「无重复字符」等价于「窗口内字符种类数等于窗口长度」。一旦窗口长度大于种类数，由抽屉原理必然存在重复字符。求满足条件的最长子串，是不定长滑动窗口（求最长）：

- 右指针 `r` 一直向右扩张，用哈希表 `cnt` 维护窗口内每种字符的出现次数；
- 当 `r - l + 1 > cnt.size()` 时说明窗口内有重复字符（长度超过种类数），左指针 `l` 右移收缩，移出 `s[l]` 时计数减一，减到 `0` 就把该字符从哈希表里 `erase` 掉，保证 `cnt.size()` 始终是窗口内真实种类数；
- 每轮窗口合法后用 `r - l + 1` 更新答案。

这道题的巧妙之处在于**收缩条件不用逐字符比对重复**：不需要记录"当前字符是否已出现两次"，而是直接比较窗口长度和种类数。`while` 收缩到 `r - l + 1 == cnt.size()` 为止，此时窗口内所有字符恰好各出现一次。

### 我的代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<int, int> cnt;
        int l = 0, r = 0, n = s.size();
        int ans = 0;
        for (r = 0; r < n; ++r) {
            cnt[s[r]]++;
            while (r - l + 1 > cnt.size()) {  // 如果子串长度大于不重复的字符个数
                cnt[s[l]]--;
                if (cnt[s[l]] == 0) {
                    cnt.erase(s[l]);
                }
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

时间复杂度~~ `O(n)`：`l` 和 `r` 各最多前进 `n` 次。空间复杂度 `O(min(n, |Σ|))`：哈希表只存窗口内出现过的字符，`|Σ|` 是字符集大小（本题约 128，可视为 `O(1)`）。~~

两个细节：

- **`cnt.erase(s[l])` 不能省**：哈希表里残留计数为 `0` 的键会让 `cnt.size()` 虚大，收缩条件 `r - l + 1 > cnt.size()` 就永远不会触发，答案出错。这一点和只比较"某字符出现次数"的写法（如 2958 题）不同，本题的条件依赖种类数，必须把空键清掉；
- 收缩用 `while` 保证循环结束时窗口一定合法：新进来的 `s[r]` 可能与窗口内多个字符重复，一次只移出一个 `l` 可能不够。
