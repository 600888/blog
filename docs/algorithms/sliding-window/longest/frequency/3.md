# 3. 无重复字符的最长子串

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)

### 题意

给定字符串 `s`，求不含重复字符的最长连续子串长度。

### 样例 1

```text
输入：s = "abcabcbb"
输出：3
```

解释：`"abc"` 是一个长度为 `3` 的无重复字符子串。
