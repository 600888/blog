# 1438. 绝对差不超过限制的最长连续子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/description/)

### 题意

给定数组 `nums` 和整数 `limit`，求最长连续子数组的长度，要求其中任意两个元素的绝对差不超过 `limit`。

### 样例 1

```text
输入：nums = [8,2,4,7], limit = 4
输出：2
```

解释：`[2,4]` 满足条件，而 `[2,4,7]` 的最大差为 `5`。

### 样例 2

```text
输入：nums = [10,1,2,4,7,2], limit = 5
输出：4
```

解释：`[2,4,7,2]` 的最大值为 7、最小值为 2，差为 5，满足条件。

### 样例 3

```text
输入：nums = [4,2,2,2,4,4,2,2], limit = 0
输出：3
```

解释：`[2,2,2]` 是最长的、任意两元素相等的子数组。

### 解题思路

"任意两个元素的绝对差不超过 `limit`"等价于"窗口内 **最大值 − 最小值** 不超过 `limit`"，约束只依赖窗口极值，所以核心问题是动态维护滑动窗口的最值。

这里用有序 `map<int, int>` 维护窗口内每个值的出现次数：键有序，`begin()` 直接给出最小值，`rbegin()` 给出最大值。右端元素进入窗口后检查极差，一旦超过 `limit` 就从左端收缩。收缩时计数减到 0 必须把键从 map 中 `erase`，否则 `begin()` / `rbegin()` 会读到已经离开窗口的值。

`l < r` 保证窗口至少剩一个元素；由于进入循环前刚把 `nums[r]` 加入 map，收缩只发生在 `l < r` 时，map 始终非空。每轮 `while` 结束后窗口必然合法，用 `r - l + 1` 更新答案。

经典 `O(n)` 做法是用两个单调队列分别维护窗口最大值和最小值（与 239. 滑动窗口最大值同源，2762. 不间断子数组也用同样技巧）。map 写法是 `O(n log n)`，在本题数据范围内同样通过，优点是思路直接、不易写错。

### 我的代码

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums, int limit) {
        int l = 0, r = 0, n = nums.size();
        int ans = 0;
        map<int, int> cnt;                 // 键为元素值，值为窗口内出现次数；键有序
        for (r = 0; r < n; ++r) {
            cnt[nums[r]]++;                // 右端元素进入窗口
            int mini = cnt.begin()->first;    // 窗口内最小值
            int maxm = cnt.rbegin()->first;   // 窗口内最大值
            while (maxm - mini > limit && l < r) {  // 极差超限，收缩左端
                cnt[nums[l]]--;
                if (cnt[nums[l]] == 0) {
                    cnt.erase(nums[l]);    // 计数归零必须删键，否则极值读到已离开的元素
                }
                l++;
                mini = cnt.begin()->first;    // 收缩后重新取极值
                maxm = cnt.rbegin()->first;   // 最大值
            }
            ans = max(ans, r - l + 1);     // 此时窗口合法，记录最长长度
        }
        return ans;
    }
};
```

时间复杂度 `O(n log n)`，每个元素最多进出窗口各一次，`map` 的插入、删除和取极值都是 `O(log n)`；空间复杂度 `O(n)`，最坏时窗口内所有元素互不相同。
