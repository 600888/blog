# 2401. 最长优雅子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-nice-subarray/description/)

### 题意

如果连续子数组中任意两个不同元素的按位与都为 `0`，则称它为优雅子数组。求最长优雅子数组的长度。

### 样例 1

```text
输入：nums = [1,3,8,48,10]
输出：3
```

解释：`[3,8,48]` 中任意两个数的按位与都为 `0`。

### 样例 2

```text
输入：nums = [3,1,5,11,13]
输出：1
```

解释：任意两个元素都有公共的二进制位，最长的优雅子数组是任意单个元素。

### 解题思路

"任意两个元素按位与为 `0`"等价于"窗口内所有元素的二进制位**互不重叠**"。约束只和位有关，所以维护窗口内所有元素的**按位或** `st`：新元素 `nums[r]` 能否加入，只需检查 `st & nums[r]` 是否为 `0`，有公共位就冲突。

冲突时从左端收缩，直到 `nums[r]` 不再与窗口冲突，再加入并更新答案。

这段代码成立的关键是一个不变量：**窗口内元素两两位不重叠，因此 `st` 中每个为 1 的位都由唯一元素贡献**。于是移出左端元素时 `st &= ~nums[l]` 是精确清除，不会误伤其他元素仍然持有的位。在允许共享位的场景下这种清除方式是错的，这里靠不变量才安全。

用 `bitset<32>` 只是为了直观（`.any()` 判断是否有公共位）；由于 `nums[i] <= 10^9` 不超过 30 位，直接用一个 `int` 做状态、用 `(st & num) != 0` 判断也完全可以。窗口冲突检查的思路同样适用于"每个字符/元素最多出现 K 次"一类限制频率的题（如 3090）。

### 我的代码

```cpp
class Solution {
public:
    void count(bitset<32>& st, int num) {
        st |= bitset<32>(num);      // 按位或，把 num 的位并入窗口状态
    }
    bool check(bitset<32>& st, int num) {
        return (st & bitset<32>(num)).any();   // 与窗口有公共位则冲突
    }
    void erase(bitset<32>& st, int num) {
        st &= ~bitset<32>(num);     // 按位清除 num 贡献的位
    }
    int longestNiceSubarray(vector<int>& nums) {
        int l = 0, n = nums.size(), ans = 0;
        bitset<32> st;                        // 窗口内所有元素的按位或
        for (int r = 0; r < n; ++r) {
            while (check(st, nums[r])) {      // 先检查即将加入的 nums[r]
                erase(st, nums[l]);           // 窗口内两两位不重叠，清除是精确的
                l++;
            }
            count(st, nums[r]);               // 无冲突，nums[r] 进入窗口
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`，每个元素最多进出窗口各一次，`bitset` 的按位运算和 `.any()` 都是常数代价；空间复杂度 `O(1)`。
