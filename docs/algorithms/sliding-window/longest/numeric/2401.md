# 2401. 最长优雅子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-nice-subarray/description/)

### 题意

如果连续子数组中任意两个不同元素的按位与都为 `0`，则称它为优雅子数组。求最长优雅子数组的长度。

### 样例 1

```text
输入：nums = [1,3,8,48,10]
输出：3
```

解释：`[3,8,48]` 中任意两个数的按位与都为 `0`。
