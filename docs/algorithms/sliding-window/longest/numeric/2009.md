# 2009. 使数组连续的最少操作数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-continuous/description/)

### 题意

一次操作可以把 `nums` 中任意一个元素替换为任意整数。求使数组元素互不相同，且最大值与最小值之差恰好为 `nums.length - 1` 的最少操作次数。

### 样例 1

```text
输入：nums = [4,2,5,3]
输出：0
```

解释：四个元素正好是连续整数，无须修改。
