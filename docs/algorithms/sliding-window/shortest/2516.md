# 2516. 每种字符至少取 K 个

[力扣原题（完整题面）](https://leetcode.cn/problems/take-k-of-each-character-from-left-and-right/description/)

### 题意

给定只含 `a`、`b`、`c` 的字符串 `s`，每分钟从左端或右端取走一个字符。求使取走的字符中每种至少有 `k` 个所需的最少分钟数；无法做到则返回 `-1`。

### 样例 1

```text
输入：s = "aabaaaacaabc", k = 2
输出：8
```

解释：可以从两端合计取走 `8` 个字符，分别至少取得两个 `a`、`b`、`c`。
