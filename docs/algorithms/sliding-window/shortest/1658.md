# 1658. 将 x 减到 0 的最小操作数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-operations-to-reduce-x-to-zero/description/)

### 题意

给定数组 `nums` 和整数 `x`，每次只能移除数组最左端或最右端的元素，并从 `x` 中减去该值。求使 `x` 恰好变为 `0` 的最少操作数；无法做到则返回 `-1`。

### 样例 1

```text
输入：nums = [1,1,4,2,3], x = 5
输出：2
```

解释：依次移除右端的 `3` 和 `2`。

### 样例 2

```text
输入：nums = [3,4,5,1,2], x = 2
输出：-1
```

解释：数组总和为 15，不存在和为 `15 - 2 = 13` 的连续子数组，无法做到。

### 样例 3

```text
输入：nums = [5,6,7,8,9], x = 4
输出：-1
```

解释：每次移除的元素至少是 5，`x` 无法被减到 0。

### 解题思路

直接从"移除"入手不好下手，因为每一步的选择会让剩余数组的形状不断变化。换个角度：**被移除的元素一定构成一个前缀加一个后缀，剩下的是一段连续子数组**。设数组总和为 `total`，要减掉的总和必须恰好是 `x`，因此：

```text
保留的子数组和 = total - x
最少操作数 = n - 保留子数组的长度
```

于是问题变成：**求和等于 `total - x` 的最长连续子数组**。操作数与保留长度是一一对应的相反关系，所以"最少操作"等价于"最长子数组"，方向由最短窗口翻转为最长窗口。

边界与步骤：

1. 若 `total - x < 0`，说明 `x` 比数组总和还大，不可能做到，直接返回 `-1`。
2. 窗口内维护和 `sum`，右端每轮扩张；当 `sum > total - x` 时，从左端不断移出元素直到 `sum <= total - x`。
3. 此时若 `sum == total - x`，窗口合法，用 `r - l + 1` 更新最长长度。
4. 若从未出现合法窗口，返回 `-1`；否则返回 `n - 最长长度`。

收缩是安全的，因为数组元素全为正数，左端移出元素只会让 `sum` 变小，具有单调性。注意收缩条件是 `sum > target` 而不是 `>=`，否则会把等于目标的那个窗口提前缩掉，丢失最优解。

### 我的代码

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int x) {
        // 题目转换为：求最长连续子串，使得子串和等于数组和sum-x
        int total = 0;  // 用于记录数组和
        for (int i = 0; i < nums.size(); ++i) {
            total += nums[i];
        }
        if (total - x < 0) {
            return -1;
        }
        int l = 0, r = 0, n = nums.size();
        int sum = 0;  // 用于记录子串和
        int ans = -1;
        for (r = 0; r < n; ++r) {
            sum += nums[r];
            while (sum > total - x) {
                sum -= nums[l];
                l++;
            }
            if (sum == total - x) {
                ans = max(ans, r - l + 1);
            }
        }
        if (ans == -1) return -1;
        return n - ans;
    }
};
```

时间复杂度 `O(n)`，左右端点各最多移动 `n` 次；空间复杂度 `O(1)`。

### 另一种解法：前缀和 + 哈希表

元素全为正数时前缀和严格递增，也可以不看窗口直接用哈希表找"存在过的前缀和"：

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int x) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        if (total - x < 0) return -1;
        int target = total - x;
        unordered_map<int, int> first;  // 前缀和 -> 最早出现下标
        int pre = 0, best = -1;
        first[0] = 0;                  // 空前缀，使"从下标 0 开始的子数组"也能被覆盖
        for (int i = 1; i <= (int)nums.size(); ++i) {
            pre += nums[i - 1];
            if (first.count(pre - target)) {
                best = max(best, i - first[pre - target]);
            }
            // 只记录最早下标：起点越靠左，子数组越长
            if (!first.count(pre)) first[pre] = i;
        }
        return best == -1 ? -1 : (int)nums.size() - best;
    }
};
```

时间复杂度仍为 `O(n)`，空间复杂度 `O(n)`。滑窗解法空间 `O(1)`，前缀和哈希解法不需要依赖"收缩到什么时候停止"的判断，两者适合对照理解。
