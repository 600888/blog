# 1658. 将 x 减到 0 的最小操作数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-operations-to-reduce-x-to-zero/description/)

### 题意

给定数组 `nums` 和整数 `x`，每次只能移除数组最左端或最右端的元素，并从 `x` 中减去该值。求使 `x` 恰好变为 `0` 的最少操作数；无法做到则返回 `-1`。

### 样例 1

```text
输入：nums = [1,1,4,2,3], x = 5
输出：2
```

解释：依次移除右端的 `3` 和 `2`。
