# 1234. 替换子串得到平衡字符串

[力扣原题（完整题面）](https://leetcode.cn/problems/replace-the-substring-for-balanced-string/description/)

### 题意

字符串 `s` 只含 `Q`、`W`、`E`、`R`，长度是 `4` 的倍数。可以把一个连续子串替换为任意等长字符串，求让四种字符各出现 `s.length / 4` 次所需替换子串的最短长度；已平衡则返回 `0`。

### 样例 1

```text
输入：s = "QQQW"
输出：2
```

解释：把两个 `Q` 替换为 `E` 和 `R` 即可。
