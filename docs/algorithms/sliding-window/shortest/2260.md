# 2260. 必须拿起的最小连续卡牌数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-consecutive-cards-to-pick-up/description/)

### 题意

给定卡牌数值数组 `cards`，一次拿起一段连续卡牌，要求其中至少有两张数值相同。求必须拿起的最少卡牌数；无法满足则返回 `-1`。

### 样例 1

```text
输入：cards = [3,4,2,3,4,7]
输出：4
```

解释：拿起前四张 `[3,4,2,3]`，包含两张 `3`。

### 样例 2

```text
输入：cards = [1,0,5,3]
输出：-1
```

解释：没有任何两张卡牌数值相同。

### 解题思路

拿起的卡牌段要包含一对同值卡牌，这对卡牌就是这个区间的**两端**——所以最优解一定来自"同一数值两次出现"构成的区间，且其中距离最近的两次出现必然在出现序列中**相邻**。

于是不必真的维护一个会收缩的窗口：用哈希表记录每个数值上一次出现的下标。右端扫到 `cards[r]` 时，如果它出现过，`r` 与上一次出现的下标 `p` 就构成候选区间 `[p, r]`，用 `r - p + 1` 更新答案，再把上一次出现位置刷新为 `r`。每个下标只访问一次。

这题虽然归入"最短窗口"分类，本质是把收缩过程压缩成了"直接跳到上一次出现位置"。等价的滑动窗口写法是：维护窗口内无重复，`cards[r]` 已在窗口内时先记录 `r - l + 1` 再收缩左端，两种写法得到相同结果。

### 我的代码

```cpp
class Solution {
public:
    int minimumCardPickup(vector<int>& cards) {
        int r = 0, n = cards.size();
        int ans = INT_MAX;
        unordered_map<int, int> pos;   // 每个数值上一次出现的下标
        for (r = 0; r < n; ++r) {
            if (pos.find(cards[r]) == pos.end()) {
                pos[cards[r]] = r;     // 首次出现，只记录位置
            } else {
                ans = min(ans, r - pos[cards[r]] + 1);  // 与上一次出现构成候选区间
                pos[cards[r]] = r;     // 刷新上一次出现位置
            }
        }
        if (ans == INT_MAX) return -1; // 扫描结束仍无重复数值
        return ans;
    }
};
```

时间复杂度 `O(n)`，哈希表操作均摊 `O(1)`；空间复杂度 `O(n)`，哈希表最多存 `n` 个键。
