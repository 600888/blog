# 209. 长度最小的子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-size-subarray-sum/description/)

### 题意

给定正整数数组 `nums` 和正整数 `target`，求元素和至少为 `target` 的非空连续子数组的最短长度；不存在则返回 `0`。

### 样例 1

```text
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
```

解释：子数组 `[4,3]` 的和为 `7`。

### 样例 2

```text
输入：target = 4, nums = [1,4,4]
输出：1
```

解释：单个元素 `[4]` 本身就满足条件。

### 样例 3

```text
输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0
```

解释：整个数组的和为 8，小于 11，不存在满足条件的子数组。

### 解题思路

窗口内维护元素和 `sum`。右端点每轮把新元素加入窗口；一旦 `sum >= target`，窗口已经合法，此时不断从左端移出元素并记录最短长度，直到 `sum < target` 为止。

收缩是安全的，因为元素全为正数：左端移出元素只会让 `sum` 变小，具有单调性。一旦 `sum < target` 就停止收缩，等待右端继续扩张。每个元素最多进入和离开窗口各一次。

### 我的代码

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int l = 0, r = 0, n = nums.size();
        int sum = 0;
        int ans = INT_MAX;
        for (r = 0; r < n; ++r) {
            sum += nums[r];
            while (sum >= target) {
                ans = min(ans, r - l + 1);
                sum -= nums[l];
                l++;
            }
        }
        if (ans == INT_MAX) return 0;
        return ans;
    }
};
```

时间复杂度 `O(n)`，左右端点各最多移动 `n` 次；空间复杂度 `O(1)`。`ans` 初始化为 `INT_MAX`，循环结束后若仍是初始值说明不存在合法子数组，返回 `0`。
