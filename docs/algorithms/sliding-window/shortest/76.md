# 76. 最小覆盖子串

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-window-substring/description/)

### 题意

给定字符串 `s` 和 `t`，在 `s` 中找包含 `t` 所有字符及其重复次数的最短连续子串；不存在则返回空字符串。

### 样例 1

```text
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
```

解释：`"BANC"` 包含 `A`、`B`、`C`，长度为 `4`。
