# 187. 重复的 DNA 序列

[力扣原题（完整题面）](https://leetcode.cn/problems/repeated-dna-sequences/description/)

### 题意

给定 DNA 字符串 `s`（只含 `A`、`C`、`G`、`T`），找出所有在 `s` 中出现至少两次的长度为 `10` 的不同连续子串，返回顺序不限。

### 样例 1

```text
输入：s = "AAAAAAAAAAA"
输出：["AAAAAAAAAA"]
```

解释：长度为 `10` 的串 `"AAAAAAAAAA"` 在两个不同起点出现。
