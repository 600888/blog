# 395. 至少有 K 个重复字符的最长子串

[力扣原题（完整题面）](https://leetcode.cn/problems/longest-substring-with-at-least-k-repeating-characters/description/)

### 题意

给定字符串 `s` 和整数 `k`，求最长连续子串的长度，要求其中每种出现过的字符都至少出现 `k` 次；不存在则返回 `0`。

### 样例 1

```text
输入：s = "aaabb", k = 3
输出：3
```

解释：子串 `"aaa"` 中的字符 `a` 恰好出现三次。
