# 1297. 子串的最大出现次数

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-number-of-occurrences-of-a-substring/description/)

### 题意

给定字符串 `s`、`maxLetters`、`minSize`、`maxSize`。在长度介于 `minSize` 和 `maxSize`、不同字符数不超过 `maxLetters` 的子串中，返回某个子串在 `s` 中出现的最大次数；不存在则返回 `0`。

### 样例 1

```text
输入：s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4
输出：2
```

解释：`"aab"` 出现两次，且只包含两种字符。
