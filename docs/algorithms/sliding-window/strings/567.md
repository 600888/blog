# 567. 字符串的排列

[力扣原题（完整题面）](https://leetcode.cn/problems/permutation-in-string/description/)

### 题意

给定字符串 `s1` 和 `s2`，判断 `s2` 是否包含一个与 `s1` 字符及其次数完全相同的连续子串。

### 样例 1

```text
输入：s1 = "ab", s2 = "eidbaooo"
输出：true
```

解释：`s2` 中的 `"ba"` 是 `s1` 的一种排列。
