# 30. 串联所有单词的子串

[力扣原题（完整题面）](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/description/)

### 题意

给定字符串 `s` 和等长单词数组 `words`，找出所有起点，使从该位置开始的子串恰好由 `words` 中全部单词各使用一次、按任意顺序连续拼接而成。

### 样例 1

```text
输入：s = "barfoothefoobarman", words = ["foo","bar"]
输出：[0,9]
```

解释：下标 `0` 处是 `"barfoo"`，下标 `9` 处是 `"foobar"`。
