# 438. 找到字符串中所有字母异位词

[力扣原题（完整题面）](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/)

### 题意

给定字符串 `s` 和 `p`，返回 `s` 中所有与 `p` 字母异位的连续子串的起始下标，顺序从小到大。

### 样例 1

```text
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
```

解释：`"cba"` 和 `"bac"` 都是 `"abc"` 的字母异位词。
