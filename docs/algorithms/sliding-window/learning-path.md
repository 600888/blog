# 滑动窗口学习路径

下面是一条建议的刷题顺序。每道题仍有独立的笔记页，可以做完后再补自己的思路。

## 入门：简单题

1. [643. 子数组最大平均数 I](./fixed/basic/643.md)：固定长度，维护窗口和。
2. [1652. 拆炸弹](./fixed/basic/1652.md)：练习循环数组中的窗口。
3. [2269. 找到一个数字的 K 美丽值](./fixed/counting/2269.md)：枚举固定长度的数字子串。
4. [1876. 长度为三且各字符不同的子字符串](./fixed/counting/1876.md)：判断窗口内是否有重复字符。
5. [2379. 得到 K 个黑块的最少涂色次数](./fixed/counting/2379.md)：统计窗口内需要修改的位置。
6. [1984. 学生分数的最小差值](./fixed/unique/1984.md)：排序后枚举长度为 `k` 的窗口。

## 基础：中等题

1. [2090. 半径为 k 的子数组平均值](./fixed/basic/2090.md)：用前缀和快速求窗口和。
2. [1456. 定长子串中元音的最大数目](./fixed/counting/1456.md)：练习进一个、出一个。
3. [3. 无重复字符的最长子串](./longest/frequency/3.md)：首次练习窗口收缩。
4. [904. 水果成篮](./longest/frequency/904.md)：限制窗口内元素种类。
5. [1004. 最大连续 1 的个数 III](./longest/budget/1004.md)：在给定预算内求最长窗口。
6. [209. 长度最小的子数组](./shortest/209.md)：满足条件时收缩，求最短窗口。
7. [2260. 必须拿起的最小连续卡牌数](./shortest/2260.md)：求含重复元素的最短连续段。
8. [567. 字符串的排列](./strings/567.md) → [438. 找到字符串中所有字母异位词](./strings/438.md)：练习字符频率匹配。

## 进阶：中等题

1. [1838. 最高频元素的频数](./longest/budget/1838.md)：排序后维护变换成本。
2. [2516. 每种字符至少取 K 个](./shortest/2516.md)：把两端取字符转为保留中间窗口。
3. [2799. 统计完全子数组的数目](./counting/monotonic/2799.md)：统计满足条件的窗口个数。
4. [2962. 统计最大元素出现至少 K 次的子数组](./counting/monotonic/2962.md)：练习“越长越合法”的计数。
5. [1438. 绝对差不超过限制的最长连续子数组](./longest/numeric/1438.md) → [2762. 不间断子数组](./advanced/2762.md)：维护窗口最值，再统计合法子数组。

## 挑战：困难题

1. [2302. 统计得分小于 K 的子数组数目](./counting/product-sum/2302.md)：窗口和与窗口长度一起参与约束。
2. [992. K 个不同整数的子数组](./counting/exact/992.md)：用“至多 `K`”之差求“恰好 `K`”。
3. [76. 最小覆盖子串](./shortest/76.md)：维护多个字符的覆盖需求。
4. [239. 滑动窗口最大值](./advanced/239.md)：用单调队列维护窗口最大值。
5. [2444. 统计定界子数组的数目](./counting/monotonic/2444.md)：同时处理最小值、最大值和无效位置。
6. [2009. 使数组连续的最少操作数](./longest/numeric/2009.md)：排序去重后找覆盖最多元素的窗口。
7. [862. 最短子数组之和至少为 K](./advanced/862.md)：前缀和与单调队列结合。
8. [480. 滑动窗口中位数](./advanced/480.md)：维护窗口内的有序状态。
