# 2762. 不间断子数组

[力扣原题（完整题面）](https://leetcode.cn/problems/continuous-subarrays/description/)

### 题意

统计数组 `nums` 的非空连续子数组中，任意两个元素的绝对差都不超过 `2` 的子数组数量。

### 样例 1

```text
输入：nums = [5,4,2,4]
输出：8
```

解释：例如 `[4,2,4]` 满足条件，而 `[5,4,2]` 不满足。
