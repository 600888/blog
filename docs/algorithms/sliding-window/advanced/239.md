# 239. 滑动窗口最大值

[力扣原题（完整题面）](https://leetcode.cn/problems/sliding-window-maximum/description/)

### 题意

给定整数数组 `nums` 和窗口长度 `k`。窗口从左到右每次移动一格，返回每个窗口中的最大值。

### 样例 1

```text
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
```

解释：第一个窗口 `[1,3,-1]` 的最大值是 `3`，依次计算其余窗口。
