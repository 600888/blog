# 862. 最短子数组之和至少为 K

[力扣原题（完整题面）](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/description/)

### 题意

给定整数数组 `nums`（可以含负数）和整数 `k`，求元素和至少为 `k` 的非空连续子数组的最短长度；不存在则返回 `-1`。

### 样例 1

```text
输入：nums = [2,-1,2], k = 3
输出：3
```

解释：整个数组的和为 `3`，没有更短的达标子数组。
