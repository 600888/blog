# 2461. 长度为 K 子数组中的最大和

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-sum-of-distinct-subarrays-with-length-k/description/)

### 题意

给定数组 `nums` 和整数 `k`，在长度为 `k` 且元素两两不同的连续子数组中求最大元素和；若不存在，返回 `0`。

### 样例 1

```text
输入：nums = [1,5,4,2,9,9,9], k = 3
输出：15
```

解释：子数组 `[4,2,9]` 的元素互不相同，和为 `15`。
