# 2461. 长度为 K 子数组中的最大和

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-sum-of-distinct-subarrays-with-length-k/description/)

### 题意

给定数组 `nums` 和整数 `k`，在长度为 `k` 且元素两两不同的连续子数组中求最大元素和；若不存在，返回 `0`。

### 样例 1

```text
输入：nums = [1,5,4,2,9,9,9], k = 3
输出：15
```

解释：子数组 `[4,2,9]` 的元素互不相同，和为 `15`。

### 解题思路

定长滑动窗口模板题，额外维护一个「窗口内是否无重复」的条件：

- 用 `sum` 维护窗口元素和，用哈希表 `mp` 维护窗口内每个元素的出现次数；
- **进**：每轮把 `nums[i]` 加进 `sum` 并让 `mp[nums[i]]++`；
- **更新**：当 `i >= k - 1` 时窗口长度恰好为 `k`。此时若 `mp.size() == k`，说明窗口内 `k` 个元素两两不同（哈希表的键数等于元素个数，即每个元素恰好出现一次），用 `sum` 更新答案；
- **出**：窗口左端元素下标为 `left = i - k + 1`，把 `nums[left]` 从 `sum` 和 `mp` 中移除。注意当它的计数减到 `0` 时要 `erase` 掉，否则 `mp.size()` 会把出现 `0` 次的键也算进去，导致判重出错。

关键点：`mp.size() == k` 是「窗口内无重复」的等价判定——若窗口内存在重复，必有某个元素出现超过一次，键数就会小于 `k`。

### 我的代码

```cpp
class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> mp;
        long long ans = 0, sum = 0;
        for (int i = 0; i < nums.size(); ++i) {
            sum += nums[i];
            mp[nums[i]]++;
            int left = i - k + 1;
            if (left < 0) continue;  // 窗口还没凑满 k 个
            if (mp.size() == k) {
                ans = max(ans, sum);
            }
            sum -= nums[left];  // 减去左边第一个元素
            mp[nums[left]]--;   // 计数-1
            if (mp[nums[left]] == 0) {
                mp.erase(nums[left]);  // 不计入出现0次的元素
            }
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`，每个元素进窗口、出窗口各一次，哈希表操作均摊 `O(1)`。空间复杂度 `O(k)`，哈希表最多存 `k` 个键。

两个实现细节：

- `ans` 和 `sum` 都用 `long long`：`n` 达到 `1e5`、元素可达 `1e9`，窗口和会超出 `int` 范围；
- 先判 `left < 0` 再结算，保证只在窗口恰好为 `k` 时更新答案，移除的也一定是上一轮窗口的左端元素。
