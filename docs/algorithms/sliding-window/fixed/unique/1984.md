# 1984. 学生分数的最小差值

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-difference-between-highest-and-lowest-of-k-scores/description/)

### 题意

给定学生分数数组 `nums`，选出恰好 `k` 个分数，使所选分数的最大值与最小值之差尽量小；返回这个最小差值。

### 样例 1

```text
输入：nums = [9,4,1,7], k = 2
输出：2
```

解释：选择 `7` 和 `9`，差值为 `2`。

### 样例 2

```text
输入：nums = [9], k = 1
输出：0
```

解释：只选 `1` 个分数，最大值和最小值都是它自己，差值为 `0`。

### 解题思路

选出恰好 `k` 个分数，让"最大值 - 最小值"最小。**选出的这组数和它们在原数组里的位置无关**，所以先把数组排序：排序后，最优的 `k` 个数一定是**连续的一段**。

为什么？假设选出的 `k` 个数在排序后不连续，中间"夹"了一个没选的数，把没选的换成夹在中间的那个，最小值不会变大、最大值不会变小，差值只会不变或更小。所以只需在排序数组上枚举所有长度为 `k` 的窗口，答案就是 `min(窗口右端 - 窗口左端)`——排序后窗口内最大值就是最右元素，最小值就是最左元素，中间的不用管。

这是定长窗口的极简形态：窗口不用维护任何计数，每次结算只看两端。枚举左端点 `l`，右端点 `r = l + k - 1`，保证 `r < n`（即 `l + k - 1 < n`）即可。

### 我的代码

```cpp
class Solution {
public:
    int minimumDifference(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int ans = INT_MAX;
        // 滑动窗口：窗口大小固定为 k
        for (int l = 0; l + k - 1 < nums.size(); l++) {
            int r = l + k - 1;
            ans = min(ans, nums[r] - nums[l]);
        }
        return ans;
    }
};
```

时间复杂度 `O(n log n)`，瓶颈在排序；排序后的窗口滑动部分是 `O(n)`。空间复杂度 `O(1)`（不计排序的栈空间）。

两个边界说明：

- `k == 1` 时每个窗口就是单元素，`nums[r] - nums[l] = 0`，循环自然返回 `0`；
- 循环条件写成 `l + k - 1 < nums.size()`，保证右端点 `r = l + k - 1` 不越界，比写成 `r < nums.size()` 少一次变量计算。
