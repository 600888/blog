# 1423. 可获得的最大点数

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-points-you-can-obtain-from-cards/description/)

### 题意

给定卡牌点数数组 `cardPoints`，每次只能从最左或最右取一张，恰好取 `k` 张，求可获得的最大点数。

### 样例 1

```text
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
```

解释：从右端取 `1`、`6`、`5`，总点数为 `12`。
