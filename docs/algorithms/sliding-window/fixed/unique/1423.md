# 1423. 可获得的最大点数

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-points-you-can-obtain-from-cards/description/)

### 题意

给定卡牌点数数组 `cardPoints`，每次只能从最左或最右取一张，恰好取 `k` 张，求可获得的最大点数。

### 样例 1

```text
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
```

解释：从右端取 `1`、`6`、`5`，总点数为 `12`。

### 解题思路

正向想「从两端取 k 张」要在窗口两端跳来跳去，不好维护。**反向转换**：取走的是两端的 `k` 张，那么**剩下的一定是数组中间连续的 `n - k` 张**。取走点数最大 ⇔ 剩下的连续段点数最小。

于是问题转化为：求数组中长度为 `n - k` 的子数组的最小和。这是标准定长滑动窗口：

- 先算 `total`（全数组之和）；
- 窗口大小 `windowSize = n - k`，滑动维护窗口和 `sum`，每次窗口凑满后用 `ans = min(ans, sum)` 结算；
- 答案为 `total - ans`：总和减去留下的最小窗口和，就是能拿到的最大点数。

一个边界：当 `k == n` 时窗口长度为 `0`，循环里永远凑不满窗口，直接返回 `total`（全部拿走）。

### 我的代码

```cpp
class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        // 问题转化为长度 cardPoints.size()-k 的窗口，和的最小值
        int windowSize = cardPoints.size() - k;
        int sum = 0, total = 0;
        int ans = INT_MAX;
        for (int i = 0; i < cardPoints.size(); ++i) {
            total += cardPoints[i];
        }
        if (windowSize == 0) return total;  // 特判窗口长度为0的情况
        for (int i = 0; i < cardPoints.size(); ++i) {
            sum += cardPoints[i];
            int left = i - windowSize + 1;
            if (left < 0) continue;
            ans = min(ans, sum);
            sum -= cardPoints[left];
        }
        return total - ans;  // 总数 - 窗口最小值 = 最大点数
    }
};
```

时间复杂度 `O(n)`，两个线性遍历；空间复杂度 `O(1)`。

两个实现细节：

- 特判 `windowSize == 0` 放在第二个循环之前，避免循环里永远不结算、`ans` 停留在 `INT_MAX` 导致 `total - ans` 溢出；
- 也可以不特判：把结算改成 `if (left == 0) ans = min(ans, sum)` 并把 `total - ans` 中的 `ans` 初始化为 `0`，但特判写法更直观。

另一种等价写法是直接维护「取走的 k 张」的窗口和（初始取前 k 张之和，之后每轮从窗口右端换入 `cardPoints[i]`、换出 `cardPoints[i - k]`），取 `max` 即可，不需要 `total`，也不需要特判——不过本题用「反向求最小剩余窗口」更能体现转化思想。
