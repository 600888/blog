# 2841. 几乎唯一子数组的最大和

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-sum-of-almost-unique-subarray/description/)

### 题意

给定数组 `nums` 和正整数 `m`、`k`。长度为 `k` 且至少含 `m` 种不同整数的子数组称为几乎唯一子数组；求它们的最大元素和，不存在则返回 `0`。

### 样例 1

```text
输入：nums = [2,6,7,3,1,7], m = 3, k = 4
输出：18
```

解释：符合要求的子数组中，`[2,6,7,3]` 的和最大。

### 解题思路

和 [2461. 长度为 K 子数组中的最大和](./2461) 是同一套定长滑动窗口模板，唯一区别在合法判定：

- 2461 要求窗口内元素**两两不同**，即恰好 `k` 种，判 `mp.size() == k`；
- 本题只要求窗口内**至少** `m` 种不同整数，判 `mp.size() >= m` 即可。

维护方式完全一样：`sum` 记窗口和，哈希表 `mp` 记窗口内每个元素的出现次数。每轮先进（`sum += nums[i]`、`mp[nums[i]]++`），窗口凑满 `k` 个（`left = i - k + 1 >= 0`）后结算答案，再出（把 `nums[left]` 从 `sum` 和 `mp` 中移除，计数减到 `0` 时 `erase`，避免 `mp.size()` 被出现 `0` 次的键虚增）。

### 我的代码

```cpp
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        long long ans = 0, sum = 0;
        unordered_map<int, int> mp;
        for (int i = 0; i < nums.size(); ++i) {
            sum += nums[i];
            mp[nums[i]]++;
            int left = i - k + 1;
            if (left < 0) continue;  // 窗口还没凑满 k 个
            if (mp.size() >= m) {
                ans = max(ans, sum);
            }
            sum -= nums[left];
            if (--mp[nums[left]] == 0) {
                mp.erase(nums[left]);
            }
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`，每个元素进出窗口各一次。空间复杂度 `O(k)`，哈希表最多存 `k` 个键。

和 2461 一样，`ans` 与 `sum` 必须用 `long long`：单元素最大 `1e9`、`k` 最大 `1e5`，窗口和远超 `int` 上限。
