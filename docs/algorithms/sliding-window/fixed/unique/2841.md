# 2841. 几乎唯一子数组的最大和

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-sum-of-almost-unique-subarray/description/)

### 题意

给定数组 `nums` 和正整数 `m`、`k`。长度为 `k` 且至少含 `m` 种不同整数的子数组称为几乎唯一子数组；求它们的最大元素和，不存在则返回 `0`。

### 样例 1

```text
输入：nums = [2,6,7,3,1,7], m = 3, k = 4
输出：18
```

解释：符合要求的子数组中，`[2,6,7,3]` 的和最大。
