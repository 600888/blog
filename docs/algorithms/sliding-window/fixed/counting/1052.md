# 1052. 爱生气的书店老板

[力扣原题（完整题面）](https://leetcode.cn/problems/grumpy-bookstore-owner/description/)

### 题意

给定每分钟的顾客数 `customers` 和老板是否生气的数组 `grumpy`。老板可选择连续 `minutes` 分钟不生气；求最终满意顾客的最大人数。

### 样例 1

```text
输入：customers = [1,0,1,2,1,1,7,5], grumpy = [0,1,0,1,0,1,0,1], minutes = 3
输出：16
```

解释：选择合适的连续三分钟使用技巧，最多让 `16` 位顾客满意。
