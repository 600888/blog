# 1461. 检查一个字符串是否包含所有长度为 K 的二进制子串

[力扣原题（完整题面）](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/description/)

### 题意

给定二进制字符串 `s` 和整数 `k`，判断长度为 `k` 的所有二进制串是否都在 `s` 中作为连续子串出现。

### 样例 1

```text
输入：s = "00110110", k = 2
输出：true
```

解释：`00`、`01`、`10`、`11` 都出现了。
