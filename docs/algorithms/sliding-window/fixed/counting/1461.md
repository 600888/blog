# 1461. 检查一个字符串是否包含所有长度为 K 的二进制子串

[力扣原题（完整题面）](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/description/)

### 题意

给定二进制字符串 `s` 和整数 `k`，判断长度为 `k` 的所有二进制串是否都在 `s` 中作为连续子串出现。

### 样例 1

```text
输入：s = "00110110", k = 2
输出：true
```

解释：`00`、`01`、`10`、`11` 都出现了。

### 解题思路

长度为 `k` 的二进制串一共有 `2^k` 种。要判断它们是否**全部**出现，最直接的做法就是：把 `s` 中所有长度为 `k` 的子串收集起来去重，最后看数量是否等于 `2^k`。

这本质上是"定长窗口 + 哈希计数"：窗口从左往右滑动，每次滑入一个新字符、滑出一个旧字符，窗口内恰好是一个长度为 `k` 的子串。用一个 `unordered_set` 存所有出现过的子串（自动去重），滑动一遍之后：

- 若集合大小等于 `1 << k`，说明 `2^k` 种串全都出现过了，返回 `true`；
- 否则说明有缺失，返回 `false`。

一个隐含的剪枝：如果 `s.size() < k`，连一个完整窗口都凑不出来，循环体一次都不会执行，集合为空，直接返回 `false`，不需要特判。

代码里 `i` 指向窗口的**右端点的下一位**，即每个窗口是 `[i - k, i)`，与 2379 的 `[left, right)` 写法一致。

### 我的代码

```cpp
class Solution {
public:
    bool hasAllCodes(string s, int k) {
        unordered_set<string> st;
        for (int i = k; i <= s.size(); ++i) {
            st.insert(s.substr(i - k, k));  // 将所有长度为k的子串放入哈希表中
        }
        return st.size() == (1 << k);  // 如果哈希表中包含所有可能的二进制字符串，返回true
    }
};
```

时间复杂度 `O(n * k)`：共 `n - k + 1` 个窗口，每次取子串和哈希都要拷贝长度为 `k` 的字符串。空间复杂度 `O(n * k)`，最坏情况下集合里存下所有不同的子串。

进阶优化：不存字符串，而是把每个窗口看作一个 `k` 位二进制数，用一个 `bool` 数组（大小 `2^k`）代替哈希集合。滑动时维护这个整数 `cur = ((cur << 1) | (s[i] - '0')) & ((1 << k) - 1)`，窗口值 `O(1)` 更新，总复杂度降到 `O(n)`、空间 `O(2^k)`。不过直接存字符串的写法思路最简洁，数据范围内完全够用。

### 进阶优化代码

核心技巧是**滚动窗口值**：窗口右移时，新值 = 旧值左移一位、末位填入新字符，再用掩码 `(1 << k) - 1` 只保留低 `k` 位（高位自动丢弃，等价于把窗口最左端的字符"挤"出去）。这样窗口对应的整数每次 `O(1)` 就能更新，不需要重新读取整个子串。

```cpp
class Solution {
public:
    bool hasAllCodes(string s, int k) {
        int n = s.size();
        if (n < k) return false;         // 连一个完整窗口都凑不出来

        int total = 1 << k;              // 2^k 种可能的二进制串
        int mask = total - 1;            // 低 k 位掩码，如 k=3 时 mask=0b111
        vector<bool> seen(total, false); // 用数组代替哈希集合，下标即窗口值
        int cur = 0;                     // 当前窗口对应的二进制值
        int cnt = 0;                     // 出现过的不同子串数量

        for (int i = 0; i < n; ++i) {
            cur = ((cur << 1) | (s[i] - '0')) & mask;  // 滑入新字符，只保留低 k 位
            if (i >= k - 1) {            // 前 k-1 个字符是在"预热"，凑满第一个窗口
                if (!seen[cur]) {
                    seen[cur] = true;
                    if (++cnt == total) return true;  // 集齐 2^k 种，提前返回
                }
            }
        }
        return false;
    }
};
```

几个细节：

- **预热阶段**：前 `k - 1` 次迭代窗口还没凑满，`cur` 只在 `i >= k - 1` 后才代表一个完整窗口，此时才开始标记。
- **数组代替哈希**：窗口值天然落在 `[0, 2^k)` 内，直接作下标，`vector<bool>` 比字符串哈希快一个量级，空间也从 `O(n * k)` 降到 `O(2^k)`（题目保证 `k <= 20`，`1 << k` 不会溢出 `int`）。
- **提前返回**：一旦 `cnt` 凑满 `2^k` 立即返回，不用滑完整个字符串。

时间复杂度 `O(n)`，空间复杂度 `O(2^k)`。
