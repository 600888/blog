# 1343. 大小为 K 且平均值大于等于阈值的子数组数目

[力扣原题（完整题面）](https://leetcode.cn/problems/number-of-sub-arrays-of-size-k-and-average-greater-than-or-equal-to-threshold/description/)

### 题意

给定数组 `arr` 和整数 `k`、`threshold`，统计所有长度为 `k` 的连续子数组中，平均值大于等于 `threshold` 的个数。

### 样例 1

```text
输入：arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4
输出：3
```

解释：子数组 `[2,5,5]`、`[5,5,5]` 和 `[5,5,8]` 的平均值分别为 `4`、`5` 和 `6`，其余长度为 `3` 的子数组平均值都低于 `4`。

### 样例 2

```text
输入：arr = [11,13,17,23,29,31,7,5,2,3], k = 3, threshold = 5
输出：6
```

解释：前 `6` 个长度为 `3` 的子数组（如 `[11,13,17]` 均值约 `13.67`）平均值都大于 `5`，最后两个 `[7,5,2]` 和 `[5,2,3]` 的平均值低于 `5`。

### 解题思路

窗口长度始终是 `k`，和 643 是同一个套路：先让右端点向右走，累加出第一个窗口的和；之后每轮结算完，就把左端点的数移出窗口，`left` 右移一格，下一轮再补进右边的新数。这样不需要为每个窗口重新求和。

窗口凑满 `k` 个数时，用 `sum * 1.0 / k` 算出平均值与 `threshold` 比较，达标就把答案加一。窗口和最大为 `10^5 * 10^4 = 10^9`，用 `long long` 保存更稳妥。

代码里 `right` 指向下一个要加入的元素。每次判断时，当前窗口恰好是 `[left, right)`，长度为 `k`。最后一个窗口判断完后，`right` 已经到达数组末尾，循环结束。

### 我的代码

```cpp
class Solution {
public:
    int numOfSubarrays(vector<int>& arr, int k, int threshold) {
        int left = 0, right = 0;
        int len = arr.size();
        long long sum = 0;
        int ans = 0;

        while (right < len) {
            while (right - left < k) {
                sum += arr[right];
                right++;
            }
            if (sum * 1.0 / k >= threshold) {
                ans++;
            }
            sum -= arr[left];  // 将左边第一个数移出窗口
            left++;
        }
        return ans;
    }
};
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。每个元素只进出窗口各一次。

### 关于判断条件

由于 `threshold` 是整数，`sum * 1.0 / k` 的浮点转换其实可以省掉：整数除法 `sum / k` 是向下取整，而下取整后仍大于等于整数阈值，等价于平均值本身达标，所以 `sum / k >= threshold` 也不会漏判。

更常见的写法是把除法换成乘法，直接比较 `sum >= (long long)threshold * k`，既没有除法，也没有任何浮点参与，是这类"平均值达标"题最稳妥的判断方式。
