# 1456. 定长子串中元音的最大数目

[力扣原题（完整题面）](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/)

### 题意

给定字符串 `s` 和整数 `k`，在所有长度为 `k` 的连续子串中，找出元音字母（`a`、`e`、`i`、`o`、`u`）最多的那一个，返回它的元音个数。

### 样例 1

```text
输入：s = "abciiidef", k = 3
输出：3
```

解释：子串 `"iii"` 包含 `3` 个元音字母，是所有长度为 `3` 的子串中最多的。

### 样例 2

```text
输入：s = "aeiou", k = 2
输出：2
```

解释：任意长度为 `2` 的子串都恰好包含 `2` 个元音字母。

### 样例 3

```text
输入：s = "leetcode", k = 3
输出：2
```

解释：`"lee"`、`"eet"` 和 `"ode"` 都包含 `2` 个元音字母。

### 解题思路

窗口长度始终是 `k`。先让右端点向右走，凑出第一个窗口；之后每轮结算完，就把左端点的字符移出窗口，`left` 右移一格，下一轮再补进右边的新字符。

用一个 `unordered_map` 维护当前窗口内每个字符的出现次数。窗口凑满 `k` 个字符时，把五个元音字母的次数加起来得到当前窗口的元音数，更新答案；随后 `cnt[s[left]]--` 把左端字符移出窗口，`left` 右移。由于题目保证 `k <= s.size()`，至少能凑出一个完整窗口。

代码里 `right` 指向下一个要加入的字符。每次结算时窗口恰好是 `[left, right)`，长度为 `k`。

### 我的代码

```cpp
class Solution {
public:
    int maxVowels(string s, int k) {
        int left = 0, right = 0, len = s.size();
        unordered_map<char, int> cnt;
        int maxCnt = 0;

        while (right < len) {
            while (right - left < k) {  // 固定起始为left，长度为k的窗口
                cnt[s[right]]++;
                right++;
            }
            int sum = cnt['a'] + cnt['e'] + cnt['i'] + cnt['o'] + cnt['u'];
            maxCnt = max(maxCnt, sum);
            cnt[s[left]]--;
            left++;
        }
        return maxCnt;
    }
};
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。每个字符只进入窗口一次、移出一次；每次结算只对哈希表做五次查询，`cnt` 中保存的是窗口内的小写字母计数，规模与字符集相关，可视为常数空间。

### 优化：只维护元音计数

本题只关心元音，不需要完整的哈希表。进入窗口的字符是元音就把计数 `+1`，移出窗口的字符是元音就 `-1`，一个计数器即可完成维护：

```cpp
class Solution {
public:
    int maxVowels(string s, int k) {
        int sum = 0;
        for (int i = 0; i < k; ++i) {    // 第一个窗口 [0, k)
            sum += isVowel(s[i]);
        }
        int maxCnt = sum;

        for (int i = k; i < static_cast<int>(s.size()); ++i) {
            sum += isVowel(s[i]) - isVowel(s[i - k]);   // 进一个、出一个
            maxCnt = max(maxCnt, sum);
        }
        return maxCnt;
    }

    int isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }
};
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。相比哈希表写法省掉了每次结算的五次查询，这也是定长窗口最典型的"进一个、出一个"套路。
