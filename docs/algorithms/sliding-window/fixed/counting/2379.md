# 2379. 得到 K 个黑块的最少涂色次数

[力扣原题（完整题面）](https://leetcode.cn/problems/minimum-recolors-to-get-k-consecutive-black-blocks/description/)

### 题意

给定一个由 `'W'`（白块）和 `'B'`（黑块）组成的字符串 `blocks` 和整数 `k`。每次操作可以把一个白块重新涂成黑块，要让字符串中出现至少一段连续 `k` 个黑块，求最少操作次数。

### 样例 1

```text
输入：blocks = "WBBWWBBWBW", k = 7
输出：3
```

解释：把下标 `0、3、4` 的三个白块涂成黑块，得到 `"BBBBBBBWBW"`，开头即为连续 `7` 个黑块。可以证明少于 `3` 次操作无法做到。

### 样例 2

```text
输入：blocks = "WBWBBBW", k = 2
输出：0
```

解释：字符串中已经存在连续 `2` 个黑块（下标 `3、4`），不需要任何操作。

### 解题思路

反过来想：要涂的次数最少，就是要挑一个"本来黑色就最多"的窗口。最终那连续 `k` 个黑块一定落在某个长度为 `k` 的窗口里，涂色次数 = 窗口内白块数 = `k` - 窗口内黑块数。所以只需在所有长度为 `k` 的窗口中找出黑色块最多的那个，答案就是 `k - maxCnt`。

窗口长度始终是 `k`，和 1456、1876 是同一个计数套路：右端点先把第一个窗口凑满，统计黑块数；之后每轮结算完，左端移出一个字符（是 `'B'` 就把计数减一），下一轮右端补进一个新字符（是 `'B'` 就加一）。

代码里 `right` 指向下一个要加入的字符，结算时窗口恰好是 `[left, right)`，长度为 `k`。题目保证 `k <= blocks.size()`，至少能凑出一个完整窗口。

### 我的代码

```cpp
class Solution {
public:
    int minimumRecolors(string blocks, int k) {
        int left = 0, right = 0;
        int len = blocks.size();
        int sum = 0;      // 用于统计子数组中黑色块的数量
        int maxCnt = 0;

        // 等价于找到窗口大小为k的子数组中，黑色块最多的数量
        while (right < len) {
            while (right - left < k) {
                if (blocks[right] == 'B') {
                    sum++;
                }
                right++;
            }
            maxCnt = max(sum, maxCnt);
            if (blocks[left] == 'B') {  // 如果左侧第一个数是黑色，移出窗口时计数-1
                sum--;
            }
            left++;
        }
        return k - maxCnt;  // 用窗口长度k减去最多黑色块的数量，即为最少操作次数
    }
};
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。每个字符只进出窗口各一次，全程只维护一个黑块计数。数据规模很小（`n <= 100`），暴力枚举每个窗口也能过，但窗口写法不需要重复统计。
