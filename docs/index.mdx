## 从哪里开始

如果你刚开始学习，可以按下面的顺序阅读：

1. **先理解数据。** 从 [时间与空间复杂度](./algorithms/complexity.md) 开始，建立衡量算法效率的直觉。
2. **再理解通信。** 通过 [网络分层](./networks/layering.md)，梳理数据从应用到链路的路径。
3. **走进程序底层。** 阅读 [进程与线程](./operating-systems/processes.md)，理解程序如何运行。
4. **把原理带到现场。** 从 [报文阅读与分析](./power-protocols/reading-frames.md) 开始，将通信知识用到联调中。
