## 分析通信问题

1. 应用有没有真正发起请求？
2. 域名是否解析为预期地址？
3. 目标地址与端口是否可达？
4. 连接是否成功建立，是否发生重传或断开？
5. 应用协议的报文是否满足双方约定？
