# 关于这些笔记

这是一份围绕计算机基础与电力通信整理的个人知识库。

## 内容范围

- **数据结构与算法**：理解数据的组织、算法的思路和效率。
- **计算机网络**：理解数据如何穿过协议栈，在不同设备之间传递。
- **操作系统**：理解进程、内存和并发背后的资源管理。
- **电力规约**：整理报文阅读方法、点表映射和通信联调经验。

## 阅读方式

顶部导航切换知识模块，左侧目录选择文章，右侧目录定位当前文章的章节。窄屏设备可以通过“菜单”展开目录。

使用顶部搜索，或按 `Ctrl + K`（macOS 为 `⌘ + K`），查找关键词。右上角可以切换深浅色主题。

## 记录约定

示例优先说明原理。具体工程实现还需要结合运行环境、设备说明和项目约定。

对于电力通信，规约名称相同也可能存在不同版本和设备实现差异。报文字段与参数以项目采用的正式标准、厂商文档和双方确认的点表为准。

发现错误时，可以通过文章底部的“编辑此页”前往 GitHub 修订。
