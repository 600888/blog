# 操作系统

操作系统在硬件资源与应用之间提供抽象，管理 CPU、内存、设备和文件，并协调多个程序的运行。

## 观察程序的视角

遇到运行问题时，先区分 CPU 忙、等待 I/O、锁竞争和内存压力。这些现象可能表现为相同的“响应慢”，但排查方向不同。
