    #123. 买卖股票的最佳时机 III

    力扣原题（完整题面）

    #题意

    给定每日股价 prices，最多完成两笔交易，且卖出后才能再次买入；求最大总利润。

    #样例 1

    输入：prices = [3,3,5,0,0,3,1,4]
输出：6

    解释：可以先在 0→3 获利 3，再在 1→4 获利 3。
